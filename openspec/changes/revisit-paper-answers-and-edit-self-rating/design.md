## Context

用户确认：做题时可无限次回看此前题目；回看默认不主动展示参考答案，只显示原作答及正误判定；支持重新编辑自评。

现行 practice-review 的立即上一题限制、主动显示答案及禁止改评分条款与新需求冲突。GLOSSARY 的记录只增不改及 Agent-only Attempt Correction 也需显式协调。本文件记录拟议行为，尚未上线。

## Goals / Non-Goals

支持本卷同次执行内多题、多次往返回看、主动揭示参考答案及原作答关联的自评编辑，保留当前题草稿和其他卷进度。

不提供重答、修改原答案、手工修改客观判定、混合多个历史轮次或新建学习记录体系。闪卡保持原行为。

## Decisions

1. 复用现有回看视图及 Paper、Practice Run、Attempt 身份。只扩展浏览器缓存无法可靠支持刷新恢复，另建回看存储会重复事实；优先从现有执行与持久作答恢复。未确认提交仍可显示浏览器暂存，但必须标注未确认。
2. 回看位置与执行游标独立。可回到第一条有记录的题，再前进至最后一条，并返回当前题；边界禁用，不回绕，不自动提交，不设访问次数上限。可访问的已完成执行仍能回看，不伪造当前未做题。
3. 每次进入回看题，包括离开后再次进入同题，都收起参考答案和解析。点击后才展开；选项正常显示，但不得用正确项高亮、解析摘要提前泄露答案。无判定时如实显示，不把自评当正误。
4. 编辑加载该次作答已有的 1–5 分及可选评语。保存只改变本次自评的有效结果，不改原答案、客观判定或 Attempt 身份，不移动游标；取消不写入。未自评时按原偏好和规则补评，关闭自评的执行不被强行开启。
5. 保存使用精确的执行、题目、Attempt 身份及并发版本、稳定请求身份。重试只生效一次；失败保留编辑。题目失效、删除或记录已改时零写入并提示，不转写当前题或另一卷。
6. 较早的已评分题也应可编辑，不能照搬 Agent correct 仅允许最新尝试的限制。实施前必须证明如何替换旧评分贡献并保留后续学习活动，可使用按原活动顺序重放或可证明等价机制。禁止回滚整份旧快照覆盖后续记录。不能安全实现时保持任务未完成并提出具体方案，不静默缩减为只读或只能改最新题。
7. 新 Agent 消息跟随当前可见回看题和原作答；返回当前题后恢复上下文，已接受消息的上下文不追溯修改。无需等待右侧栏独立性 change。

## Contract reconciliation before implementation

- practice-review：通过 delta 替代单题、主动揭示及禁止编辑评分条款，保留未确认提示、草稿恢复、游标不变及 Agent focus 场景。
- GLOSSARY：复用既有名词，为浏览器仅自评更改明确例外，不混同 Agent Attempt Correction。
- DATA_MODEL：定义旧/新评分有效性、反馈关联、学习投影和调度重算、幂等与并发、后续活动保护。模型不够时先补设计。
- PRODUCT-MANUAL 和 ACTION-GRAPH：登记回看、主动展开、编辑/取消/保存及失败处理。ARCHITECTURE 和 FILE_CONTRACT 仅同步实际受影响部分。

## Validation and rollout

先以确定性回归证明跨三题以上回看、隐藏答案、自评修改、重复提交、失败及迟到响应。独立验收在隔离库和浏览器验证真实 DOM、刷新/切卷恢复、草稿与游标不变、旧评分不重复累计及同知识点后续学习活动保留。

不得在真实库试答。迁移或真实写入需要另行授权。实施与独立验收分开，验收通过后才同步 live specs 并归档。本轮仅规划，全部实施任务保持未完成。
