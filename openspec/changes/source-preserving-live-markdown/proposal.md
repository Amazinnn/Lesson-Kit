## Why
长文本输入目前仅展示源码，公式和结构难以在输入时检查。

## What Changes
全部正式长文本入口使用原位 Markdown 编辑，保存原文，保留草稿、队列、快捷键及锁定规则。短字段不变。

## Capabilities
### New Capabilities
- `live-markdown-editing`: source-preserving long-text editing and safe real-time rendering.
### Modified Capabilities
None.

## Impact
Browser editor, local build, package assets and long-text display. No API, database or frozen-layer changes.
