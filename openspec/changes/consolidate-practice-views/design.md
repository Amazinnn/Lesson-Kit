# consolidate-practice-views 设计

## D1 三个功能、一张「今天」列表

视图收敛的判据：按「用户要完成的事」清点，四个视图只覆盖三个功能——
选范围（F1，知识点页/图谱独占）、看今日推荐（F2，计划排序）、看到期（F3，
调度排序）。F2 与 F3 的行结构 80% 同构，因此合流：

- 列表 = 计划队列行 ∪ 到期行，去重（同一知识点同时命中时合并为一行，
  原因并列）；排序 = 计划权重优先、到期日次之、名称兜底（确定性）；
- 行格式：`名称 · 人话原因 · 动作`；徽标只保留类型/方向两种；
- 动作：知识点行 = 范围交接（选中并跳练习）；题目行 = `include_ids`
  直达该题。

## D2 人话原因短语（纯函数，零调度参数）

| 条件 | 短语 |
|---|---|
| 计划行，覆盖低 | `覆盖仍低` |
| 逾期 N 天 | `拖了 N 天` |
| 今天到期 | `今天到期` |
| last_rating 1–2 | `，上次没记住` |
| last_rating 3 | `，上次一般` |
| last_rating 4–5 | `，上次记得不错` |
| 无评分 | `，还没评过` |

拼接规则：到期行 = `可以复习 · ` + 时间短语 + 记忆短语（最多一个）；
计划行沿用既有原因文案。每行总长超 24 字时截断记忆短语。

## D3 时间安排并列布局

练习页顶部改为两栏：左 = 学习安排（目标卡 + 合流列表），右 = 时间安排
（月历 + 柱状图，宽约 300px）；`@media (max-width: 1023px)` 纵向堆叠。
既有 `.plan-columns` 网格扩展为三段。`/calendar` 端点与渲染逻辑从复习页
原样搬移，不改行为。

## D4 卡片轻会话（模式内，非页面）

- 触发：开始闪卡/判断模式时，`review_overview` 显示范围内存在到期方向行
  → 会话区顶部出现可关闭的提示条「范围内有 N 张到期卡，先翻一张？」；
- 接受 → 现有卡片流组件原地运行（复用正面/揭示/评分/feedback direction），
  翻完自动回到模式流程；拒绝 → 直接进入常规拉题，本次不再提示；
- 判断题本体走 micro quiz 判分卡，方向卡仅是范围调度内容的轻入口。

## D5 移除清单与保留清单

**移除**：`review` 导航项、`review_page`/`_send_page` review 分支、
到期日期分组列表、复习页时间区块、`start-card-review` 入口区。
**保留**：`queries.review_overview`（合流列表数据源）、`/calendar`、
`pull.include_ids`、`feedback.direction`、micro quiz 全部、
`workbench.css` 中徽标/水位等通用样式。
**迁移**：`workbench.js` 卡片流组件移至练习页模式流程内。

## D6 规格处置

- `review-page` capability 标注 Deprecated（Purpose 顶部声明），无代码
  对应的 UI 需求随实现拆除；
- include 过滤与方向调度键收编为 review-workbench 的 ADDED 需求；
- 三页导航恢复后，`workbench-ui` Purpose 段在归档时同步改写
  （tasks 列出）。
