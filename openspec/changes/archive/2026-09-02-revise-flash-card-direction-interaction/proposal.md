# revise-flash-card-direction-interaction 提案

## Why

所有者 2026-09-02 走查反馈：闪卡当前的「混合偏好 + 会话中 ⇄ 交换 + 叠牌露边角」三者
逻辑含混。闪卡语义应当类推单词学习：正面是概念本身，反面是对它的阐释。方向应在开练
前一次性选定（正向=概念先行，反向=阐释先行），会话内不再切换；每张卡在任何时刻都应
呈现为两张完全重合的牌，揭示时上牌逆时针漂移停住、下牌顺时针漂移后从下方滑出完全可见，
而不是先露出边角再扇开。

## What Changes

- 闪卡方向偏好收敛为 `forward | reverse`，会话开始时选定、会话内固定；`mixed` 偏好
  从页面、拉取 API 与域规则中移除；双向卡在正向会话出正向动作、反向会话出反向动作，
  单向卡在反向会话保留为正向动作（不变）。
- 移除会话内 ⇄ 方向交换按钮与相关状态；评分永远携带会话方向。
- 所有闪卡统一渲染为完全重合的两张牌（提示面在上、另一面完全遮蔽）；揭示动作为
  上牌逆时针漂移停住、下牌顺时针漂移后从下方滑出并保持轻微倾斜；减少动态效果下
  直接呈现终态。
- 不改方向数据模型（`directions` 能力、`(card, direction)` 调度行、`exclude_directions`
  拉取排除全部保留）。

## Capabilities

### Modified Capabilities

- `flash-card`：方向偏好收敛为会话级 forward/reverse，移除 mixed。
- `workbench-ui`：新增统一叠牌呈现与漂移滑出揭示的要求。

## Impact

练习页标记、浏览器练习流、CSS 动画、拉取 API 校验、域规则与对应测试；无数据迁移。
