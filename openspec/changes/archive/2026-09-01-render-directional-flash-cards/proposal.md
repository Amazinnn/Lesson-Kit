# render-directional-flash-cards 提案

## Why

闪卡内容与调度已经能表达单向、双向及独立方向，但练习页仍固定显示 front → back，用户无法在开练前选择方向，也无法在练习中交换提示面。单向与双向内容目前使用同一种“背面下挂”表现，也没有传达双向卡两面地位对称的视觉含义。

## What Changes

- 选择闪卡模式时显示正向 / 反向 / 混合方向偏好，混合为默认；单向卡无论偏好都保持正向。
- 双向卡显示紧凑 ⇄，点击随时交换当前卡的提问方向；评分携带最终使用方向。
- 单向卡揭示时向下展开另一面；双向卡以两张叠卡呈现，揭示后像扑克牌一样向左下/右下扇开。
- 同一张双向内容的两个方向在混合会话中可分别出现、分别回翻、分别评分。
- 减少动态效果偏好下取消位移动画，但保留完整内容与状态。
- 不增加动画库、手势框架或新页面。

## Capabilities

### Modified Capabilities

- `flash-card`：练习流启用方向选择、方向交换与两种揭示表现。
- `review-workbench`：方向 UI 的冻结裁决由显式闪卡会话取代；仍不自动发起卡片会话。

## Impact

修改服务端练习页标记、会话牌组的兼容字段、浏览器练习流、CSS 动画及测试。方向数据与拉取 API 依赖 `enable-flash-card-directions`；本 PR 不增加数据迁移。
