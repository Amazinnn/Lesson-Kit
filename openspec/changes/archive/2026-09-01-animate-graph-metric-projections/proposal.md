# 知识图谱指标投影动画

## Why

现有图谱已经能切换关系结构、题目数量、重要性和学习状态，但切换时会销毁并重建整张图，节点直接跳到新位置；节点大小也始终只表达题目数量，无法随当前指标一起传达高低。用户需要节点像气泡一样向中心或外围迁移，并由大小和一组克制的蒙德里安色谱共同表达当前指标。

## What Changes

- 投影切换保留现有节点与选择状态，通过力场目标位置和目标半径完成连续过渡。
- 非关系投影中，指标越高的节点越靠近中心且越大；学习状态按 `needs_work / review / null / mastered` 表达由高到低的关注优先级。
- 关系结构、题目数量、重要性、学习状态分别使用可辨识的暖白、蓝、黄和红黄蓝色谱。
- 尊重系统减少动态效果设置：减少动态效果时直接计算并绘制稳定终态。

## Scope

本变更只处理指标投影的大小、色彩和过渡。多条件筛选分群、关系管道立体渲染与新的学习指标另行交付。
