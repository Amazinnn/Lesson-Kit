# Change: Apply the soft Mondrian workbench foundation

## Why

The workbench has a coherent three-column structure but still carries the neutral
reference application's visual identity. Lesson Kit needs its own sunny learning
character without turning every card into a colored dashboard.

## What Changes

- Introduce stable paper, ink, blue, yellow, and red visual roles.
- Use paper surfaces and dark structural rules for the shell.
- Add a compact three-block brand mark and a yellow page-header accent.
- Use blue for primary action/selection, yellow for review/current emphasis, and red
  for needs-work/error emphasis.
- Tighten ordinary card geometry while leaving conversation bubbles soft.

Color continues to be accompanied by text, outline, or geometry.
