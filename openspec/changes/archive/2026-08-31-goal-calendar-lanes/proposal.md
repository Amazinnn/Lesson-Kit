# goal-calendar-lanes 提案

## Why

现有时间安排把目标只放在截止日的单个格子里，无法表达「一个阶段目标从某天持续到某天」，也无法直观看见多个目标的时间重叠。所有者要求把目标显示成遍布月历的横向跑道：起止日期决定长度，重叠目标上下并列。

## What Changes

- 目标新增可选 `start_date`；既有无开始日期目标继续兼容，并显示为截止日单日跑道。
- 目标表单、卡片、CLI 与 Agent 目标助填动作同步支持开始日期。
- 月历按自然周绘制目标时间跑道；跨周自动切段，重叠区间自动分轨，阶段目标与长期目标保持可辨识。
- 14 天任务量柱状、重日判断与 Agent 预填行为保持不变；时间视图继续只读。

## Capabilities

### Modified Capabilities

- `calendar-workload`：目标由截止日落格升级为起止日期时间跑道。
- `ai-teacher-bridge`：目标表单助填动作增加可选开始日期字段。

## Impact

代码限于 `workbench/data/goals.py`、目标 CLI/页面表单、时间视图 JavaScript/CSS 与目标动作清洗；不新增数据库、不修改调度算法。同步更新产品手册、术语表与动作图谱。
