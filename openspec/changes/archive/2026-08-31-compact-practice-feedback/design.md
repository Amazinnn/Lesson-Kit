# compact-practice-feedback 设计

## 交互结构

即时自评区保持现有 DOM id 和 JavaScript 写入路径，只调整呈现层：

1. `rating-input` 继续使用 `type=number`、`min=1`、`max=5`、`step=1` 与
   `inputmode=numeric`，直接填一个数字；不创建五个按钮。
2. `feedback-note` 收为单行起步的可选备注，并与 `save-rating` 放在同一圆角
   容器内。备注仍可纵向拉伸，长内容不被截断。
3. 两个 `<label>` 保留并使用视觉隐藏样式，输入框以短占位文案说明用途。
4. 提交按钮文案改为「记录并下一题」，明确这是一次写入和推进，而非自动保存。

## 视觉边界

- 宽度跟随练习栏，最大 560px；数字输入不超过 180px。
- 第二行使用 `min-width: 0` 的 flex 布局，窄栏中备注区收缩、按钮不折行。
- 聚焦第二行任一控件时只强调外层输入面，避免双重边框。

## 不做的事

- 不改变统一自评收束页。
- 不新增自动提交、快捷键或评分默认值。
- 不改变校验、反馈写入、弱项识别和下一题推进逻辑。
