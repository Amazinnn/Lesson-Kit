# 知识图谱状态筛选与分群

## Why

图谱脚本保留了一个单值状态筛选变量，但页面没有对应控件，学生无法按学习状态收束复杂图谱。用户要求筛选与指标投影相互独立：可同时选择一个或多个学习状态，不符合条件的节点和连线淡出，保留节点按状态聚成一团或多团，取消后重新浮现。

## What Changes

- 图谱工具栏新增四项多选状态筛选：`needs_work / review / mastered / null`。
- 未选任何状态时展示完整图谱；选择一项或多项时按并集保留节点和内部连线。
- 被排除的节点与相关连线先淡出再离开布局；取消筛选时重新淡入。
- 筛选后的节点按状态获得独立、确定性的聚类中心，并通过现有力场移动到对应区域。
- 筛选与关系结构/题量/重要性/学习状态投影并行使用，且不改变练习选区或学习数据。

## Scope

本变更不增加学习状态、不持久化图谱坐标，也不实现关系管道的立体渲染。
