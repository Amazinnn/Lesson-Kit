# metric-projections-render-nodes-only 提案

## Why

所有者 2026-09-02 走查：重要性、题目数量、学习状态等指标投影下，关系连线仍会
渲染，导致节点因连线而呈现拥挤缠绕的形状。指标投影的意义是「看指标不看关系」，
此时应只保留一团圆点，连线直接不存在（而非隐藏）。

## What Changes

- 关系结构是唯一渲染关系连线的投影；题量、重要性、学习状态投影只渲染节点，
  不创建任何连线元素。
- 聚焦/邻域等需要邻接关系的逻辑仍由数据模型驱动，与可见连线无关。

## Capabilities

### Modified Capabilities

- `workbench-ui`：指标投影形态要求更新为「只渲染节点」；投影切换场景措辞同步。

## Impact

客户端图谱渲染分支、spec 文案；无数据与 API 变化。
