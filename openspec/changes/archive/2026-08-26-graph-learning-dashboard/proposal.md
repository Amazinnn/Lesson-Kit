# Graph learning dashboard

The graph right column duplicates the formal knowledge-point page and exposes too many write controls. Replace it with a compact dashboard while keeping the formal knowledge-point page as the deep-reading and content-editing destination.

## Scope

- Show selected knowledge-point state, problem count, neighbor/relationship summary, signals, and schedule.
- Keep one quick current-state edit using the existing graph state endpoint.
- Link to the formal knowledge-point page.
- Remove body editing and per-problem state controls from the graph panel.

## Non-goals

- No new graph data model or physics engine.
- No removal of existing API compatibility endpoints.
