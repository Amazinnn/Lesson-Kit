# 验收清单 — graph-node-visual-language

> 本文件是**本变更自带的验收基线**（**所有者裁决 A-12**，`decisions.md`）。
> 验收方式与 v2 同构：**对照截图 + 关键帧序列 + 交互清单**三件套；
> 但**判据不同** —— 本变更的判据是**结构不变量**，不是「亮色逐像素不变」。
>
> 相关：`proposal.md`（范围与冻结）、`design.md`（实现方案，D-12.3 / D-14.5）、
> `../workbench-visual-language-v2/decisions.md`（G-1…G-24、A-7 / A-8 / A-10 / A-12）、
> `../workbench-visual-language-v2/design-notes/graph-isolation.md`（实测事实与比对协议 §6）。
>
> **为什么本文件存在（必读）**：
> v2 的 `acceptance.md` G-5 写的是「图谱页未被本变更触碰（否定式断言）… 差异像素数 = 0。
> 图谱**不在该变更的验收范围内**」——**那条只对 v2 有效**。
> 本变更存在的目的就是重画节点，因此：
> - **不引用** v2 的 G-5 作为本变更的门禁（那是一条对本变更并不存在的断言）；
> - **「亮色逐像素不变」按 A-12 从图谱的约束里拿掉**（节点本来就要重画；
>   A-10.1 已把半径区间从 20–44px 改为 14–30px ⇒ 与「逐像素一致」物理互斥）；
> - 本文件**自带**基线：**结构不变量必须成立**，**四个声明区允许变化**。

## 0. 底线守卫（最高优先级，先于其它任何检查）

### 0.1 底部守卫：请求与持久化不变（沿用 v2 的 G-1…G-4 口径）

> 冻结项：**请求与持久化不变**。冻结 = API 请求序列与载荷、持久化内容、学习事实、
> 状态机、由请求驱动的可见性切换。本变更**不写产品代码之外的后端**，
> `pool/` `pipeline/` `workbench/data/` 一行不动（`proposal.md`「不改」段）。

| # | 检查项 | 判定方法 | 通过标准 |
|---|---|---|---|
| G-1 | 图谱页的**请求序列**不变 | 在池副本上脚本化走一遍图谱页（进页 → 切投影 → 搜索 → 筛选 → 选中节点 → 拖拽 → 缩放 → Fit），记录服务端收到的**请求方法 + 路径 + 载荷键集合**；改造前后各跑一次并 diff | 序列与载荷**逐条相同**；新增 / 删除 / 改名任意一条即 FAIL |
| G-2 | 图谱的**持久化结果**不变 | 同一次脚本化走查前后，比对池中 `problem_attempts` / `feedback_events` / `practice_runs` 的行数与关键列 | 行数与关键列**逐行相同** |
| G-3 | **学习投影不变** | 同一份脚本化走查前后，比对受影响知识点 / 题目的当前状态与调度行 | 完全相同 |
| G-4 | **复习建议集合不变** | 比对改造前后同一时刻的到期项集合与弱项排序 | 集合与顺序**完全相同** |
| G-5 | **无新增学习事实** | 人工核对：本变更的图谱改动只落在 `workbench.css` 图谱区段、图谱 JS 与 `pages.py` 图谱页 | 池 schema **零变更**；`workbench-ui` / `review-workbench` 的既有能力未被改写（除本变更 delta 显式 MODIFIED 的 6 条） |

> 〔沿用 v2 口径〕G-1…G-4 的脚本要**同时**用于改造前与改造后，且跑在**池副本**上（见 §5）。
>
> 〔与 v2 的差别〕v2 的 G-5 是「图谱未被触碰」的**否定式断言**；
> 本文件的 G-5 是「**无新增学习事实**」的**底线断言** —— 两者不是同一条门禁。

### 0.2 结构不变量清单（本变更的硬门禁，判据核心）

> 〔A-12〕以下五条**必须不变**。任何一条不成立 ⇒ 本变更 FAIL，
> **不得**用「视觉上更好」抵扣。

| # | 不变量 | 判定方法 | 通过标准 |
|---|---|---|---|
| **SI-1** | **节点集合不变** | 取图谱页渲染完成后的节点 id 全集（DOM `.node-wrap` 的 `data-*` / 后端返回的节点清单），改造前后各取一次并求差集 | 节点 id 集合**完全相同**（数量、内容皆同）；新增 / 减少 / 改名任一节点即 FAIL。依据：G-10「布局物理、关系线、交互、投影语义一律不动」；实现入口 `workbench.js:957-1053` `graphCreateNodes()` |
| **SI-2** | **关系边集合不变** | 取 WebGL 关系线的拓扑（source / target / type / direction 四元组全集；类型集合见 `workbench-ui:662-678`），改造前后各取一次求差集 | 边四元组集合**完全相同**；不得新增、删除或改类型 / 改方向。依据：G-10 / G-18（线型 / 粗细 / 颜色不改，只改端点落点） |
| **SI-3** | **力导向布局的收敛性与确定性** | ① 收敛：等 `#graph-solver-state` **不再带 `.solving` 类**（`workbench.js:719`）且 DOM 静止签名连续 N 次不变（`graph-isolation.md` §6.4 的等待谓词）后，取每个节点的归一化坐标；② 确定性：**清空 `lk_graph_layout_v1_<workspace>`**（`graph-physics.js:43-48`）后**重跑两次从零求解**，取同一批坐标 | ① 布局**必须收敛**（`graph-physics-core.js:1246` alpha 衰减 → `:1255` 连续 15 帧稳定 → `:1260` `settled = true`）；② 两次从零求解的坐标**逐节点相同**（允许 ≤0.1px 的存储取整误差，同 `graph-isolation.md` §6.3 N-3 口径）；③ 改造前后的坐标集**相同**（节点位置属结构，不属允许变化区） |
| **SI-4** | **投影语义不变** | 四个投影（关系结构 / 题目数量 / 重要性 / 学习状态）各自的取值来源与判读含义不得改变：取 `graph-physics-core.js:1463-1470` `scoreFor()` 对同一批节点算出的值，与 `workbench.js:1055-1061` `graphProjectionDisplay()` 的显示映射 | ① 四个投影**都还在**、**含义不互换**（关系结构投影仍不承载量值语义，见 G-22）；② 同一节点在同一投影下的量值**相同**；③ 量值 → 视觉（半径 / 环宽 / 颜色）的映射是**单调**的，改动只落在**取值区间**（A-10.1：14→30 屏幕 px）与**色键**（G-7 / G-16 / G-20…G-22），不落在**排序**上 |
| **SI-5** | **交互行为不变** | 逐项对照 `workbench-ui:121-248` 与 `pages.py:410-481`：搜索、筛选、缩放、平移、Fit、拖拽、聚焦、聚拢滑杆、详情看板的**触发方式、结果、可见性切换** | ① 每个交互的**结果与改造前一致**（同一操作落到同一状态）；② **不得新增**任何由本变更引入的交互态；③ 筛选**只改成员、不改外观**（存活节点保持同心圆形态与当前投影配色，离场节点淡出而不变色）—— 见本变更 delta 的 `Multi-state graph filtering` MODIFIED 块 |

> 〔边界〕SI-1…SI-5 是**结构**。**节点 / 标签 / 图例 / 底噪这四个区域不在此列** ——
> 它们是本变更要改的东西，判据见 §0.3。

### 0.3 允许变化区清单（节点 / 标签 / 图例 / 底噪）及其判据

> 〔A-12〕这四个区域**允许变化**。但「允许变化」≠「可以乱改」：
> 每一条都给出**必须仍然成立**的判据。比对截图的差异像素集合必须 **⊆**
> 这四个区域的包围盒并集（`design.md` D-12.3）。

| # | 允许变化区 | 本变更改了什么 | 判据（**仍然必须成立**） |
|---|---|---|---|
| **AV-1** | **节点区**（`.node-wrap` / `.node` / `.node-face` / `.node-value`，`workbench.css:1643-1719`） | 形态：五层信息挤在一个圆 → **内核 + 外环**两个同心圆（G-1 / G-13）；删除 `.metric-track` 度量弧（G-2）；删除节点上的状态文字（G-6）；圆心只留一个正式题数（G-9）；半径收窄为 **14→30 屏幕 px**（A-10.1）；外环粗细随量值映射（D-3）；选中 / 悬停 = 外环加粗变实 + 轻微放大，**不用阴影与卫星点光晕**（G-15）；缩放补偿：尺寸按**屏幕像素**而非世界像素（D-1 / G-24） | ① 节点**数量与 id** 不变（SI-1）；② 节点的**位置**不变（SI-3）；③ 圆心数字 = 该节点的**正式题数**，**所有投影相同**（G-9）；④ 节点上**不得出现任何状态文字**（G-6）—— 状态名只许出现在学习看板、悬浮提示与无障碍名里；⑤ 量值 → 尺寸的映射**单调**，区间落在 14–30 屏幕 px；⑥ 缩放补偿后**每个节点的外环、圆心数字与标签都可读**（不缩放即可读，见 `graph-visual-language` delta 的 `Night paper graph adaptation`） |
| **AV-2** | **标签区**（`.label` / `.meta`） | 常态可见但不抢眼：字号略放大、**不截断**（换行显示全文）、降低对比度（A-10.3 / G-5）；删除 `.meta` 行（G-6）；标签重叠时**自动隐藏次要标签**（按节点大小与重要度排序让位，G-23）—— 取代「按缩放阈值隐藏」 | ① 标签**默认可见**，判据从「缩放阈值」改为「**重叠让位 / 超出可见标签预算**」（G-23）；② 标签**不截断**，完整标题由**悬浮 / 键盘聚焦**可达（G-5 / A-10.3）；③ 标签字号为**屏幕像素**语义（D-6 / D-1）；④ 标签对比度**低于**节点自身填充（不抢节点）但**可读**；⑤ 隐藏的必须是**次要**标签（按大小与重要度排序让位），不得随意隐藏 |
| **AV-3** | **图例区**（`.legend-*`，`workbench.css:1780-1799`） | 图例分两块：上半保留关系线型（现状），下半为**节点颜色**并**随投影切换**（G-14 / G-11） | ① 图例**两块**都在；② 下半的节点颜色键**与当前投影**严格对应（G-11：必须有「什么颜色对应什么类型」的标注，且随投影切换）；③ 上半关系线型**保留现状**（`workbench-ui:662-678`）；④ 图例「相关」色与 WebGL 实况**一致**（现状 `#aaa399` vs 实况 `rgb(117,112,104)` 是缺陷，本变更修好） |
| **AV-4** | **底噪画布区**（`.graph-tide`） | **保留观感**（G-4：所有者「其实那个还挺好看的」），只改**绘制方式**：每帧约 600 个 alpha 混合色斑 → **静态预渲染 / 降频**（D-9） | ① 底噪**仍在**（不得整体删掉）；② 观感**仍读作极淡的纸纹底噪**；③ 不再每帧重绘 600 个色斑（性能断言见 §3.4）；④ 底噪**不承载任何数据语义**（它与图谱数据完全无关，只在节点周围挖洞） |

> 〔比对口径〕差异像素集合 **⊆**（节点区 ∪ 标签区 ∪ 图例区 ∪ 底噪画布区）；
> 遮罩由 DOM 的 `getBoundingClientRect` 在截图时导出，作为比对脚本的输入（`design.md` D-12.3 代价段）。
> **落在遮罩之外的任何一个差异像素 ⇒ FAIL。**

## 2. 关键帧序列清单

> 动效不能只靠截图验收（截图看不到运动）。每个动效采一组帧，拼成一条**分镜条**。
>
> **〔范围说明〕** **台灯转场（涟漪）不涉及图谱** —— 台灯是 v2 的全站主题转场，
> 图谱的夜纸适配是**值集切换**（`html[data-theme="night"]` 下的 token 重声明），
> 不参与涟漪扩散。本变更的关键帧只覆盖**节点自身**的状态过渡。

| # | 过渡 | 采样帧 | 通过标准 |
|---|---|---|---|
| M-1 | **节点选中** | 0 / 60 / 120 / 200 ms 四帧 | 外环**加粗变实** + 节点**轻微放大**（scale ≈ 1.07）；**无阴影、无光晕、无卫星点**；选中**标签永不隐藏** |
| M-2 | **悬浮 / 聚焦进入与离开** | 0 / 60 / 120 ms 三帧 | 进入 = 基线 **+1px** 环宽、颜色走更实的一档；离开 = 回到基线；**不改选中态**（悬浮 ≠ 选中） |
| M-3 | **投影切换**（关系结构 → 学习状态） | 0 / 100 / 250 / 500 ms 四帧 | 节点配色与**图例下半的节点颜色键同步**换；量值 → 尺寸的映射**在整段过渡里保持单调**；圆心数字**不变**（仍是正式题数） |
| M-4 | **状态筛选**（成员进出） | 0 / 100 / 300 / 600 ms 四帧 | 离场节点**淡出**（不变色）；存活节点形态与配色**不变**；边的保留规则与现状一致 |
| M-5 | **标签让位**（重叠发生时） | 0 / 80 / 200 ms 三帧 | 只隐藏**次要**标签（按大小与重要度排序）；被隐藏者完整标题仍可由**悬浮 / 键盘聚焦**取到 |
| M-6 | **底噪改绘制方式**后的首帧 | 0 / 100 / 1000 ms 三帧 | 首帧即有底噪；1000ms 后**不再每帧重绘**（性能断言见 §3.4）；观感与改造前同档 |

**通用判据**：所有过渡只用 `transform` / `opacity` / `stroke-width`；
`prefers-reduced-motion` 下全部降级为状态直切（M-1…M-6 各出一张降级对照帧）。

## 3. 交互清单（逐条可勾选）

### 3.1 键盘可达
- [ ] 每个可交互控件在键盘 Tab 时都有**可见焦点环**（不得被 `outline:none` 压死）
- [ ] 节点可由键盘聚焦；聚焦态与悬浮态**同一种**强调（G-15），且**不改变选中态**
- [ ] 被隐藏的次要标签，其完整标题可由**键盘聚焦**取到（G-5 / A-10.3）
- [ ] 节点图谱的 DOM 仍是**可访问性与交互的载体**（`workbench-ui:123`、`:205-208`）——
      只换画法，不换归属（D-13 第 7 项）
- [ ] 页面转场与浮层出现时，焦点不被抢走

### 3.2 悬浮
- [ ] 悬浮某节点 → 外环加粗 + 颜色更实 + 节点轻微放大；**不出现阴影与光晕**
- [ ] 悬浮**不改变**选中态
- [ ] 悬浮的节点若是次要标签的宿主，完整标题可由悬浮取到

### 3.3 投影切换
- [ ] 四个投影都能切；切换后节点配色与**图例颜色键同步**（G-11 / G-14）
- [ ] 圆心数字在**所有投影**下都是正式题数（G-9）
- [ ] 量值 → 尺寸的映射在每个投影里都**单调**
- [ ] 关系结构投影下节点色为**墨阶三档**（不承载语义，G-22）

### 3.4 状态筛选
- [ ] 筛选**只改成员、不改外观**：存活节点保持同心圆形态与当前投影配色；离场节点淡出而不变色
- [ ] 筛选**不新增状态通道**（不额外加色 / 加标 / 加几何）
- [ ] 筛选语义不变：可选状态集合、可见节点的并集、边的保留规则、筛选状态仍是页面级
- [ ] 筛选**不发新请求**、不写池

### 3.5 可读性与对比度
- [ ] **缩放补偿后**每个节点的外环、圆心数字与标签**不缩放即可读**
- [ ] 节点内区**可见填充**（不是空纸）
- [ ] 标签对比度 ≥ 4.5:1（夜色下同样达标）
- [ ] 夜纸下节点填充、外环、关系线、标签在深底上**均可读**
- [ ] 黄色 / 琥珀等低对比色**不承载文字**（沿用全站口径）

### 3.6 性能
- [ ] 底噪**不再每帧重绘约 600 个 alpha 混合色斑**（改为静态预渲染或降频，D-9）
- [ ] 节点绘制不因缩放补偿而引入每帧重排（尺寸在绘制时确定，不进 layout 热路径）
- [ ] 长时间停留时帧率与改造前相当（底噪改法不得把开销挪到别处）

### 3.7 零全局依赖（图谱区段自足）
- [ ] 图谱 CSS 区段**零**引用 `var(--lk-*)` / `var(--dsw-*)`（C-8 的 L1 自足性）
- [ ] 图谱的 12 个裸名 token 已改名为 `--graph-*` 且**区段外引用 0 次**（D-12.1）
- [ ] 新增的夜纸块限定在图谱作用域内，不外泄到其它页面
