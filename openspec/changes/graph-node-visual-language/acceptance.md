# 验收清单 — graph-node-visual-language

> 本文件是**本变更自带的验收基线**（**所有者裁决 A-12**，`decisions.md`）。
> 验收方式与 v2 同构：**对照截图 + 关键帧序列 + 交互清单**三件套；
> 但**判据不同** —— 本变更的判据是**结构不变量 + 算法冻结**，不是「亮色逐像素不变」。
>
> 相关：`proposal.md`（范围与冻结）、`design.md`（实现方案，D-12.3 / D-13 / D-14.5）、
> `../workbench-visual-language-v2/decisions.md`（A-24 / A-26 / **A-28** / A-7 / A-8 / A-10 / A-12）、
> `../workbench-visual-language-v2/design-notes/graph-isolation.md`（实测事实与比对协议 §6）、
> `tmp/frontend-audit/OBSIDIAN-GRAPH.md`（**Obsidian 官方源码实测的图谱渲染规格**）。
>
> **为什么本文件存在（必读）**：
> v2 的 `acceptance.md` G-5 写的是「图谱页未被本变更触碰（否定式断言）… 差异像素数 = 0。
> 图谱**不在该变更的验收范围内**」——**那条只对 v2 有效**。
> 本变更存在的目的就是重画节点，因此：
> - **不引用** v2 的 G-5 作为本变更的门禁（那是一条对本变更并不存在的断言）；
> - **「亮色逐像素不变」按 A-12 从图谱的约束里拿掉**（节点本来就要重画；
>   A-24 整个换掉了形态，**A-28 又把半径区间定案为 5–13 屏幕 px**
>   ⇒ 与「逐像素一致」物理互斥）；
> - 本文件**自带**基线：**结构不变量必须成立**，**四个声明区允许变化**，
>   **并且图谱算法必须逐位不动**（**SI-0**）。
>
> **被验收的形态（**A-24 决策链 + **A-28 的 Obsidian 源码实测参数**）**：
> 单层实心圆点（半径 **5–13 屏幕 px**、无描边无投影无光晕）、
> 标签在**点下方 5px**、**12 屏幕 px 恒定**、**缩放 < 0.5 时按对数淡出**、
> 关系线**屏幕恒定 1.25px** + **方向箭头**、**非邻接元素 alpha 0.2**、
> 圆心数字**按投影决定**、选中态 = **换色 + 1px 描边环 + 点放大 + 标签提亮**。

## 0. 底线守卫（最高优先级，先于其它任何检查）

### 0.1 底部守卫：请求与持久化不变（沿用 v2 的 G-1…G-4 口径）

> 冻结项：**请求与持久化不变**。冻结 = API 请求序列与载荷、持久化内容、学习事实、
> 状态机、由请求驱动的可见性切换。本变更**不写产品代码之外的后端**，
> `pool/` `pipeline/` `workbench/data/` 一行不动（`proposal.md`「不改」段）。

| # | 检查项 | 判定方法 | 通过标准 |
|---|---|---|---|
| G-1 | 图谱页的**请求序列**不变 | 在池副本上脚本化走一遍图谱页（进页 → 切投影 → 搜索 → 筛选 → 选中节点 → 拖拽 → 缩放 → Fit），记录服务端收到的**请求方法 + 路径 + 载荷键集合**；改造前后各跑一次并 diff | 序列与载荷**逐条相同**；新增 / 删除 / 改名任意一条即 FAIL |
| G-2 | 图谱的**持久化结果**不变 | 同一次脚本化走查前后，比对池中 `problem_attempts` / `feedback_events` / `practice_runs` 的行数与关键列 | 行数与关键列**逐行相同** |
| G-3 | **学习投影不变** | 同一份脚本化走查前后，比对受影响知识点 / 题目的当前状态与调度行 | 完全相同 |
| G-4 | **复习建议集合不变** | 比对改造前后同一时刻的到期项集合与弱项排序 | 集合与顺序**完全相同** |
| G-5 | **无新增学习事实** | 人工核对：本变更的图谱改动只落在 `workbench.css` 图谱区段、图谱 JS 与 `pages.py` 图谱页 | 池 schema **零变更**；`workbench-ui` / `review-workbench` 的既有能力未被改写（除本变更 delta 显式 MODIFIED 的 6 条） |

> 〔沿用 v2 口径〕G-1…G-4 的脚本要**同时**用于改造前与改造后，且跑在**池副本**上（见 §5）。
>
> 〔与 v2 的差别〕v2 的 G-5 是「图谱未被触碰」的**否定式断言**；
> 本文件的 G-5 是「**无新增学习事实**」的**底线断言** —— 两者不是同一条门禁。

### 0.2 结构不变量清单（本变更的硬门禁，判据核心）

> 〔A-12〕以下 **SI-0…SI-5** **必须全部成立**。任何一条不成立 ⇒ 本变更 FAIL，
> **不得**用「视觉上更好」抵扣。
>
> **SI-0 是本变更最重的一条**：它是 A-26「不要动图谱的算法」这句话的**可执行形式** ——
> **改造前后，同一份输入的力导向收敛坐标必须逐项一致（diff = 0）**。

| # | 不变量 | 判定方法 | 通过标准 |
|---|---|---|---|
| **SI-0** | **图谱算法冻结：改造前后收敛坐标 diff = 0**（A-26 的可执行判据，**与 SI-1…SI-5 并列的核心门禁**） | 用第 14 组的对比脚本：取同一章节（dmath/ch06）的图谱模型，**清空** `lk_graph_layout_v1_<workspace>`（`graph-physics.js:43-48`）后**从零求解**（同一初始条件、同一迭代预算），等收敛（`#graph-solver-state` 不再带 `.solving` 且 DOM 静止签名连续 N 次不变），导出每个节点的 `(id, x, y)`；**改造前后各跑一次**（基线 JSON 在任何产品代码改动之前存档） | 节点 id 集合差集为空；**逐节点的 `x / y` 差值严格为 0**（**不是**「≤0.1px」—— 那条是 SI-3 的口径，用于「同一实现重跑两次」的确定性；SI-0 是**跨实现**比较，必须严格 0）。**diff ≠ 0 ⇒ 立刻按 `git diff` 定位越界改动并回退**（`tasks.md` 14.5）。证据：baseline / after / diff 三份 JSON + 复跑命令入库 |
| **SI-1** | **节点集合不变** | 取图谱页渲染完成后的节点 id 全集（DOM `.node-wrap` 的 `data-*` / 后端返回的节点清单），改造前后各取一次并求差集 | 节点 id 集合**完全相同**（数量、内容皆同）；新增 / 减少 / 改名任一节点即 FAIL。依据：A-26「DOM 节点的身份与顺序」冻结；实现入口 `workbench.js:957-1053` `graphCreateNodes()` |
| **SI-2** | **关系边集合不变** | 取 WebGL 关系线的拓扑（source / target / type / direction 四元组全集；类型集合见 `workbench-ui:662-678`），改造前后各取一次求差集 | 边四元组集合**完全相同**；不得新增、删除或改类型 / 改方向。依据：A-26「邻接与边集合 / 边的类型与权重」冻结；A-24.3 只改**画法**（线宽 / 透明度 / 箭头 / 端点落点） |
| **SI-3** | **力导向布局的收敛性与确定性** | ① 收敛：等 `#graph-solver-state` **不再带 `.solving` 类**（`workbench.js:719`）且 DOM 静止签名连续 N 次不变（`graph-isolation.md` §6.4 的等待谓词）后，取每个节点的归一化坐标；② 确定性：**清空 `lk_graph_layout_v1_<workspace>`**（`graph-physics.js:43-48`）后**重跑两次从零求解**，取同一批坐标 | ① 布局**必须收敛**（`graph-physics-core.js:1246` alpha 衰减 → `:1255` 连续 15 帧稳定 → `:1260` `settled = true`）；② 两次从零求解的坐标**逐节点相同**（允许 ≤0.1px 的存储取整误差，同 `graph-isolation.md` §6.3 N-3 口径） |
| **SI-4** | **投影语义不变** | 四个投影（关系结构 / 题目数量 / 重要性 / 学习状态）各自的取值来源与判读含义不得改变：取 `graph-physics-core.js:1463-1470` `scoreFor()` 对同一批节点算出的值，与 `workbench.js:1055-1061` `graphProjectionDisplay()` 的显示映射 | ① 四个投影**都还在**、**含义不互换**（关系结构投影仍不承载量值语义，见 G-22）；② 同一节点在同一投影下的量值**相同**；③ 量值 → 视觉的映射是**单调**的，改动只落在**取值区间**（**5–13 屏幕 px**，A-28）与**色键**（G-7 / G-16 / G-20…G-22），不落在**排序**上；④ **圆心数字按投影决定**（关系结构 / 学习状态**无数字**；题目数量 / 重要性**有数字**）—— 这是**画法**的分工，不是投影语义的改变 |
| **SI-5** | **交互行为不变** | 逐项对照 `workbench-ui:121-248` 与 `pages.py:410-481`：搜索、筛选、缩放、平移、Fit、拖拽、聚焦、聚拢滑杆、详情看板的**触发方式、结果、可见性切换** | ① 每个交互的**结果与改造前一致**（同一操作落到同一状态）；② **不得新增**任何由本变更引入的交互态；③ 筛选**只改成员、不改外观**（存活节点保持**单层实心圆点**形态与当前投影配色，离场节点淡出而不变色）—— 见本变更 delta 的 `Multi-state graph filtering` MODIFIED 块；④ **淡化的强度变了但语义没变**（非邻接元素 alpha 0.07 → 0.2 是**绘制层**；**谁被强调、谁被压暗**不变） |

> 〔边界〕SI-1…SI-5 是**结构**。**节点 / 标签 / 图例 / 底噪这四个区域不在此列** ——
> 它们是本变更要改的东西，判据见 §0.3。

### 0.3 允许变化区清单（节点 / 标签 / 图例 / 底噪）及其判据

> 〔A-12〕这四个区域**允许变化**。但「允许变化」≠「可以乱改」：
> 每一条都给出**必须仍然成立**的判据。比对截图的差异像素集合必须 **⊆**
> 这四个区域的包围盒并集（`design.md` D-12.3）。

| # | 允许变化区 | 本变更改了什么 | 判据（**仍然必须成立**） |
|---|---|---|---|
| **AV-1** | **节点区**（`.node-wrap` / `.node` / `.node-dot` / `.node-focus-ring` / `.node-value`，`workbench.css:1643-1719`） | 形态：五层信息挤在一个圆 → **单层实心圆点**（A-24.1 / **A-28.1**：无描边、无投影、无内高光、无渐变、无 halo 可见痕迹）；删除 `.metric-track` 度量弧（G-2）；删除节点上的状态文字（G-6 / A-24.5）；**圆心数字按投影决定**（结构 / 状态无数字；题量 / 重要性有数字，A-24.4 / A-28）；绘制半径 **5–13 屏幕 px**、**与物理半径解耦**（D-3 / A-26）；缩放补偿：尺寸按**屏幕像素**而非世界像素（D-1 / G-24 / A-28.2）；选中 / 悬停 = **换色 + 1px 描边环 + 放大 + 标签提亮**（D-8 / A-28） | ① 节点**数量与 id** 不变（SI-1）；② 节点的**位置**不变（SI-3 / SI-0）；③ 圆心数字**按投影决定**：结构 / 状态投影**没有数字**，题量 / 重要性投影的数字 = 该投影的量（**题量 = 正式题数**，**重要性 = round(importance×100)**，**不含 %**）；④ 节点上**不得出现任何状态文字**（G-6 / A-24.5）—— 状态名只许出现在学习看板、悬浮提示与无障碍名里；⑤ 量值 → 尺寸的映射**单调**，区间落在 **5–13 屏幕 px**（两个数值投影**随量映射**、下限 6.5px / 直径 13px，见 D-3.4 / **A-34** —— **不是**恒 13px）；⑥ **常态点没有描边、没有投影、没有光晕**（截图逐点可查）；⑦ 缩放补偿后**每个节点的点、数字与标签都可读**（不缩放即可读）；⑧ **物理半径未变**（`sizeFor()` 零改动，SI-0 的前提） |
| **AV-2** | **标签区**（`.label` / `.meta`） | 常态可见但不抢眼：字号 12 屏幕 px **恒定**、**不截断**（换行显示全文）、降低对比度（A-10.3 / G-5）；**位置 = 点下方 5px**（A-28）；**缩放 < 0.5 时按对数淡出**（A-28）；删除 `.meta` 行（G-6）；标签重叠时**自动隐藏次要标签**（按节点大小与重要度排序让位，G-23）—— 取代「按缩放阈值隐藏」 | ① 标签**默认可见**，判据从「缩放阈值」改为「**重叠让位 / 超出可见标签预算**」（G-23）；② 标签**不截断**，完整标题由**悬浮 / 键盘聚焦**可达（G-5 / A-10.3）；③ 标签字号为**屏幕像素**语义且**恒定 12px**（D-6 / D-1）；④ 标签**基线/顶边**与点**不重合**，且**点下缘到字顶 = 5 屏幕 px**（A-28）；⑤ 标签对比度**低于**节点自身填充（不抢节点）但**可读**；⑥ 隐藏的必须是**次要**标签（按大小与重要度排序让位），不得随意隐藏；⑦ **缩放 < 0.5 时按对数淡出**（默认 Fit 视图下 alpha = 1），不是继续缩小，也不是硬阈值隐藏 |
| **AV-3** | **图例区**（`.legend-*`，`workbench.css:1780-1799`） | 图例分两块：上半保留关系线型（现状）**并给有向的两项补箭头符号**，下半为**节点颜色**并**随投影切换**（G-14 / G-11 / A-24.3） | ① 图例**两块**都在；② 下半的节点颜色键**与当前投影**严格对应（G-11：必须有「什么颜色对应什么类型」的标注，且随投影切换）；③ 上半关系线型**保留现状**（`workbench-ui:662-678`），且**箭头符号与画布上实际画出的箭头一一对应**（A-24.3 的箭头语义被钉在图例上）；④ 图例「相关」色与 WebGL 实况**一致**（现状 `#aaa399` vs 实况 `rgb(117,112,104)` 是缺陷，本变更修好） |
| **AV-4** | **底噪画布区**（`.graph-tide`） | **保留观感**（G-4：所有者「其实那个还挺好看的」），只改**绘制方式**：每帧约 600 个 alpha 混合色斑 → **静态预渲染 / 降频**（D-9） | ① 底噪**仍在**（不得整体删掉）；② 观感**仍读作极淡的纸纹底噪**；③ 不再每帧重绘 600 个色斑（性能断言见 §3.6）；④ 底噪**不承载任何数据语义**（它与图谱数据完全无关，只在节点周围挖洞） |

> 〔比对口径〕差异像素集合 **⊆**（节点区 ∪ 标签区 ∪ 图例区 ∪ 底噪画布区）；
> 遮罩由 DOM 的 `getBoundingClientRect` 在截图时导出，作为比对脚本的输入（`design.md` D-12.3 代价段）。
> **落在遮罩之外的任何一个差异像素 ⇒ FAIL。**

**比对方式**：同尺寸并排；节点 / 标签 / 图例 / 底噪四区**允许**变化，
但变化必须**落在 §0.3 的判据内**；**遮罩之外零差异**。文字内容（节点名、图例文字）
除本变更显式改动（G-6 删状态文字、AV-3 图例「相关」色修好）外应逐字一致。

### 1.3 比对的前置固定（沿用 `graph-isolation.md` §6.2 / §6.3）

| 项 | 取值 | 为什么 |
|---|---|---|
| 视口 | **1440 × 900** | 与 v2 `acceptance.md` §1 统一；三栏全展开，无抽屉 |
| `deviceScaleFactor` | **= 1** | `graph-renderer.js:189` dpr 夹在 1..2；dpr 不一致 ⇒ WebGL backing store 与 tide canvas 分辨率不同 |
| 浏览器缩放 | 100%，不叠加系统缩放 | 同上 |
| WebGL | headless Chromium 固定 flag `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`（或两次都用同一块真 GPU） | 软件光栅化确定性 ≠ 真 GPU；**两次必须同一种** |
| 动效 | `prefers-reduced-motion: reduce` | 冻结 N-1（tide 时间驱动）与 N-2（Worker 迭代）的确定性 |
| 字体 | 截图前等 `document.fonts.ready` | 避免 fallback / swap 两种渲染并存 |
| 布局种子 | **两次都用全新浏览器上下文**（清 `lk_graph_layout_v1_<workspace>`） | 强制两次都走「从零求解」同一条路径（`graph-physics.js:358` 的采纳缓存分支会差 0.1px） |
| 数据 | **池数据库副本 + 隔离注册表 + 独立端口**；两次用**同一份**副本快照 | 见 §5 |
| 滚动位置 | 强制 `window.scrollTo(0, 0)` 并在截图前断言 | 中栏不滚动，但文档本身仍可能滚动 |
| 缓存 | 每次导航前 `clearCookies()` + 关缓存，或 URL 加 `?v=<timestamp>` | `app.py:214-232` 不发 `Cache-Control` / `ETag`，启发式缓存可能遮蔽新 CSS |

**先自证基线可复现**（沿用 **A-14** 的顺序：**先试最严 → 不可复现才降级 → 降级必须留痕**）：
正式比对前，先连跑**两次改造前**基线截图并互比。
若基线自身不可复现，则把「基线不可复现」作为一条**待裁决**项**登记**，
而不是默默放宽标准；本变更侧对应 SI-3 的「两次从零求解坐标必须相同」
与 **SI-0 的「改造前后 diff = 0」**。

## 2. 关键帧序列清单

> 动效不能只靠截图验收（截图看不到运动）。每个动效采一组帧，拼成一条**分镜条**。
>
> **〔范围说明〕** **台灯转场（涟漪）不涉及图谱** —— 台灯是 v2 的全站主题转场，
> 图谱的夜纸适配是**值集切换**（`html[data-theme="night"]` 下的 token 重声明），
> 不参与涟漪扩散。本变更的关键帧只覆盖**节点自身**的状态过渡。

| # | 过渡 | 采样帧 | 通过标准 |
|---|---|---|---|
| M-1 | **节点选中** | 0 / 60 / 120 / 200 ms 四帧 | **换色 + 1px 描边环 + 点放大**（scale ≈ 1.12）+ **标签提亮**（字重 700）；**无阴影、无光晕、无卫星点**；选中**标签永不隐藏**；**世界坐标不变**（只改绘制） |
| M-2 | **悬浮 / 聚焦进入与离开** | 0 / 60 / 120 ms 三帧 | 进入 = 换色 + 1px 环 + 放大（scale ≈ 1.06）+ 标签提亮；离开 = 回到基线；**不改选中态**（悬浮 ≠ 选中） |
| M-3 | **投影切换**（关系结构 → 学习状态） | 0 / 100 / 250 / 500 ms 四帧 | 节点配色与**图例下半的节点颜色键同步**换；量值 → 尺寸的映射**在整段过渡里保持单调**；**圆心数字按投影决定**（切到学习状态后**数字消失**） |
| M-4 | **状态筛选**（成员进出） | 0 / 100 / 300 / 600 ms 四帧 | 离场节点**淡出**（不变色）；存活节点形态与配色**不变**；边的保留规则与现状一致 |
| M-5 | **标签让位**（重叠发生时） | 0 / 80 / 200 ms 三帧 | 只隐藏**次要**标签（按大小与重要度排序）；被隐藏者完整标题仍可由**悬浮 / 键盘聚焦**取到 |
| M-6 | **底噪改绘制方式**后的首帧 | 0 / 100 / 1000 ms 三帧 | 首帧即有底噪；1000ms 后**不再每帧重绘**（性能断言见 §3.6）；观感与改造前同档 |

**通用判据**：所有过渡只用 `transform` / `opacity` / `color`；
`prefers-reduced-motion` 下全部降级为状态直切（M-1…M-6 各出一张降级对照帧）。

## 3. 交互清单（逐条可勾选）

### 3.1 键盘可达
- [ ] 每个可交互控件在键盘 Tab 时都有**可见焦点环**（不得被 `outline:none` 压死）
- [ ] 节点可由键盘聚焦；聚焦态与悬浮态**同一种**强调（换色 + 1px 环 + 放大 + 标签提亮），且**不改变选中态**
- [ ] 被隐藏的次要标签，其完整标题可由**键盘聚焦**取到（G-5 / A-10.3）
- [ ] 节点图谱的 DOM 仍是**可访问性与交互的载体**（`workbench-ui:123`、`:205-208`）——
      只换画法，不换归属（D-13.1 第 13 项）
- [ ] 页面转场与浮层出现时，焦点不被抢走

### 3.2 悬浮
- [ ] 悬浮某节点 → 换色 + 1px 描边环 + 点轻微放大 + 标签提亮；**不出现阴影与光晕**
- [ ] 悬浮**不改变**选中态
- [ ] 悬浮的节点若是次要标签的宿主，完整标题可由悬浮取到

### 3.3 投影切换
- [ ] 四个投影都能切；切换后节点配色与**图例颜色键同步**（G-11 / G-14）
- [ ] **圆心数字按投影决定**：关系结构 / 学习状态**没有数字**；题目数量 / 重要性**有数字**且等于该投影的量
- [ ] 量值 → 尺寸的映射在每个投影里都**单调**（结构 / 状态投影落在 5–13px；两个数值投影**随量映射**、下限 6.5px / 直径 13px，**A-34** —— 不是恒 13px，数字可读优先）
- [ ] 关系结构投影下节点色为**墨阶三档**（不承载语义，G-22）

### 3.4 状态筛选
- [ ] 筛选**只改成员、不改外观**：存活节点保持单层实心圆点形态与当前投影配色；离场节点淡出而不变色
- [ ] 筛选**不新增状态通道**（不额外加色 / 加标 / 加几何）
- [ ] 筛选语义不变：可选状态集合、可见节点的并集、边的保留规则、筛选状态仍是页面级
- [ ] 筛选**不发新请求**、不写池

### 3.5 可读性与对比度
- [ ] **缩放补偿后**每个节点的点、圆心数字与标签**不缩放即可读**
- [ ] 节点是**实心填充**（不是空纸、不是描边环）
- [ ] 标签对比度 ≥ 4.5:1（夜色下同样达标）
- [ ] 夜纸下节点填充、圆心数字、关系线、标签在深底上**均可读**
- [ ] 黄色 / 琥珀等低对比色**不承载文字**（沿用全站口径）
- [ ] **圆心数字**对点填充 ≥ 4.5:1（亮纸 4.60–9.03 / 夜纸 4.78–8.62）

### 3.6 性能
- [ ] 底噪**不再每帧重绘约 600 个 alpha 混合色斑**（改为静态预渲染或降频，D-9）
- [ ] 节点绘制不因缩放补偿而引入每帧重排（尺寸在绘制时确定，不进 layout 热路径）
- [ ] 长时间停留时帧率与改造前相当（底噪改法不得把开销挪到别处）

### 3.7 零全局依赖（图谱区段自足）
- [ ] 图谱 CSS 区段**零**引用 `var(--lk-*)` / `var(--dsw-*)`（C-8 的 L1 自足性）
- [ ] 图谱的 12 个裸名 token 已改名为 `--graph-*` 且**区段外引用 0 次**（D-12.1）
- [ ] 新增的夜纸块限定在图谱作用域内，不外泄到其它页面
