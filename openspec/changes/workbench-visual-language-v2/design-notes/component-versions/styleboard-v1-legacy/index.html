lesson-kit 工作台 · 视觉样板板（候选对比页）

本页把「柔和蒙德里安 v2」精修的视觉候选并排画出来，供产品所有者直接肉眼比较与挑选。它不是产品代码，只是一块静态对比板。

这是什么：25 组视觉决策的候选对照表（01–17 仿古纸感方向，18–25 现代圆润方向）。每组第一张卡固定是现状（当前线上真实值），其余是候选 A/B/C…。
怎么用：每张卡右下角是具体数值（色值 / px / 占比），对着数值投票，不用凭感觉；卡片里是真排版的样例（真文字，不是色块），差别只有放进真实排版才看得出。
怎么选：先看现状卡，再逐个候选比；优先选「差别看得见、但阅读不变差」的那个。
字体：本页用系统中文字体栈只为方便对比；正式版阅读面会用衬线（题面 / 知识点正文 / 解析），界面面仍是无衬线。
范围：本页只讨论工作台视觉；知识图谱页完全不在范围内。
新方向提示：18–25 组是「现代圆润（多邻国式）」方向，与前 17 组并存不互斥；其中第 20 组（多色）与第 24 组（全无衬线）会主动违反现行契约，已在组内标注，采纳前需另开 OpenSpec 变更。
