## 1. 统一 SVG 技术规格

> 以下条款对**全部**资产（图标 / 插画 / 台灯）生效。除非某一项另有明文说明。

### 1.1 画布与网格

| 资产类 | `viewBox` | 画幅（u） | 默认渲染尺寸（CSS px） | 1 u = |
|---|---|---|---|---|
| 导航图标 | `0 0 48 48` | 48 × 48 | 24 × 24 | 0.5 px |
| 空态插画 | `0 0 240 200` | 240 × 200 | 宽 180（高 150） | 0.75 px |
| 台灯 | `0 0 240 200` | 240 × 200 | 宽 180 | 0.75 px |

- **u（unit）** 是本文件的唯一长度单位。所有坐标、线宽、半径都以 u 给出，实现时乘以上表的换算。
- 网格：
  - 图标：**12 × 12 单元**，1 单元 = 4 u = 2 CSS px。部件端点尽量落在整单元或半单元上。
  - 插画 / 台灯：**24 × 20 单元**，1 单元 = 10 u = 7.5 CSS px。允许半单元偏移（手绘感），但**不得**出现 1–3 u 的随机抖动。
- 安全区：
  - **图标**：图形外接框 ≤ 32 × 32 u，且必须整体落在以 (24, 24) 为心、**半径 16 u 的内切圆**内
    （图形最大占圆底直径的 67%）。四周必须留出呼吸空间——图标挤满圆底会变成"贴纸"。
  - **插画**：主体（器物本体）高度占画幅 45%–58%；主体水平居中；底部 9%–12% 是桌面横线与其下留白；
    左右留白 ≥ 画幅宽的 22%。
- `preserveAspectRatio` 保持默认 `xMidYMid meet`；**禁止** `slice`（会裁掉笔画）。

### 1.2 线宽阶

全组**同一组数值阶梯**，图标与插画共用（渲染尺寸不同，阶梯结构相同）：

| 档 | u | 图标 @24px | 插画 @180px | 用途 |
|---|---|---|---|---|
| **主** | 3 | 1.5 px | 2.25 px | 形体外轮廓、封面、器物主壁 |
| **次** | 2 | 1.0 px | 1.5 px | 内部结构线、书脊、部件分界、连接线 |
| **细** | 1.5 | 0.75 px | 1.125 px | 纹理：页行、叶脉、灯罩棱 |

- 线宽比恒为 **3 : 2 : 1.5**。不得出现第四档。
- 每张资产**最多用三档**；用不到某档就不用，但不得自造新值。
- 角色分工：结构轮廓 = 主线；内部结构 = 次线；纹理 = 细线。
- **细线（1.5 u）在图标尺寸下是 0.75 CSS px**：只允许出现在"删掉也不损失识别"的位置。
  若在目标浏览器里发虚，**把该处升到次线并同时删掉冗余纹理**，不得加粗到主线。
- **禁止**：hairline（< 1 u）、超粗线（> 4 u）、同一形体上混用两档线宽。

### 1.3 端点与连接

- 全组统一：`stroke-linecap="round"`、`stroke-linejoin="round"`。
  可写在最外层 `<g>` 上继承，**不要**每个 path 重复写。
- **禁止** `butt` 端点、`miter` 连接、`stroke-miterlimit`。
- `stroke-dasharray` 仅允许用于"图谱的虚线连接"这一处语义，且虚线节奏为 `4 3`（u）。

### 1.4 圆角档

圆角语言 = **局部短边的比例**，与界面 12px 圆角是同一种"语气"的不同尺度
（界面 12 px 是"不小于所作用边长的 1/16、且不用小圆角"；资产内部用比例表达同一件事）。

| 档 | 比例（局部短边） | 图标参考值 (u) | 插画参考值 (u) | 典型用途 |
|---|---|---|---|---|
| **锐** | 0 | 0 | 0 | 纸边、笔尖、硬折线、裁切边 |
| **微** | 1/16 | 1.5 | 4 | 小构件角：纸角、笔筒口沿、书签缺口 |
| **小** | 1/10 | 3 | 8 | 次级形体：书页、灯罩口、杯沿、画框内缘 |
| **中** | 1/6 | 6 | 16 | 主形体：书封面、笔记本、画布框、台灯底座 |
| **大** | 1/4 | 8 | 20 | 大件柔性形体：果篮、花瓶腹、灯罩外沿 |

- 规则：
  1. 任何角都不是直角；除"锐"档的明确纸边外，至少给到"微"。
  2. 主形体用"中"（1/6），次级用"小"（1/10），细节用"微"（1/16）。
  3. 自由曲线（杯口、篮沿、花器口、灯罩口）不设限，由造型自然决定。
  4. 同一套资产里，同类部件的圆角档必须一致（五个图标的"主形体圆角"必须读起来是同一种）。

### 1.5 描边与填充的关系

- **描边优先**：形体用「描边 + 透明或极淡填充」表达。
- 填充只承担三件事，且仅此三件：
  1. **淡彩晕染**（低透明度色面）；
  2. **彩色圆底**（仅图标）；
  3. **高光 / 亮部**（极小面积）。
- **禁止**「大面积实心填充 + 粗描边」的贴纸感。同一形体上，描边相对填充的对比度必须 ≥ 3:1
  （可用 §1.7 的取值直接验算）。
- 淡彩填充的透明度：暖纸 8%–18%，夜纸 6%–14%。晕染**不得盖过墨线**——永远先铺淡彩、后描线。
- **阴影**：
  - **禁止 SVG filter**（`feGaussianBlur` / `feDropShadow` / `feTurbulence` 一律不用）。
  - 柔影 = 「同形复制 + 2 u 偏移 + 3%–6% 不透明度 + 深一档色相」。
  - 接触阴影 = 一条 3–5 u 宽的横向淡色带（放在器物底下）。
- **禁止** `clipPath` 做复杂裁剪。需要裁切时优先直接画 `circle` / `rect rx` / 带 `Z` 的闭合路径。

### 1.6 淡彩与渐变语言

渐变**只允许出现在资产内部**（`decisions.md` §14.3），不得用于背景、卡片或任何大面积表面。
全组只允许下面 **4 组**渐变，方向统一 **135°**（`objectBoundingBox`，`x1=0 y1=0 x2=1 y2=1`）：

| id 前缀 | 类型 | 停靠点 | 用途 |
|---|---|---|---|
| `gWash` | linear 135° | 3 点：offset 0 / 0.5 / 1，`--asset-wash-*`，alpha **0.20 / 0.10 / 0.02** | 淡彩晕染 |
| `gLight` | linear 135° | 2 点：offset 0 / 0.9，`--asset-highlight`，alpha **0.40 → 0** | 克制高光 |
| `gRole` | linear 135° | 3 点：offset 0 / 0.55 / 1，角色色提亮 6% / 原色 / 压暗 8% | 彩色圆底（**可选**，默认纯色） |
| `gLamp` | radial（中心 50%/50%，r 50%） | 2 点：offset 0 / 1，`--asset-lamp-glow`，alpha **0.55 → 0** | 台灯暖光晕 |

- 同一资产内渐变**≤ 2 组**。
- 渐变不得越出形体边界（需要时用同形闭合路径承载，而不是裁剪）。
- **夜纸不新建渐变**：同一 `<linearGradient>` 只换停靠点色阶（更暗的色相 + 更弱的高光），
  色阶由 CSS 变量给（§1.7），`gradientTransform` 不动。

### 1.8 命名、id 命名空间与文件组织

**目录结构**（新增，位于既有静态目录之下；`/static/` 路由与 `.svg` 的 MIME 已就绪
——`workbench/server/app.py:136-137`、`:29`）：

```
workbench/server/static/assets/
├── icons/                     导航静物图标（5）
│   ├── icon-practice.svg
│   ├── icon-practice-sets.svg
│   ├── icon-kps.svg
│   ├── icon-graph.svg
│   └── icon-records.svg
├── empty/                     空态静物插画（10）
│   ├── empty-vase.svg
│   ├── empty-fruit-basket.svg
│   ├── empty-canvas.svg
│   ├── empty-cup.svg
│   ├── empty-books.svg
│   ├── empty-pen.svg
│   ├── empty-pencil-cup.svg
│   ├── empty-globe.svg
│   ├── empty-inkwell.svg
│   └── empty-compass.svg
└── motion/
    └── lamp.svg               台灯（单文件三姿态）
```

**文件名规则**：`<kind>-<subject>[-<qualifier>].svg`，全小写 kebab-case。

| kind | 含义 |
|---|---|
| `icon` | 导航静物图标（圆底徽章式） |
| `empty` | 空态静物插画 |
| `lamp` | 台灯（motion 类唯一资产） |

**SVG 内部 id 命名空间**：所有 `id`（渐变、组）**必须**带资产前缀，
形如 `icon-practice-wash`、`empty-vase-gLight`、`lamp-gLamp`。
理由：资产以 inline 方式进入同一文档，重复 id 会让 `url(#id)` 指到别的资产的定义。
**禁止**出现裸 id（如 `id="wash"`）。

**根元素约定**：

```xml
<svg viewBox="0 0 48 48" class="asset asset-icon" xmlns="http://www.w3.org/2000/svg"
     role="img" aria-labelledby="...">
  <title>练习</title>
  <defs>…</defs>
  <g class="asset-icon__ground">…</g>
  <g class="asset-icon__art">…</g>
</svg>
```

- 不写死 `width` / `height`，尺寸由宿主 CSS 的 `.asset-icon` / `.asset-empty` 控制。
- 必须写 `xmlns`（独立打开时也要合法）。
- 必须有 `<title>`（见 §5.5）。

### 1.9 class / `currentColor` / CSS 变量的用法规则

| 用途 | 用什么 | 不用什么 |
|---|---|---|
| 主题适配（暖纸 ↔ 夜纸） | **CSS 变量** `var(--asset-*, fallback)` | 不用 `prefers-color-scheme` 媒体查询（主题偏好是工作区级的浏览器偏好，不是系统级） |
| 跟随宿主文字色 | `currentColor`（仅限"跟随上下文文字"的装饰件） | 不用硬编码 hex |
| 颜色回退 | `var(--asset-ink, #221f1a)`，**每个 `var()` 都带回退值** | 不写无回退的 `var()` |
| 结构分组 | 语义 class：`__ground` / `__art` / `__wash` / `__line` / `__highlight` | 不写行内 `style="fill:#xxx"` |

- **禁止**在 SVG 里写 `style` 属性、`class` 里塞颜色、`<style>` 块内定义颜色。
- 颜色只能出现在两处：`fill` / `stroke` 属性上的 `var(--asset-*)`，
  或 `<stop stop-color="var(--asset-*)">`。
- 主题切换时**只换变量值，不重画资产、不新增资产**（`acceptance.md` §3.2）。

### 1.10 交付形态：inline 是硬要求

- 资产必须以 **inline `<svg>`** 进入 DOM：
  - 服务端模板内联（读文件内容注入 HTML），**或**
  - 前端 `fetch('/static/assets/…')` → `DOMParser` / `<template>` → 注入并缓存。
- **禁止**用 `<img src="*.svg">` 承载需要主题适配的资产：
  `<img>` 引用的是独立文档，外层 CSS 变量与 `currentColor` **穿不过去**，
  会导致夜纸下资产仍是亮纸版本（直接违反 `acceptance.md` §3.2 第 4 条）。
- 独立打开 `.svg` 文件时，变量走回退值——这是**设计走查用的正常形态**，
  但夜纸检查必须在 inline 状态下做。

### 1.11 禁止清单（资产内）

| 禁止 | 替代 |
|---|---|
| `<image>` / base64 位图 / 外链 `href` | 纯路径绘制 |
| `@font-face` / `<text>` / `<tspan>` | 无文字 |
| 外链（`http://` `https://` `//`） | 无 |
| `<script>` / `<foreignObject>` | 无 |
| `<animate>` / `<animateTransform>` / `<set>` / SMIL | 动画一律由宿主 CSS 驱动 |
| SVG `filter`（`feGaussianBlur` 等） | 描边复制法 / 渐变 |
| `stroke-linecap="butt"` / `stroke-linejoin="miter"` | round / round |

## 2. 导航静物图标集（5 个）

### 2.0 共用规则

- **徽章式**：每个图标文件 = **彩色圆底 + 图形**。圆底 = `<circle cx="24" cy="24" r="24">`，
  填充 `var(--asset-ground-*)`；圆底是纯色（不用渐变，除非愿意用 §1.6 的 `gRole`）。
- 图形是**具象静物**，不是抽象几何占位符（`decisions.md` §14.1）。
- 五个图标**同一支笔**：同一组线宽（主 3 / 次 2 / 细 1.5 u）、同一组圆角档、同一光源（左上 45°）、
  同一视角（略俯视、正对读者，允许 ≤3° 偏转）。
- 图形外接框 ≤ 32 × 32 u，且整体落在以 (24,24) 为心、半径 16 u 的内切圆内。
- **墨色一色律**：一个图标只有一种线条颜色。淡彩只作为"面"出现。

**五个图标的圆底角色与前景色**（按基线的角色语义分配，不是为了彼此区分而分配）：

| 图标 | 圆底角色 | 前景（线条）色 | 受光淡彩域 | 背光淡彩域 | 语义依据 |
|---|---|---|---|---|---|
| 练习 | 学习蓝 | 纸白 `--asset-ink-on-blue` | 阳光黄 16% | 中性 10% | 主行动 = 学习蓝 |
| 试卷 | 阳光黄 | 墨 `--asset-ink-on-yellow` | 纸白 26% | 中性 12% | 阳光黄 = 当前/进行中的卷宗 |
| 知识点 | 学习蓝 | 纸白 | 阳光黄 18% | 中性 10% | 学习内容，与练习同族 |
| 知识图谱 | 学习蓝 | 纸白 | 阳光黄 22%（核心）/ 纸白 16%（卫星） | 中性 10% | 结构浏览，与练习同族 |
| 记录 | 阳光黄 | 墨 | 纸白 24% | 中性 12% | 阳光黄 = 复习/回看强调 |

> **关于红色**：注意红**只**表示失败与阻塞，导航项不是失败，因此**导航圆底不用红**。
> 若所有者坚持五个圆底各不相同，唯一可接受的改法是把「记录」改为注意红
> （记录中心确实含失败与错题复盘），代价是红底与「失败」语义重叠，须明确裁决。
> 本规格的默认分配**不需要**第五种分法，也不需要新色相。

> **受光/背光的分工**：受光面（左上朝向）用**与底色不同的一层淡彩**，背光面（右下朝向）用**中性淡彩**。
> 在蓝底上，受光面是暖黄（在冷底上显暖）；在黄底上，受光面是纸白（白纸压在黄纸上显亮）。
> 两者都只承担"这是哪一面"，不承担状态语义。

## 3. 空态静物插画集（10 个）

### 3.0 共用规则

- 每张画**一件器物**（允许器物自带的必要配件，如笔筒里的笔、杯子的碟），不出现第二件主题物。
- 器物必须是**学习器物或书房器物**：与内容无关，只表达「此刻无事」。
- **禁止**：人物、动物、文字、字母、品牌标识、抽象几何团块（`decisions.md` §13.3）。
- 桌面横线：一条水平淡线（中性 8%–10%），长度约画幅的 60%–70%，

- 高光 ≤ 2 处；接触阴影一条；不透明度 ≤ 12%。
- 主体底部与桌面横线之间留 1–3 u 的"悬空感"或直接压线，二选一，全组统一（推荐压线）。

### 3.11 插画 × 使用场景对应表

**选择原则**（按此挑，不要按"哪个好看"挑）：

1. **气质匹配**：空态要传达的是「此刻无事，随时可以开始」，不是「缺东西、坏掉了」。
   因此不选残缺、倾倒、破损、脏乱的器物。
2. **同屏不重复**：同一页面内出现两个空态时，必须用不同的插画。
3. **不暗示任务内容**：不选会让人误以为"这里应该有某样东西"的画（如空杯子会像"你的茶被喝了"）。
4. **可替换**：插画可被换掉而不影响理解——文案与主按钮才是空态的主体（P-1 少字原则）。

## 4. 台灯的三姿态

> 台灯是**空态插画语言的一部分**（`decisions.md` §16.5），因此它与 §3 的插画共用：
> 同一套线宽（主 3 / 次 2 / 细 1.5 u）、同一套圆角档、同一光源、同一台面横线。
> 差别只有两点：① 它是**唯一的动效资产**；② 它是**单文件三姿态**。

### 4.1 画布与共用结构

- 画布：`viewBox="0 0 240 200"`，与插画同规格；默认渲染宽度 180 px。
- 部件（组 class 固定，便于宿主 CSS 切换）：

| 组 class | 部件 | 线宽 | 坐标 / 形状（u） |
|---|---|---|---|
| `lamp__table` | 台面横线 | — | y = 176，x 12 → 228，中性 10% |
| `lamp__lightpool` | 桌面光斑 | — | 椭圆 cx 150 cy 174 rx 46 ry 8，`--asset-lamp-glow` 12%（仅亮态） |
| `lamp__base` | 底座 | 主 | `M 70 176 L 78 152 L 118 152 L 126 176 Z`，圆角 4 u（中） |
| `lamp__arm` | 灯杆 | 主 | 折线 `M 98 152 L 110 96 L 142 76`；关节 `circle(110,96,r4)` |
| `lamp__shade` | 灯罩 | 主 | 钟形 `M 126 62 L 174 92 L 168 100 L 132 74 Z`（罩口斜切椭圆） |
| `lamp__shade-back` | 灯罩背面细节 | 次 | 罩背两条棱线（仅 A 姿态可见） |
| `lamp__shade-front` | 罩口 + 罩内壁 | 次 | 罩口椭圆 + 内壁一圈（仅 B/C 姿态可见） |
| `lamp__knob` | 提钮 | 次 | `circle(126,58,r5)` |
| `lamp__bulb` | 灯泡 | 次 | `circle(150,86,r7)`（仅亮态可见） |
| `lamp__glow` | 光晕 | — | 椭圆 cx 152 cy 92 rx 44 ry 26，`gLamp`（仅亮态可见） |

- 台面横线是 `lamp__table`，与 §3 插画的桌面横线**同一条线**，确保转场时"同一张桌子"成立。

### 4.2 姿态 A · 收（parked）

- **画面**：灯几乎不在画面里——只在画幅右下角露出灯罩上缘与提钮的一小截（约 10 u），
  像一盏被推到角落的台灯。台面横线完整可见。**灯未点亮**（无灯泡、无光晕、无光斑）。
- **实现**：整组 `lamp__body` 被平移到画幅右下方之外（`transform: translate(…, …)`），
  使只有罩口上缘探入画面；`lamp__shade-back` 可见，`lamp__shade-front` / `lamp__bulb` / `lamp__glow` /
  `lamp__lightpool` 全部 `opacity: 0`。
- **终态含义**：暖纸 = 熄；夜纸 = 灯留在角落但保留极弱光晕（`opacity 0.35`），
  呼应「夜里是台灯照着的纸」。

### 4.3 姿态 B · 探（peek）

- **画面**：灯从右下角**转出来**并面向观者，完整可见（底座 + 灯杆 + 灯罩），
  罩口朝向左下，光还**没有亮**——"咔哒"之前的那一瞬。
- **实现**：`lamp__body` 平移/旋转回正位（`transform` 变化），`lamp__shade-back` 淡出、
  `lamp__shade-front` 淡入，灯泡与光晕仍为 0。
- **与 A 的关系**：只有**位置与朝向**变了（一个 `transform` 插值 + 两组细节的 opacity 交叉），
  几何本身不变——**不允许为 B 姿态另画一张灯**。

### 4.4 姿态 C · 亮（lit）

- **画面**：灯罩内亮起（灯泡可见 + 罩内壁一圈暖色），暖光从罩口溢出成一团晕，
  台面上落下一滩光。灯的位置与 B 相同。
- **实现**：`lamp__bulb` `opacity 0→1`；`lamp__glow` `opacity 0→1`（`gLamp` 径向）；
  `lamp__lightpool` `opacity 0→1`；罩内壁加一层 `--asset-lamp-glow` 的暖色 wash。
- **光的方向**：光从罩口（朝向左下）射出，因此**光斑在灯的左下方**、光晕偏左，
  不做对称发光——这与 §1 的左上光源规则不同，是**画内光源**，属有意为之。

### 4.5 姿态切换与时序

**状态机**（相对时序；绝对毫秒由动效基座给，基线 §动效：「台灯探出 → 点亮 → 涟漪扩散铺满 → 灯收回」，总约 700 ms）：

```
   ①收 ──转出──▶ ②探 ──咔哒──▶ ③亮 ──涟漪铺满──▶ ④收(终态)
     │            │            │
     │ 180ms      │ 120ms      │ 450ms（涟漪，不是资产）
     │            │            │
     └─ 反向：④收 ──探出──▶ ③亮 ──熄灭──▶ ②探 ──收回──▶ ①收
```

| 步 | 姿态 | 发生什么 | 备注 |
|---|---|---|---|
| 0 | A（收） | 静置 | 暖纸=熄 / 夜纸=微亮 |
| 1 | A → B | 灯体转出（`transform` 插值）+ 背/正细节交叉淡入淡出 | 约 180 ms |
| 2 | B（探） | 静置一拍 | 约 60 ms，"咔哒"的静默 |
| 3 | B → C | 灯泡亮 + 光晕扩散 + 光斑浮现 | 约 120 ms |
| 4 | C（亮） | **涟漪层**从灯下扩散铺满全屏 | 约 450 ms；**不是资产**，见 §4.6 |
| 5 | C → A | 灯退回角落 | 约 150 ms |
| 终 | A | 与主题一致的终态 | 暖纸=熄；夜纸=微亮 |

**不变量**：
- **终态时灯的状态永远与主题一致**：暖纸 → 熄；夜纸 → 亮（弱）。
- 灯的**几何**在三姿态间不变（只有 `transform` 与 `opacity` 变化）。
- 灯罩始终是**同一支笔**画的：不因姿态切换而重画。

### 4.6 涟漪层（不是资产）

- 涟漪**不是 SVG 资产**，是宿主 CSS 的一层：一张放大的径向渐变遮罩
  （中心在灯嘴位置），用 `transform: scale()` + `opacity` 扩散。
- 约束（`decisions.md` §17.2）：只动 `transform` / `opacity`；不阻塞交互；不改请求时序。
- `prefers-reduced-motion` 下降级为**状态直切**（无探出、无点亮、无涟漪）。
- 切回暖纸时，涟漪**反向收拢**（暖纸色由外向内铺满）。

### 5.4 浏览器自查流程

> 建议在实现阶段临时搭一个**自查页**（不入产品、不进版本库），把 16 件资产按
> 「暖纸 / 夜纸」两块排开，图标给 16 / 24 / 32 px 三档，插画给 120 / 180 / 240 px 三档。

**第 1 步：结构自检（浏览器 Console 脚本）**

```js
// 1) 禁止元素 / 外链 / 位图
const bad = ['image','script','foreignObject','text','tspan','animate','animateTransform',
             'set','filter','use'];
[...document.querySelectorAll('svg *')]
  .filter(el => bad.includes(el.tagName.toLowerCase()))
  .map(el => el.tagName + ' @ ' + el.outerHTML.slice(0, 60));

// 2) 外链与内联样式
[...document.querySelectorAll('svg [href], svg [xlink\\:href], svg [style]')];

// 3) id 唯一性
const ids = [...document.querySelectorAll('svg [id]')].map(e => e.id);
ids.length === new Set(ids).size;

// 4) 硬编码色值（应只剩 var() 的回退值）
[...document.querySelectorAll('svg [fill], svg [stroke], svg stop')]
  .map(e => e.getAttribute('fill') || e.getAttribute('stroke') ||
            e.getAttribute('stop-color'))
  .filter(v => v && /^#|rgb/i.test(v));
```

**第 2 步：对比度自检**

- 图形对圆底：按 §1.7 的表逐组合验算（该表已算好，但**在 token 层取值落定后必须重算一次**，
  因为 `--asset-ground-*` 最终会引用 token 层的值）。
- 插画墨线对纸面：`--asset-ink` on `--asset-paper` 需 ≥ **4.5:1**（插画有语义，按正文级要求）。
- DevTools：选中元素 → Rendering 面板 → Contrast issues。
- **注意**：黄底图标里的图形必须是墨色（8.54:1）；若误用纸白（1.89:1），自查会直接报出来。

**第 3 步：与 12px 圆角的相容性**

- 把图标放进一个 **12px 圆角的导航行**里看两件事：
  1. 圆底（正圆）与行块的 12px 圆角是否读起来是同一族——不出现"小圆角套大圆角"的割裂；
  2. 圆底直径与行高是否留够间隙（建议圆底直径 = 24 px，行高 ≥ 44 px，圆底与行块边缘间距 ≥ 8 px）。
- 圆底的柔影与卡片柔影用同一套 token（暖调柔影），不要图标自成一档。

**第 4 步：夜纸可读性**

- 切到夜纸（`[data-theme="night"]`）后：
  1. 插画必须仍能一眼认出是什么器物（不是"一团线"）；
  2. 墨线反相为暖浅色后不得刺眼、不得比正文更亮（正文才是主角）；
  3. 圆底降饱和 + 提亮后，图形与圆底的对比仍 ≥ 3:1；
  4. **确认没有多出一套夜纸专用 SVG**——文件数应恒为 16。

**第 5 步：极限识别**

- 图标缩到 **16 px**：五个图标仍能分辨（书 / 纸 / 书签 / 节点 / 本子）。
  分辨不了就减线条，不是加线条。
- 浏览器 **200% 缩放**下检查：主线不断裂、细线不糊成一片。
- 插画缩到 **120 px**：器物仍可辨认；高光与接触阴影消失后形体仍完整。

**第 6 步：台灯分镜自查**（对应 `acceptance.md` §2 M-1）

- 按 0 / 90 / 180 / 330 / 500 / 700 ms 采样六帧，确认四段都在：
  **探出 → 点亮 → 涟漪扩散 → 收回**，700 ms 后终态干净（无残留光晕、无残留遮罩）。
- `prefers-reduced-motion: reduce` 下出一张对照帧：应为**状态直切**，无探出、无点亮、无涟漪。

### 5.5 无障碍交付规则

| 场景 | 处理 |
|---|---|
| 左栏导航（图标 + 可见文字） | 图标 `aria-hidden="true"` `focusable="false"`，名称由可见文字承担 |
