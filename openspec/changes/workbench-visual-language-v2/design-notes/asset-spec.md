- §1 是**全局规则**，画每一张图之前先读一遍，不必回读。

## 1. 统一 SVG 技术规格

> 以下条款对**全部**资产（图标 / 插画 / 台灯）生效。除非某一项另有明文说明。

### 1.1 画布与网格

| 资产类 | `viewBox` | 画幅（u） | 默认渲染尺寸（CSS px） | 1 u = | 网格 |
|---|---|---|---|---|---|
| 导航图标 | `0 0 48 48` | 48 × 48 | 24 × 24 | 0.50 px | **12 × 12 单元**，1 单元 = 4 u = 2 px |
| 空态插画 | `0 0 240 200` | 240 × 200 | 宽 180（高 150） | 0.75 px | **24 × 20 单元**，1 单元 = 10 u = 7.5 px |
| 台灯 | `0 0 240 240` | 240 × 240 | 132 × 132 | 0.55 px | **24 × 24 单元**，1 单元 = 10 u = 5.5 px |

- **u（unit）** 是本文件的唯一长度单位。所有坐标、线宽、半径都以 u 给出，实现时乘以上表的换算。
- 网格：部件端点尽量落在整单元或半单元上。允许半单元偏移（手绘感），
  但**不得**出现 1–3 u 的随机抖动。
- **安全区**：

  | 资产类 | 判据 |
  |---|---|
  | 导航图标 | ① 图形外接框 **≤ 30 × 30 u**（占圆底直径 62%）；② 外接框中心落在以 (24,24) 为心、**半径 3 u** 的小圆内（允许有意的偏转）；③ 外接框**最远顶点**距 (24,24) **≤ 21 u**（= 圆底半径的 87.5%）；④ 图形与圆底边缘的径向间隙 ≥ 3 u |
  | 空态插画 | ① 器物本体外接框**最长边 60–125 u**（画幅宽的 25%–52%）；② 器物本体外接框**高 ≤ 132 u**（画幅高 66%）；③ 左右留白 **≥ 40 u**；④ 器物底部与桌面横线（y = 168）相距 **0–3 u**（压线）；⑤ 水平居中：外接框中心与画幅中心的横向偏移 ≤ 6 u |
  | 台灯 | ① 灯座底缘 y = 226，正方画布底部留 14 u；② 灯座中心 x = 120 = 画幅中心，使 `transform-origin: 50% 100%`（= (120,240)）正落在灯座轴线上；③ 罩口与光晕不得超出画幅（光晕半径 60 u，罩口中心 (118,131)，最远点 118−60 = 58 > 0 ✓，131+60 = 191 < 240 ✓） |

- `preserveAspectRatio` 保持默认 `xMidYMid meet`；**禁止** `slice`（会裁掉笔画）。
- **禁止**在 `<svg>` 根上写 `width` / `height` 属性（尺寸由宿主 CSS 控制，见 §1.11）。

### 1.2 线宽阶

全组**同一组数值阶梯**，三类资产共用（渲染尺寸不同，阶梯结构相同）：

| 档 | u | 图标 @24px | 插画 @180px | 台灯 @132px | 用途 |
|---|---|---|---|---|---|
| **主** | 3 | 1.50 px | 2.25 px | 1.65 px | 形体外轮廓、封面、器物主壁、灯罩外壳 |
| **次** | 2 | 1.00 px | 1.50 px | 1.10 px | 内部结构线、书脊、部件分界、连接线、罩口 |
| **细** | 1.5 | 0.75 px | 1.125 px | 0.825 px | 纹理：页行、叶脉、灯罩棱 |

- 线宽比恒为 **3 : 2 : 1.5**。不得出现第四档。
- 每张资产**最多用三档**；用不到某档就不用，但不得自造新值。
- 角色分工：结构轮廓 = 主线；内部结构 = 次线；纹理 = 细线。
- **细线（1.5 u）是亚像素线**：图标尺寸下 0.75 CSS px、插画 1.125 px、台灯 0.825 px。
  规则：
  1. 细线只允许出现在"删掉也不损失识别"的位置（页行、叶脉、编织纹、地平线细节）；
  2. 若在目标浏览器里发虚，**把该处升到次线并同时删掉冗余纹理**，不得加粗到主线；
  3. **台灯在 132 px 下只允许主 + 次两档**——细线在该尺寸下不足 1 px，
     灯罩棱、罩口内壁等处一律用次线。
- **禁止**：hairline（< 1 u）、超粗线（> 4 u）、同一形体上混用两档线宽。

### 1.3 端点与连接

- 全组统一：`stroke-linecap="round"`、`stroke-linejoin="round"`。
  可写在最外层 `<g>` 上继承，**不要**每个 path 重复写。
- **禁止** `butt` 端点、`miter` 连接、`stroke-miterlimit`。
- `stroke-dasharray` **仅**允许用于图谱图标里那条「尚未连上」的卫星连线这一处语义，
  节奏为 `4 3`（u）。其余资产一律实线。

### 1.4 圆角档

圆角语言 = **局部短边的比例**，与界面 12px 圆角是同一种"语气"的不同尺度
（界面 12 px 是"不小于所作用边长的 1/16、且不用小圆角"；资产内部用比例表达同一件事）。

| 档 | 比例（局部短边） | 图标参考值 (u) | 插画参考值 (u) | 台灯参考值 (u) | 典型用途 |
|---|---|---|---|---|---|
| **锐** | 0 | 0 | 0 | 0 | 纸边、笔尖、硬折线、裁切边 |
| **微** | 1/16 | 1.5 | 4 | 4 | 小构件角：纸角、笔筒口沿、书签缺口 |
| **小** | 1/10 | 3 | 8 | 8 | 次级形体：书页、灯罩口、杯沿、画框内缘 |
| **中** | 1/6 | 6 | 16 | 16 | 主形体：书封面、笔记本、画布框、台灯底座 |
| **大** | 1/4 | 8 | 20 | 20 | 大件柔性形体：果篮、花瓶腹、灯罩外沿 |

- 规则：
  1. 任何角都不是直角；除"锐"档的明确纸边外，至少给到"微"。
  2. 主形体用"中"（1/6），次级用"小"（1/10），细节用"微"（1/16）。
  3. 自由曲线（杯口、篮沿、花器口、灯罩口）不设限，由造型自然决定。
  4. 同一套资产里，同类部件的圆角档必须一致（五个图标的"主形体圆角"必须读起来是同一种）。

### 1.5 描边与填充的关系

- **描边优先**：形体用「描边 + 透明或极淡填充」表达。
- 填充只承担三件事，且仅此三件：
  1. **淡彩晕染**（低饱和色面）；
  2. **彩色圆底**（仅图标）；
  3. **高光 / 亮部**（极小面积）。
- **禁止**「大面积实心填充 + 粗描边」的贴纸感。同一形体上，描边相对填充的对比度必须 ≥ 3:1
  （用 §1.7 的取值直接验算）。
- **淡彩用预混色，不用 alpha**（D-3）：
  - 蓝 / 黄 / 红三色淡彩直接用 `--art-wash-blue` / `--art-wash-yellow` / `--art-wash-red`
    （不透明，已按 token 层配方与纸色混好）；
  - 中性淡彩（背光面）用 `color-mix(in oklab, var(--art-ink) 10%, var(--art-paper))`；
  - 需要**中间档位**（例如"黄 16%"而非 token 给的 18%）时，
    写 `color-mix(in oklab, var(--role-yellow) 16%, var(--art-paper))`——**不要**写
    `fill: var(--role-yellow); fill-opacity: .16`（半透明色叠在不确定的背景上不可控）。
  - 晕染**不得盖过墨线**——永远先铺淡彩、后描线。
- **阴影**：
  - **禁止 SVG filter**（`feGaussianBlur` / `feDropShadow` / `feTurbulence` 一律不用）。
  - 柔影 = 「同形复制 + 2 u 偏移 + 3%–6% 不透明度 + 深一档色相」。
  - 接触阴影 = 一条 3–5 u 宽的横向淡色带（放在器物底下）。
- **禁止** `clipPath` 做复杂裁剪。需要裁切时优先直接画 `circle` / `rect rx` / 带 `Z` 的闭合路径。

### 1.6 淡彩与渐变语言

渐变**只允许出现在资产内部**（`decisions.md` §14.3），不得用于背景、卡片或任何大面积表面。
全组只允许下面 **3 组**渐变（D-9），方向统一 **135°**
（`objectBoundingBox`，`x1=0 y1=0 x2=1 y2=1`）：

| id 前缀 | 类型 | 停靠点 | 用途 |
|---|---|---|---|
| `gRole` | linear 135° | 起 = 角色色；止 = 角色色混纸 22%（浅）/ 混夜纸底 30%（夜）；顶 = 顶部高光（见下表） | 彩色圆底（**可选**，默认纯色） |
| `gSheen` | linear 135° | 起 = `--asset-highlight` 40% → 止 = 0% | 器物表面的柔光带（玻璃、陶、金属材质），一条 |
| `gLamp` | radial（中心 = 罩口中心，r = 60 u） | 起 = `--asset-lamp-warm` 55% → 止 = 0% | 台灯暖光晕（仅台灯） |

**`gRole` 的色阶表**（直接取 token 层 `night-paper-tokens.md` §7.2，两主题只换停靠点色阶）：

| 角色 | 浅色 起 → 止 | 浅色 顶部高光 | 夜纸 起 → 止 | 夜纸 顶部高光 |
|---|---|---|---|---|
| 学习蓝 | `#2b62e8` → `#5983ea` | `#6b91ef` | `#7291de` → `#586da2` | `#89a3e3` |
| 阳光黄 | `#f5c518` → `#f7d047` | `#f8d65d` | `#e0c151` → `#a58f3f` | `#e5cb6d` |
| 注意红 | `#d1392b` → `#db6356` | `#df746b` | `#d4736b` → `#9d5852` | `#db8983` |

- 同一资产内渐变**≤ 2 组**。
- 渐变不得越出形体边界（需要时用同形闭合路径承载，而不是裁剪）。
- **夜纸不新建渐变**：同一 `<linearGradient>` 只换停靠点色阶（更暗的色相 + 更弱的高光），
  色阶由 CSS 变量给（§1.7），`gradientTransform` 不动。
- **淡彩面本身不用渐变**（D-3）——淡彩是预混的平色，渐变只留给圆底、柔光带和灯光。

（例外仅限"深色物件上一条浅色高光"，且全资产不超过 1 处）。

### 1.8 命名、id 命名空间与文件组织

**目录结构**（新增，位于既有静态目录之下；`/static/` 路由与 `.svg` 的 MIME 已就绪
——`workbench/server/app.py:136-137`、`:29`）：

```
workbench/server/static/assets/
├── icons/                     导航静物图标（5）
│   ├── icon-practice.svg
│   ├── icon-practice-sets.svg
│   ├── icon-kps.svg
│   ├── icon-graph.svg
│   └── icon-records.svg

│   ├── empty-vase.svg
│   ├── empty-fruit-basket.svg
│   ├── empty-canvas.svg
│   ├── empty-cup.svg

│   ├── empty-inkwell.svg
│   └── empty-compass.svg
└── motion/
    └── lamp.svg               台灯（单文件三姿态）
```

**文件名规则**：`<kind>-<subject>[-<qualifier>].svg`，全小写 kebab-case。

| kind | 含义 |
|---|---|
| `icon` | 导航静物图标（圆底徽章式） |
| `empty` | 空态静物插画 |
| `lamp` | 台灯（motion 类唯一资产） |

**SVG 内部 id 命名空间**：所有 `id`（渐变、组）**必须**带资产前缀，
形如 `icon-practice-wash`、`empty-vase-gLight`、`lamp-gLamp`。
理由：资产以 inline 方式进入同一文档，重复 id 会让 `url(#id)` 指到别的资产的定义。
**禁止**出现裸 id（如 `id="wash"`）。

> **id 前缀 = 文件名主干**：`icon-practice.svg` → 前缀 `icon-practice-`；
> `empty-vase.svg` → `empty-vase-`；`lamp.svg` → `lamp-`。
> 一个文件里所有 `id` 都用同一个前缀，天然保证全文档唯一。

**class 命名空间**（与宿主 CSS 的约定，**不得**自造第三套）：

| 资产 | 根 class | 内部组 class |
|---|---|---|
| 图标 | `asset asset-icon` | `asset-icon__ground` / `asset-icon__wash` / `asset-icon__line` / `asset-icon__highlight` |
| 插画 | `asset asset-empty` | `asset-empty__wash` / `asset-empty__line` / `asset-empty__highlight` / `asset-empty__shadow` |
| 台灯 | `lk-lamp`（**motion-spec 指定，不可改**） | `lk-lamp__body` / `lk-lamp__base` / `lk-lamp__stem` / `lk-lamp__arm` / `lk-lamp__shade` / `lk-lamp__glow` |

> 台灯根 class 必须是 `lk-lamp`：motion-spec §3.5 的 `.lk-lamp` 直接驱动
> `translate3d / scale / rotate` 与 `opacity`，改名即转场失效。
> 同理 `.lk-lamp__glow` 是"点亮"段的动画目标，必须保留该 class。

**根元素约定**：

```xml
<svg viewBox="0 0 48 48" class="asset asset-icon" xmlns="http://www.w3.org/2000/svg"
     role="img" aria-labelledby="icon-practice-title">
  <title id="icon-practice-title">练习</title>
  <defs>…</defs>
  <g class="asset-icon__ground">…</g>
  <g class="asset-icon__art">…</g>
</svg>
```

- 不写死 `width` / `height`，尺寸由宿主 CSS 的 `.asset-icon` / `.asset-empty` 控制。
- 必须写 `xmlns`（独立打开时也要合法）。
- 必须有 `<title>`（见 §5.5）。

### 1.9 class / `currentColor` / CSS 变量的用法规则

| 用途 | 用什么 | 不用什么 |
|---|---|---|
| 主题适配（暖纸 ↔ 夜纸） | **CSS 变量** `var(--asset-*, fallback)` | 不用 `prefers-color-scheme` 媒体查询（主题偏好是工作区级的浏览器偏好，不是系统级） |
| 跟随宿主文字色 | `currentColor`（仅限"跟随上下文文字"的装饰件，本套资产**未使用**） | 不用硬编码 hex |
| 颜色回退 | `var(--asset-ink, #2a2620)`，**每个 `var()` 都带回退值** | 不写无回退的 `var()` |
| 结构分组 | 语义 class：`__ground` / `__wash` / `__line` / `__highlight` / `__shadow` | 不写行内 `style="fill:#xxx"` |
| 派生混色 | `color-mix(in oklab, var(--role-blue) 16%, var(--art-paper))` | 不写 `fill-opacity` 叠半透明角色色 |

- **禁止**在 SVG 里写 `style` 属性、`class` 里塞颜色、`<style>` 块内定义颜色。
- 颜色只能出现在两处：`fill` / `stroke` 属性上的 `var(--asset-*)`，
  或 `<stop stop-color="var(--asset-*)">`。
- 主题切换时**只换变量值，不重画资产、不新增资产**（`acceptance.md` §3.2）。

### 1.10 双主题同文件机制（一份文件，两套主题）

> 这一节回答实现者最常问的一句：**"同一份 SVG 怎么同时给暖纸和夜纸用？"**

#### 1.10.1 机制原理

| 环节 | 事实 | 依据 |
|---|---|---|
| 变量从哪来 | CSS 自定义属性**继承**。`var()` 在 SVG 的 `fill` / `stroke` / `stop-color` 属性里**照常解析**——只要 SVG 在文档树里 | CSS Variables Level 1；SVG 2 |
| 变量在哪换 | 外壳 CSS 在 `:root` 与 `[data-theme="night"]` 两个作用域上重新赋值 `--asset-*`（见 §1.7 第二步） | token 层 §3 / §7 |
| 资产要不要改 | **不改**。文件数、几何、线宽、圆角、渐变 id 全部不变；只有**解析出来的颜色**变 | `decisions.md`「插画与主题：同一套 SVG，用 CSS 变量换前景/背景色」 |

一句话：**变的是变量，不是资产。** 资产里写的是 `var(--asset-ink, #2a2620)`，
暖纸下解析成 `#2a2620`，夜纸下解析成 `#e6ddcd`。

#### 1.10.2 什么会变 / 什么不变

| 会随主题变 | 不会随主题变 |
|---|---|
| 线稿色（`--asset-ink`） | 几何、坐标、路径 |
| 纸面色（`--asset-paper`） | 线宽三档 |
| 淡彩色域（`--art-wash-*` / 混色配方） | 圆角档 |
| 圆底色（`--role-*`，夜纸为降饱和+提亮版） | 渐变 id、停靠点**位置**、`gradientTransform` |
| 高光强度（浅色白 55% → 夜纸暖白 8%） | 透明度层级关系（先铺淡彩、后描线） |
| 圆底上的字形色（浅色蓝/红用纸色、黄用墨；夜纸统一深墨） | 元素的层序与数量 |

#### 1.10.3 一个完整的对照示例（讲清"同文件"到底同在哪）

```xml
<!-- 夜纸与暖纸共用这一段，一个字都不改 -->
<path class="asset-empty__line"
      d="M 120 96 C 94 96 94 152 120 152 C 146 152 146 96 120 96 Z"
      fill="var(--asset-wash-yellow, #fdf3cf)"
      stroke="var(--asset-ink, #2a2620)"
      stroke-width="3"/>
```

| 主题 | `fill` 解析为 | `stroke` 解析为 | 观感 |
|---|---|---|---|
| 暖纸 | `#fdf3cf`（黄 18% 混纸白） | `#2a2620`（暖炭褐） | 纸上的淡黄器物，深墨勾边 |
| 夜纸 | `#3d3721`（黄 14% 混夜纸卡面） | `#e6ddcd`（暖浅墨） | 夜纸上的暗黄器物，浅墨勾边 |

> 关键：**`stroke-width="3"` 没有变**，`d` 没有变，`fill` 指向的变量名没变。
> 变的只是那两个变量在当前主题下的取值。

#### 1.10.4 三种常见错误做法（都会导致验收 §3.2 第 4 条失败）

| 错误做法 | 后果 | 正确做法 |
|---|---|---|
| 用 `@media (prefers-color-scheme: dark)` 在 SVG 内写第二套色 | 主题偏好是**工作区级**设置，不等于系统偏好，用户显式切了主题也改不掉 | 全部走 `var(--asset-*)`，由外壳在 `[data-theme]` 作用域换值 |
| 为夜纸单独做一套 SVG（`*-night.svg`） | 文件数翻倍；两套资产会各自漂移，出现"同款插画不同形" | 一套文件，两套
