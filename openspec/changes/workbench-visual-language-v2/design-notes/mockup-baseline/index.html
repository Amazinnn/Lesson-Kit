06

三角色色 · 面积配额

蓝 = 交互层 · 黄 = 内容层 · 红 = 失败 / 阻塞

页面级软约束：同一屏内 蓝 ≤ 3 处主强调面、黄 ≤ 1 处、红 ≤ 1 处； 超出即视为「颜色失去解码力」，须降级为中性面 + 状态点。 组件级槽位：R0 不占角色色 · R1 ≤1 色 · R2 ≤2 色 · R3 三色全用。

三角色色的「蓝 / 黄 / 红」各承担什么
角色承担语义允许出现在
学习蓝 主按钮、链接、交互层当前选中（导航 / Tab / 选项 / 当前页） 实心填充、淡彩底、文字、2–3px 指示条
阳光黄 内容层当前项、复习强调、连对进度（当前题 / 当前复习项 / 连对计数） 实心填充、淡彩底、图形 —— 任何承载文字的面都禁止
注意红 失败、阻塞 淡彩底、文字（用 --role-red-ink）、计数徽标

「当前」在蓝与黄之间的分工：交互层（用户正在操作的对象）用蓝； 内容层（内容本身的状态）用黄。

黄色只承载面积与形状，绝不承载文字
黄底 · 取墨色字

合法：黄面上的字用 --ink-on-warm（浅=墨 / 夜=深墨），10.07:1 / 10.61:1

黄底 · 黄字

非法：黄色本身当文字色 —— 纸色字压在黄面上只有 1.60:1

6 种几何全部用 CSS 画（filled / ring / half / dash / cross / check 勾形），10px 盒内绘制，不引图标字体； 状态 →（色，几何）映射唯一，不得有两条状态共用同一组合。
A-20-3（2026-10-22 所有者裁决）：「答对」不再用绿色（现状兼容例外 #1a7f37 / #e6f4ea 本轮移除）， 也不再占蓝（蓝已给「当前选中」）→ 改为 中性墨 --ink-strong + 勾形。

用户原创：灯亮了就进入夜间
