# 样板图基线（mockup baseline）—— 视觉靶子

> **这是什么**：2026-10-22 14:31 由 subagents 产出的一组**静态页面**，
> 它们**照 `design-notes/layout-spec.md` 画的**，是所有者认可的**视觉基准线**。
>
> **为什么在这里**：原件住在 `tmp/frontend-audit/mockups/`，而 `tmp/` **不入库**
> ⇒ 清一次就没了。拿一个会被删掉的东西当依据 = 沙上造楼。
> ⇒ **2026-10-23 把源码提升进仓库**（8 个文件 / 520 KB；**截图不入库**，随时可重抓）。
>
> **它是什么、不是什么**：
> - ✅ 是**视觉靶子**：整页的构成、功能的有无、气氛、疏密关系。
> - ❌ **不是产品实现**：页脚自己写着「所有按钮、输入框、状态点、图表均为**静态占位**；
>   未连接任何请求、未实现任何状态机。仅两栏演示脚本：翻转（对话/题卷 token）、
>   切换夜纸视图（也可用 `?rail=list|chat` 直接进入对话视图）。右栏不出现在
>   任何视口，对话视图不进入会话列表。」
> - ❌ **不是规范的替代**：`layout-spec.md` 是**版式的规格**，本页是它的**视觉实现**；
>   两者同源，**差 4 个数字**（见下）。

## 2. 与 `layout-spec.md` 的**四处数字差异**（2026-10-23 实测）

| 项 | 本基线（实测） | `layout-spec.md` | 处置 |
|---|---|---|---|
| 中栏 padding | `24px 32px 48px` | `28px 32px 72px`（§1.7） | **规格为准**（A-142）—— 样板图是草图，§1.7 的 72px 是给滚动留余量的显式规则 |
| 标题 h1 | `28px / 36px` | `30px / 38px`（§4.1②） | **规格为准**（A-142）—— §4.1② 点名要把「现状 28/36」改掉，样板图没跟上 |
| 栏间分隔线 | 无（`border-right: none`） | 1px `--rule-hair`（§1.7） | **规格为准**（A-142） |
| 左栏 padding | `16px 12px` | `16px 12px 24px`（§1.7） | **规格为准**（A-142） |

> 共同点（**一致**）：顶栏 52px · 三栏 `280 / 1fr / 420` · 纸面 12px 圆角 + 双层柔影 ·
> 标题带 2px 墨线 · 顶栏 gap 16px / padding `0 16px` · 左栏 padding `16px 12px`。
>
> ⇒ **为什么「数值以规格为准」**：样板图自带声明「所有…均为静态占位」，
> 它是**视觉草图**；`layout-spec.md` 是**版式的规格**，两者在**构成与气氛**上同源，
> 在**具体数值**上偶有出入时，规格是显式规则、样板图是没跟上的草图。
> ⇒ **页面构成与功能以样板图为准**（那部分规格没写全），**数值以规格为准**。

## 5. V1 拼版（`v1.html`）

> **这一版 = 六个样板图页面原样拼在一页里，没有改动样板图的任何字节。**

`v1.html` 用 iframe 直引本目录的六个原文件（`index` / `shell` / `practice` /
`knowledge` / `records` / `graph`），每页配一条**规格出处**标注：

| # | 页 | 对应规格 |
|---|---|---|
| 00 | 规格总览（夜纸视觉基线） | 视觉语言的根 |
| 01 | 工作台壳层（练习进行中） | §2 顶栏 · §3 左栏 · §5.2 · §6 右栏 |
| 02 | 练习页三态 | §5.1–§5.3 |
| 03 | 知识点列表 | §5.4 |
| 04 | 记录中心 | §5.6 |
| 05 | 知识图谱 | **范围外**（§0.2） |

**为什么用 iframe 而不是拆成片段**：样板图是**整页应用**
（`body { height:100%; overflow:hidden }`），拆成片段就得改它们 ——
而这一版的前提正是「不要改」。每页仍是它自己，在自己的视口里跑自己的脚本与动效。

**打开方式**：`file://` 直接开（本目录零外部资源：无 CDN、无外链字体、无位图）。
