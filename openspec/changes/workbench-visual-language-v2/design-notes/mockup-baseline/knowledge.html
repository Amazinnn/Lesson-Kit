容斥原理与二项式反演

容斥原理与二项式反演

设 A1, A2, …, An 是全集 U 的 n 个子集。容斥原理给出并集大小的一种不重不漏的计数方式： 先加上每个集合的大小，再减去两两交的大小，再加上三重交的大小，如此交替直到 n 重交。

容斥原理

对任意 n ≥ 1，有 | A1 ∪ A2 ∪ ⋯ ∪ An | 的容斥展开；每一项对应一类「恰好同时落在若干个集合里」的元素，重叠被逐层抵消。

| ⋃i=1n Ai | = ∑i=1n |Ai| − ∑1≤i<j≤n |Ai ∩ Aj| + ⋯ + (−1)n−1 |A1 ∩ A2 ∩ ⋯ ∩ An|

当 n = 2 时，上式退化为 |A1 ∪ A2| = |A1| + |A2| − |A1 ∩ A2|， 正是两集合的容斥公式；当 n = 3 时再把三重交加回来。

二项式反演

容斥原理的另一种写法是二项式反演：若对一切 n ≥ 0 有 g(n) = ∑k=0n (−1)k C(n, k) f(n − k)， 则 f(n) = ∑k=0n (−1)k C(n, k) g(n − k)。

  • C(n, k) 记作二项式系数，等于从 n 个元素中取 k 个的方案数。
  • 反演把「逐层排除」与「按元素个数计数」两种口径互换，是容斥原理在数列上的形式。
  • 应用时先写出 g(n) 与 f(n) 的关系式再逐项回代；符号交错处最容易出错。

做题经验

先判断「至少一个」与「恰好一个」的区别：容斥的每一项对应一类重叠， 用两个条件的差集先把「恰好」拆成「至少 − 恰好」，比直接加总更不容易漏项。

  • 三集合容斥中「一个都不属于」的处理顺序
