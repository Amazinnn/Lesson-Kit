单选

How many strings are there of four lowercase letters that have the letter x in them?

选择答案
你的作答
A 26⁴ − 25⁴ = 66351

解析

用补集法计数。长度为 4 的小写字母串共 26⁴ 个；其中不含 x 的串，每个位置有 25 种选择，共 25⁴ 个。 两类相减即得含 x 的串数：26⁴ − 25⁴ = 456976 − 390625 = 66351。选 A。 选项 B 误把「x 出现的位置数」当作「x 出现一次」，漏掉了出现两次及以上的情况。

当前对话
你

第 12 题我选了 A，但我不确定「减掉不含 x 的串」这一步算的是不是重复了。

Agent

不重复。含 x 的串与不含 x 的串互为补集，求和时每个串恰好落进一类。 注意这里的计数单位是「长度为 4 的串」，不是「位置」，所以出现两次 x 的串 只会落在含 x 的那一侧一次。

摘要：加法原理用于「分类计数」、乘法原理用于「分步计数」；含重复元素时用补集法 往往更短，且必须保证补集与原集互斥。
