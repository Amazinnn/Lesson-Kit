## 0. 口径与读法

### 0.1 处理类别（固定四类）

| 类别 | 含义 | 判据 |
|---|---|---|
| **删** | 注释性文字，直接去掉，**不换成更好看的说明文字** | 该文字不承载操作入口、不承载契约词汇、只做"解释界面在干嘛" |
| **改** | 措辞调整（长度、口径、语气、一致性） | 文字要留，但现状措辞与语气/口径/一致性不符 |
| **译** | 英文转中文 | 界面文案统一中文，英文术语一律落回 GLOSSARY 的中文名 |
| **留** | 已合适，不动 | 已经是动作、契约词、必要的事实披露 |

### 0.2 「冻结」的两种含义（必须区分）

| 标记 | 含义 | 处置 |
|---|---|---|
| **冻结·行为契约** | `openspec/specs/*/spec.md` 把该字符串作为**可观察行为**引用；或 `docs/GLOSSARY.md` 定义了它；或 `docs/PRODUCT-MANUAL.md:129-130` 的硬约束句 | **一个字都不能改**。要改必须先改 spec / glossary（另案） |
| **冻结·文档引用** | `docs/PRODUCT-MANUAL.md` 在正文里**引用**了这句界面文案，但引用的是"当前长什么样"，不是行为定义 | 可以改，但**必须在同一个 PR 里同步改 `docs/PRODUCT-MANUAL.md`**，否则就是 contract drift |

> 本表把所有"文档引用"型条目单列在 §6，并在「文档同步」列写明要改 MANUAL 的哪一行。

### 0.3 新文案的硬约束

1. **不得引入承诺性表述**：不得暗示掌握度、正确率、完成度百分比等未定义口径。
   GLOSSARY「覆盖 / Coverage」的 `_Avoid_` 明列「正确率、完成度百分比」；
   GLOSSARY「行动提醒 / Action Reminder」的 `_Avoid_` 明列「掌握度、分数、调度参数」。
   → 本表所有定稿文案里没有"正确率""掌握度""完成度 %"。
2. **不得引入新术语**：定稿文案只用 GLOSSARY 已有的中文名（试卷 / 记录 / 判定 / 自评 / 行动提醒 /
   目标 / 每日计划 / 复习负荷 / 时间安排 / Agent 工件 …）。
3. **空态文案必须与「插画 + 一句 + 满宽主按钮」相容**：句子不超过一句，主按钮文案本身就是动作。
   没有动作出口的空态，**不硬凑按钮**，只留「插画 + 一句」。
4. **不得改动 `docs/GLOSSARY.md` 定义的术语**，**不得改动 `docs/PRODUCT-MANUAL.md:129-130`**。

### 5.10 本节与其他节的关系

- §5 说的是**"这个词能不能动"**；§2 说的是**"这一整句怎么处理"**。
- 两者交叉时以 §5 为准：即使 §2 把某句判成「改」，只要改动会碰到 §5 列出的契约词，
  该条必须重判为「留」，或者先改 GLOSSARY / spec（另案）。
- 例：Q-44 `熟悉程度 1–5` → `自评 1–5` 是「改」，因为被替换掉的 `熟悉度` 本身是**禁用词**，
  不是契约词；`自评` 才是契约词，而新文案用的正是它。
- 例：R-28 `最近正确率` → `最近判定` 是「改」，`正确率` 是禁用词，`判定` 才是契约词。
