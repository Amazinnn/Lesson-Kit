# 验收清单 — workbench-visual-language-v2

> 本文件是**样板线的验收口径**。样板线通过与否，按本文件判定；不按印象判定。
> 验收方式由所有者选定：**对照截图 + 关键帧序列 + 交互清单**三件套。
>
> 相关：`proposal.md`（范围与冻结）、`decisions.md`（视觉基线）、
> `design.md`（实现方案）、`tasks.md`（任务拆解）。

## 0. 底线守卫（最高优先级，先于其它任何检查）

> 冻结项：**请求与持久化不变**。冻结 = API 请求序列与载荷、持久化内容、学习事实、
> 状态机、由请求驱动的可见性切换。

| # | 检查项 | 判定方法 | 通过标准 |
|---|---|---|---|
| G-1 | 一次完整练习的**请求序列**不变 | 在池副本上脚本化跑一遍练习（建卷 → 开始 → 逐题提交 → 自评 → 交卷 → 取答卷），记录服务端收到的**请求方法 + 路径 + 载荷键集合**；改造前后各跑一次并 diff | 序列与载荷**逐条相同**；新增/删除/改名任意一条即 FAIL |
| G-2 | 练习轮的**持久化结果**不变 | 同一次脚本化练习后，比对池中 `problem_attempts` / `feedback_events` / `practice_runs` 的行数与关键列 | 行数与关键列**逐行相同** |
| G-3 | 学习投影不变 | 同一份脚本化练习前后，比对受影响知识点/题目的当前状态与调度行 | 完全相同 |
| G-4 | 复习建议集合不变 | 比对改造前后同一时刻的到期项集合与弱项排序 | 集合与顺序**完全相同** |
| G-5 | **图谱页未被本变更触碰**（否定式断言） | 改造前后同一图谱页截图并排比 | 差异像素数 **= 0**。图谱**不在本变更的验收范围内**（`decisions.md` **A-8**：图谱的夜纸适配与节点视觉重设计归独立 change `graph-node-visual-language`）；零差异不是一条待达成的门禁，而是「本变更根本没碰它」的证明 |
| G-6 | 无新增学习事实 | 人工核对：新加的字段只存在于浏览器偏好（localStorage），池内零新增列、零新增行 | 池 schema **零变更** |
| G-7 | 装饰层不拦截交互 | 检查所有新增装饰层元素的 `pointer-events` | 装饰层一律 `none`；可交互元素不在装饰层内 |
| G-8 | 焦点顺序未因改造而改变 | 键盘 Tab 遍历录制改造前后的焦点序列（页面级） | 除**新增的设置视图入口与主题开关**外，序列相同 |

> G-1…G-4 的脚本要**同时**用于改造前与改造后，且跑在**池副本**上（见 §5）。
>
> **G-5 的读法（2026-10-22 按 A-8 改写）**：G-5 是**否定式**断言 ——
> 它不要求本变更把图谱改成什么样，只要求本变更**没有误伤**图谱。
> 图谱本身（夜纸适配、节点视觉重设计、亮色下的逐像素基线）的**执行与验收**
> 归 `graph-node-visual-language` change。
> 之所以仍保留这条断言：它是本变更唯一能证明「新 token 层没有牵连图谱」的证据。

## 2. 关键帧序列清单

动效不能只靠截图验收（截图看不到运动）。每个动效采一组帧，拼成一条**分镜条**。

> **动效 ID 对照**：本节的 `M-1`…`M-13` 是**分镜条编号**；
> 「对应 A-27」列给出 `decisions.md` **A-27.2 必须实现的动效清单**里的条目号
> （M-A…M-N）。`decisions.md` A-27.1 已定：mockup 是**静态评审件**，只呈现终态 ——
> **动效的实现要求由 spec delta 与 tasks 承载，验收看分镜条与真机，不看 mockup**。
> 因此**每一条动效都必须有分镜条**，缺一条即视为该动效未实现。

| # | 动效 | 对应 A-27 | 采样帧 | 通过标准 |
|---|---|---|---|---|
| M-1 | **台灯主题转场** | M-L | 0 / 90 / 180 / 330 / 500 / 700 ms 六帧 | 台灯探出 → 点亮 → 涟漪扩散 → 收回，**四段都在**；700ms 后终态干净；**涟漪期间卡片轮廓不被压平**（只有底色在变） |
| M-2 | 交卷庆祝（日常档） | M-F | 0 / 120 / 300 / 600 / 900 ms 五帧 | 数字滚动 + 进度带 0→100%；**无彩带**（彩带只在里程碑档） |
| M-3 | 交卷庆祝（里程碑档） | M-G | 0 / 150 / 400 / 800 / 1200 ms 五帧 | 在 M-2 基础上叠几何爆点 + 纸片；时长更长但**不遮挡完成页 CTA**；触发条件只有**两个**（全对 / 章节首次完成），两个条件各采一次，其余轮次留在日常档 |
| M-4 | 连对升级（5 连 / 10 连插播） | M-I | 0 / 100 / 250 / 450 / 700 ms 五帧 | 横幅出现 → 数字替换 → 退场；**横幅只有一份**，数字是参数化输入的结果 |
| M-5 | 连对计数器三档 | M-H | 三张静帧（0 / >0 / ≥30） | 灰 → 黄 → 黄蓝渐变，**不靠文字** |
| M-6 | 连对进度火苗簇 | M-J | 0 / 200 / 500 ms 三帧 | 火苗逐簇点亮；**答案错时必须出现负反馈**（不得沉默） |
| M-7 | 挤压回弹（答对） | M-B | 0 / 17 / 33 / 83 / 167 / 217 / 517 ms 七帧 | scale 0.92 → 1.06 → 1 的回弹曲线可见；总时长 ≈517ms |
| M-8 | 视图转场 | M-C / M-E | 0 / 60 / 120 / 240 ms 四帧 | 内容**上浮 8–12px + 淡入**；不得出现「硬生生蹦出来」；转场**挂在页面容器上**（切页整体替换 innerHTML 后仍播放） |
| M-9 | 骨架屏 | M-D | 0 / 400 / 900 ms 三帧 | 灰块**整体明暗呼吸**（底色变化可见；**无横扫、无表面渐变**，见 `decisions.md` A-115） |
| M-10 | 数据层（负荷柱 / 日历） | — | 0 / 240 / 480 ms 三帧 | 负荷柱从 0 生长、逐柱错峰；日历格按强度扩散（**颜色 + 高度双编码**） |
| M-11 | **连对断裂负反馈** | M-K | 0 / 80 / 200 / 400 ms 四帧 | 连对 > 4 时答错**必须**出现明确负反馈（**不得沉默**）；计数器归零；火苗簇逐簇熄灭；**不做屏幕级震动**（摆动幅度 ≤4px） |
| M-12 | **动效偏好与系统 reduced-motion 的分级降级** | M-M | 四张静帧（系统 reduce + 偏好未设 / 系统 reduce + 偏好显式「开」 / 系统允许 + 偏好未设 / 系统允许 + 偏好「关」） | 四种组合下的**终态与「动效开启」时逐项一致**；系统 reduce + 偏好显式「开」⇒ 动效恢复（显式选择优先于系统）；偏好显式「关」⇒ 全部直切 |
| M-13 | **关键反馈音效** | M-N | 四段波形（答对 / 答错 / 完成 / 里程碑） | 每条 **< 200ms**；**只在**这四个时刻发声（其它任何状态变化零发声）；首条之前**必须**有一次用户手势；静音时四段均为静音且**视觉反馈一个不少** |

**通用判据**：所有动效只用 `transform` / `opacity`；`prefers-reduced-motion` 下
全部降级为状态直切（M-1…M-13 各出一张降级对照帧）；
**降级帧的终态必须与动效开启时的终态一致**（数字、进度带、计数器档位、灯与涟漪层、
纸片、火苗簇、内容位置逐项比对），**不得停在中间态或不可见**。

## 3. 交互清单（逐条可勾选）

### 3.1 可访问性
- [ ] 每个可交互控件在键盘 Tab 时都有**可见焦点环**（不得被 `outline:none` 压死）
- [ ] 正文与背景对比度 ≥ 4.5:1；次要文字 ≥ 3:1；大字号 ≥ 3:1
- [ ] 状态**不只靠颜色**：每个状态都有几何编码（彩色圆点 / 形状 / 竖条）
- [ ] 每个状态都有**文字**（在需要时，例如 aria-label），但不靠文字承担主要表达
- [ ] 界面注释能删则删：改造后界面上的说明性文字**数量不增加**
- [ ] 动效全部尊重 `prefers-reduced-motion`
- [ ] 页面转场与浮层出现时，焦点不被抢走
- [ ] 图标有可访问名称（`aria-label` 或视觉隐藏文本）

### 3.2 主题与暗色
- [ ] 主题切换走**台灯转场**（不是瞬切）
- [ ] 夜纸下正文对比度复测达标（逐 token 实算，不目测）
- [ ] 夜纸下图标圆底为「降饱和 + 提亮」版本
- [ ] 夜纸下插画与图标用同一套 SVG 换变量，**不另画一套**
- [ ] 主题偏好按工作区存储，切换工作区各自独立
- [ ] 刷新与重启后主题偏好保持

### 3.3 声音
- [ ] 只有四个时刻有音效：答对 / 答错 / 完成 / 里程碑，每条 < 200ms
- [ ] 首次音效必须发生在一次用户手势之后（浏览器自动播放限制）
- [ ] 有静音开关，且默认状态与用户偏好一致
- [ ] 静音后**所有**音效不再播放（包括庆祝）
- [ ] 无音效时，动效与视觉反馈仍完整可用（声音不是唯一通道）

### 3.4 交互反馈
- [ ] hover 反馈可感知（120–180ms）
- [ ] active / pressed 反馈可感知
- [ ] 加载态有骨架屏 + 微光扫过
- [ ] 错误态明确（**红色仅用于失败与阻塞**）
- [ ] 空态 = 插画 + 一句 + 满宽主按钮，按钮文案就是动作
- [ ] 会话列表**可滚动**（不静默裁切）
- [ ] 章节透镜是自绘下拉面板，不是原生 select

### 3.5 响应式
- [ ] 1440 / 1280 / 1024 / 768 四档下三栏均可用，无横向滚动条
- [ ] 768 下右栏为抽屉，可关闭并返回中栏
- [ ] 抽屉打开时背景仍可交互（装饰层 `pointer-events: none`）

### 3.6 图案与资产（对应 P-2 图案适配原则）
- [ ] 全部图标与插画是**本地 SVG**，无外链、无图标字体、无位图
- [ ] 图标与插画在同一套线宽与圆角语言内（写意线稿 + 淡彩）
- [ ] 图标圆底色只用三角色色
- [ ] 插画为具象器物（不出现抽象几何团块）
- [ ] 深浅两套主题共用同一批 SVG 文件

### 3.7 性能
- [ ] 动效只动 `transform` / `opacity`（用 DevTools 录一次逐帧确认）
- [ ] 长列表（98+ 条记录）滚动流畅
- [ ] 首次加载无字体闪烁（`font-display` 策略正确）
- [ ] 静态资源缓存策略正确：改了 CSS 能立刻生效

### 3.8 动效与降级（reduced-motion 对照）
- [ ] **每条动效在 reduced-motion 下的终态与开启时一致** —— 数字、进度带、
      计数器档位、灯与涟漪层、纸片、火苗簇、内容位置**逐项比对**，
      **不得停在中间态、不得停在不可见状态**
- [ ] 降级后动效元素的**静态样式即终态**（起始态只写在 `@keyframes` 内部，
      不写进基础规则）—— 否则关闭动效会让元素永远停在「从未出现」的状态
- [ ] 四种组合（系统 reduce + 偏好未设 / 系统 reduce + 偏好显式「开」/
      系统允许 + 偏好未设 / 系统允许 + 偏好「关」）各出一张对照帧，
      且**显式选择优先于系统设置**
- [ ] 声音偏好与动效偏好**相互独立**：关闭动效**不影响**音效；
      静音**不移除**任何视觉反馈
- [ ] §2 的 M-1…M-13 **每条都有分镜条**（缺一条即视为该动效未实现；
      mockup 是静态评审件，不能替代分镜条 —— `decisions.md` A-27.1）

## 4. 通过标准

样板线**通过**需同时满足：
1. §0 的 G-1…G-8 **全绿**（底线守卫，任何一条红即整体 FAIL，不进入后续评审）；
2. §1 的 S-1…S-12 对照截图**无回退**（配色/圆角/信息未被改坏）；
3. §2 的 M-1…M-13 分镜条**符合各自标准**，且降级对照帧**均为状态直切**、
   **终态与动效开启时一致**；
4. §3 的交互清单**全部勾选**，或未勾选项逐条列出并说明为何可接受。

任一项不通过 → 回到 `tasks.md` 对应阶段返工，**不得**带着未过的底线项进入铺开阶段。
