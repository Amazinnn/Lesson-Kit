## 2. 为什么它是「正式基线版本」

| 依据 | 说明 |
|---|---|
| **它是 token 权威表的渲染版** | 样板图页脚自述：「权威来源：`night-paper-tokens.md` §2 与 §3，**逐条转写**；视觉基线以 `decisions.md`「收口：最终基线」为准」⇒ **不是另一套规格**，是权威的视觉副本 |
| **它是版式的可视参考** | `layout-spec.md` 是**写出来**的几何，V1 是**画出来**的同一套几何（逐项可对照） |
| **所有者裁定** | 2026-10-23：「**V1不挺好的嘛？要不干脆直接使用V1继续**」「**改后的就是垃圾。样板图就是最理想的。**」⇒ `decisions.md` **A-142 / A-143** |

**权威分工（A-143）**：

| 维度 | 听谁 | 理由 |
|---|---|---|
| 构图 · 气氛 · 版式数值 | **V1** | 所有者裁定 + 它是权威表的渲染 |
| **组件形态**（按钮/输入框/圆点/开关的样子） | **`component-spec.md` §4.30（A-115）** | ⚠️ V1 画于 10-22 14:31，**早于** A-115 落定（10-23 07:35）；A-115 含命中区 ≥44px 的硬约束 |
| token | `night-paper-tokens.md` | V1 与它本来就一致（逐条转写） |
| 图谱页 | 版式 §0.2「范围外」 | V1 的图谱页不作数 |
