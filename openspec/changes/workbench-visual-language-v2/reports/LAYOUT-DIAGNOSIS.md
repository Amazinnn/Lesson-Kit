## 1. 口径：这一份里的每个词是什么意思

### 1.1 什么算一个「面」（积木）

> 有 `background-color`（非透明）**或** `box-shadow`（非 `none`）**或**
> `border`（宽度 > 0 且 style ≠ `none`）**且**可见
> **且**边框盒面积够大的**块级**元素。

- **块级**：`display` ∈ {`block`,`flex`,`grid`,`flow-root`,`list-item`,`table*`}。
  `inline-block` / `inline-flex` 另计为「chip」（本轮没有一屏超过 3 个，未进主表）。
- **可见**：`display≠none`、`visibility≠hidden/collapse`、`opacity≠0`。
- **够大**：见下面两种口径（**两种都报**，这是本报告唯一一处口径分歧）。
- `html` / `body` 是**纸面本体**，不算积木（另记在 `canvas` 里）。

### 1.2 面积门槛的两种读法（**唯一分歧点，两组数都报**）

题干写的是「**面积** ≥ 100×40 px」，有两种读法，差别只在**又宽又矮**的元素上：

| 口径 | 定义 | 谁被差别对待 |
|---|---|---|
| **面积口径**（本报告主口径） | 边框盒面积 ≥ **4000 px²** | — |
| **尺寸口径**（对照口径） | 宽 ≥ 100 **且** 高 ≥ 40 px | **知识点列表的每一行**（660×38）被剔除 |

**这不是吹毛求疵**：知识点列表的 31 行知识点是 660×38 的卡，
**正好差 2px 落在尺寸口径的门外**。两种口径下知识点列表的面块数是
**42 vs 8** —— 差 5 倍多。**下一棒若只按尺寸口径看，会完全看不见这个页面最严重的问题。**

### 1.3 其它口径

- **列**：靠最近的祖先判定 —— `#middle-page` = 中列，`#left-column` = 左栏，`#ai-column` = 右栏。
- **位置**：用 `offsetLeft/offsetTop` 沿 `offsetParent` 链累加（**不受滚动影响**，可复现）。
- **嵌套深度**：面块套面块的层数（`body` 不计）。
- **竖向留白序列**：中列内按 `top` 排序走一遍；与当前「带」重叠的面**跳过**
  （它是同一带里的第二层，不是留白），否则记 `top − 带底`。
- **间距取值**：对**页面上每一个元素**统计 `row-gap / column-gap / 4 个 margin / 4 个 padding`
  的计算值（px），去重后按频次排。**这是样式表纪律指标，不是视觉指标**（见 §4.3）。
- **字号档**：对**有直接文本节点**（或 `input/textarea/select`）的元素统计 `font-size`。
- **视觉事件**：首屏内「有 paint 且面积 ≥ 400 px²（20×20）」的元素，
  按 `(底色, 阴影, 边框)` 三元组去重后的**种类数**（发丝线与 10px 状态点不算事件）。

### 4.1 「面太多」vs「尺寸/样式不齐」—— 裁决

**归一化口径**（每项 ÷ 参照线，页内取均值）：

| 页面 | 面族均值 | 面族超线项 | 尺度族均值 | 尺度族超线项 | 面/尺度 比值 |
|---|---|---|---|---|---|
| 练习页（组卷入口） | 0.93 | 2/6 | 2.43 | **4/4** | 0.38 |
| 练习页（已载入试卷） | 0.95 | 2/6 | 2.43 | **4/4** | 0.39 |
| 练习页（练习进行中） | 1.21 | 4/6 | 2.86 | **4/4** | 0.42 |
| 记录中心 | 1.38 | 3/6 | 2.79 | **4/4** | 0.49 |
| 知识点列表 | 1.38 | 3/6 | 1.99 | **4/4** | 0.69 |
| 试卷列表 | 0.81 | 2/6 | 2.09 | **4/4** | 0.39 |
| **六页合计** | **6.66** | | **14.59** | | **面 31% / 尺度 69%** |

**照字面读：尺度不齐占 69%，面太多占 31%。**

**但这个 31/69 不能直接拿去定方向 —— 它有一个已知偏差，必须当场说清**：

1. **尺度族四项（间距档 / 内距档 / 字号档 / 左边界档）全部超线，
   且「间距档」与「内距档」是同一件事的两个测法**：
   两者的散值高度重叠（1/2/5/6/7/9/14/18/20/22 px 同时出现在两者里）。
   ⇒ **尺度族被这一条重复加权了。**
2. **「间距取值档」是样式表纪律指标，不是视觉指标**：
   它对页面上**每个元素**统计（**含控件内部**），所以 2px/5px/7px 那种
   控件内距把种类数抬到 27–36。若只看**中列面块之间的留白**，
   每一页只有 **2–7 种**取值（§2.6）—— **视觉节奏并不乱**。
3. **组件尺寸其实已经很齐**：砖块群高度 σ = **0.0**（§3.2）、
   字号 **96.9%–99.3%** 命中 `--fs-*`（§3.4）、
   底色/阴影/圆角档数**全部 ≤ 参照线**（§2.2、§3.5）。

**⇒ 最终裁决（三条）：**

1. **积木感的形状由「面太多」决定，尺度由「组件已经很齐」决定。**
   31 张 660×38 的**一模一样**的带影卡（σ=0）堆在一起 —— 这才是"乐高积木"。
   **"把卡片尺寸调一致"这条路已经被数据堵死**（它们本来就一致）。
2. **「尺度不齐」确实存在，但只存在于两个具体地方，且都不是"卡片尺寸"**：
   - **间距刻度没被使用**：`--sp-1..8` 八档里只用了 6 档，
     另有 **20–29 个散值**（含 1/2/5/6/7/9/14/18/20/22/26px）；
   - **竖向节奏是两套**：章节级 28–40px vs 行堆级 6–8px（比值 3.5–5 倍）。
   ⇒ 这两条**不是"卡片乱"，是"页面没有统一的间距尺度"**。
3. **两族不是并列的两条路，是同一条路的两端**：
   去掉"每行一张卡"的面（→ 面变少）**并且**把行缝从 8px 提到页面节奏那一档
   （→ 节奏合一），这两件事改的是**同一段 CSS**（见 §5 的 P1 / P2）。
   **只做其一都不够**：只去面不改缝 → 行还在，但变成"一列带发丝线的文字"，
   仍与章节节奏脱节；只改缝不去面 → 缝大了，积木感变成"大积木"。

**⇒ 给下一棒的一句话**：**主力走「去面化」（把重复行从"每行一张带影卡"改成
"共享一个面 + 行间发丝线 / 表格行"），副力走「间距 token 化 + 节奏合一」；
不要把预算花在"统一卡片尺寸/圆角/阴影"上 —— 那三项实测都已经在参照线以内。**

### A.3 页内探针（判定"面"的核心 JS）

```javascript
() => {
  var BLOCKISH = d => d === 'block' || d === 'flex' || d === 'grid' ||
    d === 'flow-root' || d === 'list-item' || d.startsWith('table');
  var TRANSPARENT = {'rgba(0, 0, 0, 0)': 1, 'transparent': 1};

  function absPos(el) {                    // 不受滚动影响的位置
    var x = 0, y = 0, node = el;
    while (node && node.nodeType === 1) {
      x += node.offsetLeft; y += node.offsetTop;
      var op = node.offsetParent; if (!op) break; node = op;
    }
    return {x: x, y: y};
  }

  var all = Array.from(document.querySelectorAll('body *'));
  for (var i = 0; i < all.length; i++) {
    var el = all[i];
    if (el.namespaceURI === 'http://www.w3.org/2000/svg') continue;
    var cs = getComputedStyle(el);
    if (cs.display === 'none') continue;
    if (cs.visibility === 'hidden' || cs.visibility === 'collapse') continue;
    if (parseFloat(cs.opacity) === 0) continue;

    var w = el.offsetWidth, h = el.offsetHeight;
    if (w === 0 && h === 0) continue;

    var hasBg     = !TRANSPARENT[cs.backgroundColor];
    var hasShadow = cs.boxShadow && cs.boxShadow !== 'none';
    var hasBorder = false;
    ['Top','Right','Bottom','Left'].forEach(function (side) {
      if ((parseFloat(cs['border' + side + 'Width']) || 0) > 0 &&
          cs['border' + side + 'Style'] !== 'none') { hasBorder = true; }
    });
    if (!hasBg && !hasShadow && !hasBorder) continue;   // 没 paint ⇒ 不是面
    if (!BLOCKISH(cs.display)) continue;                 // inline 盒子另计

    var pos = absPos(el);
    /* 面积口径: w*h >= 4000 ; 尺寸口径: w >= 100 && h >= 40 */
    candidates.push({
      primary: (el.getAttribute('class') || '').trim().split(/\s+/)[0] || null,
      backgroundColor: cs.backgroundColor, boxShadow: cs.boxShadow,
      borderRadius: cs.borderRadius,
      paddingTop: cs.paddingTop, /* …另外三边… */
      left: pos.x, top: pos.y, width: w, height: h,
      right: pos.x + w, bottom: pos.y + h, area: w * h,
      hasShadow: hasShadow, column: columnOf(el),
    });
  }
}
```

### A.4 竖向留白序列（"节奏被卡片切断"的那把尺子）

```python
def vertical_gaps(surfaces):
    """按 top 排序走一遍；与当前带重叠的面跳过（它是同一带的第二层）。"""
    ordered = sorted(surfaces, key=lambda s: (s["top"], s["left"]))
    gaps, band_bottom = [], None
    for s in ordered:
        if band_bottom is None:
            band_bottom = s["bottom"]; continue
        if s["top"] >= band_bottom:
            gaps.append(int(s["top"] - band_bottom)); band_bottom = s["bottom"]
        else:
            band_bottom = max(band_bottom, s["bottom"])
    return gaps
```
