# IMPL-W3f2 — `records.py`：活动日历双编码 · 五档阈值具名常量 · 档位图例

> 服务于 `openspec/changes/workbench-visual-language-v2/tasks.md` **28.5**（D-14 的五档日历阈值进 spec）
> 与 **19.x** 的收口。**只改 `workbench/server/records.py` 这一个文件。**

## 背景（为什么现在做这件事）
第 28 组刚把 D-14 的五档日历阈值**写进了 spec**：
「活动日历**恰好五档**，次数区间固定 **0 / 1 / 2–3 / 4–7 / ≥8**，
『没有作答』这一档**有自己的层级、不回落底色**，页面给出**图例**，
阈值须在页面 / 样式表 / 手册**三处一致**」。

但实现只落了**一半**（已登记为 `contract-drift.md` **CD-170**）：
- 格子只有 **fill 一重编码**（`.record-activity-day` 无高度缩放）⇒ 规范要求的 **fill + height 双编码**缺一半；
- 「**0 次**」这一档靠基础底色兜底，**不是设计出来的档**（CSS 里只有 `.level-1..4`，**没有 `.level-0`**）；
- 页面**没有档位图例**（目前只有一句「颜色只表示当天的作答次数。」）。

## 硬约束
- **只改 `workbench/server/records.py`**。不碰 `workbench.css`（**另一个 agent 正在并行改它**）、
  `pages.py`、`workbench.js`、其它 JS、`docs/`、`openspec/`、`tasks.md`。
- **零新增请求、零写入、零学习数据变更** —— 记录中心是**只读历史页**。
- **数据口径一个字都不许改**：`_summary_cards` 的四个汇总数字（作答次数 / 已完成练习 /
  客观题正确率 / 平均自评）**取值与口径保持不变**。
- **不发明算法**：只做「已有数据的第二重编码 + 图例」，**不新增统计项**。
  ⚠️ **不画正确率曲线、不显示任何百分比**（GLOSSARY `_Avoid_`）。
  ⚠️ 「连续学习天数」**不做**（无数据源，CD-167 同理）。

## 要做什么

### 1. 五档阈值落成**具名常量**（唯一真源）
- 现在五档阈值是 `records.py` 里的**行内三元表达式**（唯一来源）⇒ 提成**具名常量**
  （例如 `_CALENDAR_LEVELS = ((0, 0), (1, 1), (2, 3), (4, 7), (8, None))` 之类，
  **你自己定名**，但要能一眼看出区间是 0 / 1 / 2–3 / 4–7 / ≥8）。
- ⚠️ 常量的区间**必须与 spec 一致**：0 / 1 / 2–3 / 4–7 / ≥8。
  **先读** `openspec/changes/workbench-visual-language-v2/specs/workbench-ui/spec.md`
  里刚补的 Records center 条款，按它的措辞来，**不要凭记忆**。

### 2. 格子落 **fill + height 双编码**
- 现有格子只按次数给**颜色档**（`.level-N` class）。⇒ 再加一重**高度**编码：
  同一档内，次数越多格子越高（**单调**），让「颜色看不出差别时」仍能读出量级。
- ⚠️ 高度是**第二重编码**，**不能取代**颜色档（颜色档承载「五档」这个契约）。
- 高度怎么表达由你定（**行内 style** 或已有的 class），但必须：
  - **同一档内单调**；**跨档也单调**（高档不低于低档）；
  - 高度只由**次数**决定，**不得**引入新的统计口径；
  - **零负荷日仍要占位**（与 20.1 的「不画柱但保留基线位置」同一精神：位置不能塌）。
- ⚠️ **0 次那一档**：给它**自己的一档**（`.level-0` 对应的 class 名与其它档对齐），
  **不要让它回落到底色**。CSS 侧会补 `.level-0` 规则（**不在你的文件里**）——
  你只需**用对 class 名**，并在回报里写明「CSS 侧需要补哪几条」。

### 3. 页面给出**档位图例**
- 现在只有一句「颜色只表示当天的作答次数。」⇒ 补一个**图例**：
  **五个色块 + 区间刻度**（0 / 1 / 2–3 / 4–7 / ≥8），让人能读出格子。
- 图例用**服务端渲染**（和页面其它部分同源），**不引新资源**。
- 图例的 class 名你自己定，但**要在回报里写清**，好让 CSS 波补样式。

### 4. 一致性自查
- 把「五档区间」在**代码常量 / 页面图例文案 / spec 条款**三处对齐（AGENTS.md 要求三处一致）。
- 回报里贴出**三处的实际内容**（常量定义、图例文案、spec 条款摘录）供核对。
