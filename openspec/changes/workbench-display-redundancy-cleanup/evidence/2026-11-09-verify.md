## 2.2 A1 四态手测（pin 能力未丢）— PASS

钉住面 = 练习页题号格（`.paper-dot`）的小问状态卡（`.part-preview`，portal 至 body）。真实输入驱动：

| 态 | 断言 | 结果 |
|---|---|---|
| hover | mouseenter → 卡 `hidden=false`，内容「小问 1：已提交 · …」 | PASS |
| keyboard focus | dot 为 `<button tabindex≥0>`，`dot.focus()` + focusin → 卡显示 | PASS |
| 点击钉住 | 卡 click → `aria-pressed=true`；**mouseleave 后仍保持显示**（钉住语义） | PASS |
| Esc 解除 | document keydown Escape → `hidden=true`、`aria-pressed=false` | PASS |
| reduced-motion | emulateMedia(reduce) 下 hover/点击钉住/Enter 切换/Esc 全部照常 | PASS |

四态之外：dot 自身无任何多余小字标签（题号格干净），卡文本为小问状态语义行。
