## Goals / Non-Goals

**Goals:**

- 顶栏段三不再是空的 —— 四个控件在**任何视口宽度**都在。
- 会话列表按今天/昨天/更早分组（不引入计数）。
- 优先回看条目带状态点，颜色 + 几何双通道。
- 左栏首组为「学习」，工作区身份在顶栏段二。
- 每波交付「靶子 | 改前 | 改后」三列对照板。

**Non-Goals:**

- 组件形态的任何改动（听 A-115）。
- 图谱页（`layout-spec` §0.2）。
- 任何新的后端能力 / 新请求 / 新载荷 / 新持久化字段。
- 顶栏搜索的**检索通路**设计（见 Open Questions）。

## Decisions

### D-1 四个控件全部复用既有机制，不新增

| 控件 | 复用什么 | 备选（否决） |
|---|---|---|
| Agent 对话开关 | 已在库的 `#layout[data-ai-collapsed]`（第三轨归零）⇒ 桌面端折叠右栏 | 新增一个「面板可见性」状态机 —— 否决，多一套真值 |
| 主题（夜纸）开关 | 已在库的 `saveSetting("theme", …)` + `html[data-theme]` | 新写一套偏好存储 —— 否决 |
| 对话视图开关 | 已在库的 rail 视图切换（列表 ⇄ 会话） | 重新做一套 —— 否决 |
| 工作区切换 | 已在库的 `<select id="workspace-select">` ⇒ **搬进顶栏段二**，不自绘下拉 | 自绘下拉 = B 类新界面，须另立 change —— 否决 |
| 搜索 | 已在库的**知识图谱页搜索框**（`#graph-search`，产品里唯一真的会查东西的检索控件）⇒ 顶栏按钮跳过去 | ① 新建检索端点与结果面 = 新请求 + 新载荷 ⇒ 撞冻结边界；② `retrieval-evaluation` 的 spec 明文「SHALL NOT integrate with the student UI」；③ **假搜索框**（点开什么都不查）—— 比没有更糟 |

⇒ **本 change 的前端增量是「把既有控件摆到 V1 的位置 + 加分组 + 加状态点」，不是造新组件。**

### D-2 会话分组在**客户端**做

分组的输入是会话条目已有的时间戳 ⇒ 客户端按日期分桶即可。
**备选**：服务端分组（需要新端点 + 新载荷）⇒ **否决**：触碰「请求与载荷不变」的冻结边界。

### D-3 优先回看的状态点：状态集就是**行动提醒**的三态，几何复用既有的状态几何

- **状态集 = `docs/GLOSSARY.md`「行动提醒」的三态**（学生侧唯一允许的状态词汇）：
  **重点练习（红 cross）/ 可以复习（黄 dash）/ 其余保持中性（中性墨 ring）**。
  ⚠️ **不新造词**：第三态**没有词** ——「保持中性」＝不作任何掌握断言；
  另造一个「未开始」就会变成**第四个**学生侧词汇，与「行动提醒」条目冲突。
- **颜色与几何取 `component-spec.md` §3.6 / §4.14 的映射表**
  （「到期 / 需复习 = 黄 dash」「阻塞 / 卡住 = 红 cross」「未开始 / 待办 = 中性墨 ring」）。
  ⚠️ 靶子与本节早先的草稿写的是**蓝 ring** —— **按权威走中性墨环**：
  蓝环在 §3.6 里是「当前 · 交互层（选中项）」，挂在左栏回看条目上会被读成「已选中」；
  且产品的状态点家族**没有蓝色档**，按蓝环落地就得新造一个颜色档。
  ⇒ 已登记为契约漂移（`contract-drift.md`），并回改本节措辞。
- 映射的输入是**理由类别**：有学习信号 = 重点练习；无信号但复习已到期 = 可以复习；
  其余 = 中性。**不是分数阈值** —— 阈值会随公式漂移，词不能漂。
- **契约词先落地**：本次**不需要新词** ⇒ `docs/GLOSSARY.md`「行动提醒」条目写清
  （左栏回看条目用同一套三态、第三态没有词），`copy-table.md` §5.1 同步登记。
- **状态在服务端渲染路径上算**（`weak.review_states` 纯函数）⇒ `/api/w/{name}/weak`
  的载荷仍是原四个字段，**请求与载荷不变**。
- **备选**：用 `score` 的数值阈值直接分档 —— 否决：阈值不是契约词，语义会漂。

### D-4 状态点的几何用**已有的**状态几何，不新画

产品的状态点家族叫 **`.lk-dot`**（`workbench/server/static/workbench.css`），
已有 10px 盒 + 6 种几何（filled / ring / half / dash / cross / check）的实现口径 ⇒ 复用，
**不新增一套**。⚠️ 本节早先写的 `.status-dot` 家族名**全仓零命中**（真实名是 `.lk-dot`）
⇒ 已登记为契约漂移（`contract-drift.md`）。

## Risks / Trade-offs

- **[顶栏动作区会挤压段二]**（窄视口下四个控件 + 身份 + 章节透镜挤在一起）
  → 缓解：≤1279 时按 V1 的形态收窄（图标按钮 40×40，文字隐藏）；段二 `max-width:36ch` 截断。
- **[搜索入口的检索通路未定]** → 缓解：见 Open Questions；实现时**不放假搜索**
  （一个不查东西的搜索框比没有更糟）—— 若通路未定，先只做其余三个控件。
- **[状态词表尚未定]** → 缓解：先落 `docs/GLOSSARY.md`，再实现；不在产品里试词。
- **[与 v2 的 delta 冲突]**（同三条 requirement）→ 缓解：归档顺序 **先 v2 后本 change**；
  本 delta 以 v2 当前文本为底，已在 `specs/workbench-ui/spec.md` 顶部写明。
- **[工作区切换器上移会改 DOM 身份]** → 缓解：`<select id="workspace-select">` 的 **id 不变**
  ⇒ `workbench.js` 的既有绑定与测试照旧；只挪位置。

## Migration Plan

1. 本 change 全部是**前端呈现 + 一处 DOM 位置调整**，无数据迁移。
2. 回滚 = `git revert` 对应提交；无不可逆步骤（无 schema、无载荷、无请求变化）。
