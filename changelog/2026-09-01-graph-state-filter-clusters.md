# 知识图谱支持多状态筛选与分群

**日期：** 2026-09-01
**类型：** 前端功能

## 变化

- 图谱工具栏新增学习状态筛选，可同时选择 `needs_work / review / mastered / null`。
- 未选择时显示完整图谱；选择多项时按并集保留节点和两端均可见的关系。
- 不匹配节点与关联边先淡出再离开布局，清除筛选后重新浮现。
- 筛选后的各状态拥有独立聚类中心；跨状态关系降低布局拉力但仍保持可见。
- Agent 图谱上下文同步携带当前多选状态。
- 减少动态效果模式直接绘制稳定分群结果。

## 不变

- 状态字段仍只有 `needs_work / review / mastered / null`。
- 筛选不改变投影、练习选区、学习状态或调度数据。
- 关系管道的立体视觉另行实现。
