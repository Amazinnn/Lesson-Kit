# consolidate-practice-views：三页导航 + 准备练习列表 + 按需候选

按 `openspec/changes/archive/2026-08-29-consolidate-practice-views/` 实现
（提案经专题 19 改判后先行，PR #16 文档 / PR #17 实现 / 本 PR 归档）。

## 内容

- 导航回三页（练习 / 知识点 / 知识图谱）；第 4 导航页「复习」及其到期
  分组列表、方向卡会话 UI、复习页时间区块全部拆除（专题 18 + 专题 19）。
- 练习页「准备练习」区块：列表 = 当前知识点选区（`wb_kp_selection_{ws}`）
  的行视图，行 = 知识点名 + ✕ 清除，与知识点页/图谱勾选双向同步；
  零新存储、零 schema 变化。
- 候选按需拉取：「＋ 加今天要练的（N）」按钮（N = 候选数），点开才展开；
  行 = 知识点名 · 一个短语 · 加入。来源 = 计划队列 ∪ 到期
  （`queries.review_overview`），映射到知识点级去重，一行只留一个短语
  （到期短语优先：`拖了 N 天` / `今天到期`；计划行沿用既有原因文案）；
  已选定的不出现在候选；cap 20 + 「还有 N 条」；「重算计划」按钮迁入
  候选区；「今天先做」队列卡片解散，计划输出降为候选来源之一。
- 时间安排（月历 + 14 天柱状 + 重日预填）原样搬移至练习页右栏，
  `practice-columns` 双栏（1023px 断点纵向堆叠）；`/calendar` 端点不动。
- 方向卡 UI 全拆（提示条/卡片流/1–5 评分卡/start-card-review）；
  `pull.include_ids`、`feedback.direction`、每方向独立调度键全部保留
  （include_ids 暂无 UI 消费者）；已确立规格「Directional card practice」
  由「Directional schedule entries」（仅调度语义）取代。
- 顺手：删除 `pages.py` 成对重复的第一套死函数定义；修复主按钮禁用态
  样式（浅灰底灰字，不再像可点的品牌色）。
