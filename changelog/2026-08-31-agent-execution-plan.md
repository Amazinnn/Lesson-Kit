# Agent 执行计划视图（2026-08-31）

## 结果

- Agent 对话把 Codex / Claude 的命令、工具、搜索与回答生成显示为逐条执行计划。
- 同一活动从进行中原位更新为已完成或失败，不再把原始协议状态码写进状态栏。
- 工具与命令输出可展开查看；长标签、命令和输出不会溢出右栏。
- 流式回答仍合并为一个普通回答气泡。
- 成功轮次保存合并后的执行计划，重新打开对话可以恢复。
- hidden reasoning 不显示正文；失败与取消仍不进入成功会话镜像。

## 兼容

- 旧会话没有 `activities` 字段时照常渲染。
- 旧的 phase / text / result / error / done 轮询事件继续可读。
- Provider 命令、页面上下文、学习写入与 Agent 右栏生命周期均未改变。
