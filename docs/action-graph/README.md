## 铁律（所有者钦定，变更须所有者点头）

1. **严禁显式命令面板**——不在界面上加"一列可点的动作按钮"，动作触发只走
   对话内自然语言→结构化动作（`replace_practice_selection` 模式的推广）；
   CLI 是外部 Agent 的通道，保留可能性但不主动扩张界面。
2. **动作结果的呈现分型**：结果独立于现有功能的（报告/视图类）→ 对话框内；
   结果融入现有功能的（Agent 填目标/计划字段等）→ 版面原位直接变化。
3. **Agent 对池子的权限**：知识点池与全部题目池，Agent 可经 CLI 增删改查；
   门禁步骤是决断辅助，不是权限闸门（2026-08-29 问卷 B1）。
4. **标签一律完整显示**，不截断、不省略号（承 UX 阶段铁律）。
