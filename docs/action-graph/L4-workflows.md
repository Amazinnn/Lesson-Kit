# L4 · 工作流层（用户真实路径 + 全部意外分支）

> 本层是 v2 的灵魂：**不许只画 happy path**。用户会回退、放弃、跳过、直接关闭——
> 每个出口都要有分支和落点。每条边可回溯 L3 动作；每个写库节点可回溯 L0。

## W1 · 练习回路

```mermaid
flowchart TD
  A[选范围<br/>图谱勾选/知识点页/建议区/kp 直达] --> B{模式+自评时机<br/>都选了吗?}
  B -- 否 --> B1[开始按钮禁用·等待] --> B
  B -- 是 --> C[开始本轮练习 · 会话聚焦]
  C --> D{内容类型}
  D -- 闪卡 --> E[看正面→揭示背面]
  D -- 微题/判断 --> F[点选作答→本地判分横幅]
  D -- 综合题 --> G[写解答→提交→查看解析]
  E -- immediate --> H[即时自评 1-5]
  E -- batch --> I[标记 unrated · 等收束]
  F -- batch: 横幅停 2s --> J[自动推进]
  F -- batch: 不想等 --> K[跳到下一道 · 立即走]
  F -- immediate --> H
  G --> H
  H --> L[四件套原子写<br/>事件/信号/状态/调度] --> M{还有下一张?}
  I --> N[上一张/下一张自由回翻<br/>状态保留 · 末尾才拉新]
  N --> M
  J --> M
  K --> M
  M -- 有 --> D
  M -- 拉空·诚实空态 --> O{自评时机}
  O -- batch --> P[自动进收束页]
  O -- immediate --> Q[空态提示+回模式选择区]
  M -- 提前结束 --> O2{自评时机}
  O2 -- batch --> P
  O2 -- immediate --> Q
  P --> R[逐题补分→四件套写入] --> S[再练同类?]
  S -- 是 --> C2[同 KP 新一轮] --> C
  S -- 否 --> T[结束 · 恢复学习安排区]
  X1[中途刷新] -.恢复游标+揭示/判分态.-> D
  X2[直接关标签页] -.草稿蒸发·已评分在池安全.-> Z[(池不变)]
  X3[batch 耗尽后又回 practice] -.ended 标志.-> P
  X4[网络失败] -.原位报错+重试.-> M
  X5[kp 直达且范围不符] -.丢弃旧会话重开.-> C
```

要点：跳过不降级（已作答/已揭示的条目保持 unrated 等收束）；横幅纯本地不写库；
刷新恢复到"翻到哪一张、揭示没揭示"；耗尽与提前结束在 batch 下同归收束页。

## W2 · 内容入库（唯一合法写池通道）

```mermaid
flowchart TD
  A[产出 manifest<br/>人手写 / 未来 Agent 生成] --> B[副本演练<br/>隔离注册表+拷贝池]
  B --> C{门禁过?}
  C -- 拒收: 重复id/契约违例 --> C1[改 manifest 重投] --> B
  C -- 过 --> D[真实池整池备份<br/>pool/backups]
  D --> E[单事务 apply]
  E -- 中途失败 --> E1[整批回滚 · 池原样] --> C1
  E -- 成功 --> F[计数核对+走查抽查]
  F -- 发现内容差 --> G[入错池处置] --> G1[现在: 恢复备份重做]
  G -.Check 落地后.-> G2[批次 id 一条命令整批撤销]
  F -- OK --> H[PR 归档 · 备份留档]
```

## W3 · 目标与计划（含缺口标记）

```mermaid
flowchart TD
  A[填目标表单<br/>名称/类型/截止/说明] --> B[创建 · 卡片+月历即时可见]
  B --> C{想改/想删?}
  C -- 是 --> X1[❌ 缺口: UI 无编辑/删除入口<br/>API 已备 · 队列③补] --> X2[临时通道: 数据层直改]
  C -- 否 --> D[月历/工作量只读视图]
  E[重新安排] --> F[每日建议重算 ≤3 条]
  F -- 计算失败 --> F1[保留上次有效结果 · 不报错堆栈]
  F -- 出现重日 --> G[prefill 一句话进 AI 输入框<br/>只预填 · 不发送]
  Y1[自然语言设目标] -.队列③: Agent 筛 KP 归属+填字段.-> Y2[版面原位: 卡片字段直接变化]
  Y3[goals CLI] -.队列③: 补命令.-> B
```

## W4 · Agent 对话与动作

```mermaid
flowchart TD
  A[新建对话] --> B{本机有 provider?}
  B -- 无 --> Z1[降级: 暂无可用 Agent 提示<br/>非 AI 功能全部照常]
  B -- 有 --> C[选 provider · 创建即锁定]
  C --> D[发消息 · 自动附页面上下文<br/>当前题/模式/进度/图谱选择]
  D --> E[provider 原生运行 · 事件流回传]
  E -- done --> F[结果进对话流]
  E -- 掉线/超时/退出 --> F1[如实报错 · 不换 provider 不装死]
  E -- 运行中再发 --> F2[409 拒绝 · 单轮次串行]
  E -- 点停止 --> F3[本轮 cancelled · 不留半截记录]
  F --> G{产出带结构化动作?}
  G -- 有明确练习意图 --> H[replace_practice_selection<br/>选区一次性替换]
  G -- 普通对话 --> I[绝不写任何学习记录]
```

## 意外分支总清单（防"想当然"复查用）

| # | 意外 | 落点 |
|---|---|---|
| 1 | 中途刷新 | 牌组恢复（游标+视图态） |
| 2 | 直接关标签页 | 草稿蒸发；已评分在池安全 |
| 3 | 跳过单题 | 不写库不记欠账；已答/已玩不降级 |
| 4 | 跳过到底直接走 | 空态/收束页，不强迫评完 |
| 5 | 提前结束 | batch→收束页；immediate→回开始区 |
| 6 | batch 耗尽后再回练习页 | ended 标志自动重回收束页 |
| 7 | 拉空范围 | 诚实空态，不偷换内容 |
| 8 | 网络失败 | 原位报错+重试，不吞操作 |
| 9 | 门禁拒收 | 改 manifest 重投，池零污染 |
| 10 | apply 中途失败 | 单事务整批回滚 |
| 11 | 入错池 | 备份恢复（Check 后：整批撤销命令） |
| 12 | provider 掉线/超时 | 如实报错，会话仍锁定 |
| 13 | 双发消息 | 409 串行 |
| 14 | 无 provider | 全功能降级可用 |
| 15 | 目标想改/删 | ❌ 现为缺口（队列③） |
