# L4 · 工作流层（用户真实路径 + 全部意外分支）

> 本层是 v2 的灵魂：**不许只画 happy path**。用户会回退、放弃、跳过、直接关闭——
> 每个出口都要有分支和落点。每条边可回溯 L3 动作；每个写库节点可回溯 L0。

## W1 · Paper → Practice Run 练习回路

```mermaid
flowchart TD
  A[明确 Scope<br/>知识点页/图谱/建议/Agent] --> A1[当前 UI 选择一个兼容模式<br/>exam/micro/yes_no/flash_card]
  A1 --> B[Paper Assembly<br/>按所选模式与来源·难度·薄弱·到期·错题组卷]
  B --> C{组卷有内容?}
  C -- 否 --> C0[诚实空态<br/>调整 Scope/约束后重组] --> B
  C -- 是 --> D[冻结 Paper item 顺序]
  D --> E[开始 / 恢复 Practice Run<br/>当前 UI 每轮固定一种内容模式]
  E --> F{本轮选定的 item 形式}
  F -- 闪卡 --> G[回忆→揭示]
  F -- 微题/判断 --> H[点选→本地判定]
  F -- 综合题 --> I[作答→揭示解析]
  F -- 跳过 --> N
  G & H & I --> J{当前自评设置}
  J -- immediate --> K[记录自评/学习结论]
  J -- batch --> L[保留待统一自评状态]
  J -- off --> M[按既有 off 规则结算]
  K & L & M --> N{Paper 还有 pending item?}
  N -- 有 --> F
  N -- 无 --> O{需要 batch 收束?}
  O -- 是 --> P[统一自评收束页] --> Q[归档 Practice Run]
  O -- 否 --> Q
  E -- 提前结束 --> O
  Q --> R{再练同类?}
  R -- 是 --> B2[据结果与 Scope<br/>重新组新 Paper] --> C
  R -- 否 --> S[回练习出发页]
  X1[中途刷新] -.恢复 frozen items + cursor<br/>不重新组卷.-> E
  X2[直接关标签页] -.已落盘结算保留<br/>未提交草稿按既有恢复策略.-> Z[(当前 Paper 不变)]
  X3[网络失败] -.原位报错 + 重试<br/>不换 Paper.-> E
  X4[运行中改 Scope/筛选/章透镜] -.只影响下次组卷.-> B
  X5[练习页发消息问 Agent] -.只带聚焦上下文·零写入.-> Z
```

核心不变量：**Scope 回答想练什么，Paper 回答这次具体做什么，Practice Run 只负责把这张 Paper 做完。**
任何建议、筛选、调度或对话都不得向运行中的 Paper 动态加题；“再练同类”永远组新 Paper。
刷新恢复 frozen items 与游标而不重新组卷；提前结束仍走既有 batch 收束规则；网络失败原位重试；
直接关闭只保留已经落盘的事实。跳过继续保持现有“不凭空写学习证据”的语义。

当前练习 UI 仍用单一兼容模式组装和启动每轮；混合格式 Paper 的 learner UI 尚未交付。

> 2026-09-25（in-place-problem-edits）：入库之后改题不再等于「删除重导」。原地补丁保留题号与全部学习记录，可把选项从题面拆进 `options` 让旧单选题变成小测题，整批存旧值可 `rollback` 还原；判断题/单选题的题干上限同时从 200 放宽到 800 字。批量修改只在学生明确要求时执行。
> 2026-09-26：题干上限取消（真题长篇客观题不再被退回综合题），摄入门禁与原地改题同步生效。

> 2026-09-25（ingest-mode-choice-and-contract-parity）：入库时可选题型——判断题（`quiz_type: yes_no`）
> 与单选题（`single_choice`/`multiple_choice` + 选项）即使**题源没有答案键**也能入库：这类题不判分，
> 练习页写明「本题未录入答案键」并由学生自评，答案键可事后用 `data update problem` 补；普通题目（不给
> `quiz_type`）进综合题，声明小测/判断模式却不给 `quiz_type` 会被拒收。学生一次说清的章要一轮导完，
> 前一章入完不再问「要不要继续」；章推不出来（该项与清单顶层都没有 `chapter`）时点名拒收，不再
> 静默按当前章落库。

> 2026-09-25（cross-chapter-content-bundles）：清单可跨章（每项声明自己的 `chapter`，缺省顶层→当前章），
> 发号/落图按该项的章，题目身份重复检查覆盖整个课程；按章各记一个批次，因此回滚可以只撤其中一章；一轮回复里的每个
> content-bundle 区块都会被依次应用（各自一份恢复副本），不再只应用第一个。

> 2026-09-29（content-dedup-and-audit）：先用 `lesson-kit data <workspace> audit` 读取题库卫生基线；新题按完整题干身份跨来源、跨章节拒重。apply 后已有内容被修改时，回滚先报告冲突，不创建回滚备份、不覆盖后续内容。

## W4 · Agent 对话与动作

```mermaid
flowchart TD
  A[新建对话] --> B{本机有 provider?}
  B -- 无 --> Z1[降级: 暂无可用 Agent 提示<br/>非 AI 功能全部照常]
  B -- 有 --> C[选 provider · 创建即锁定]
  C --> D[发消息 · 自动附页面上下文<br/>可见正式题 + 同一练习最多4道前序已结算正式题<br/>明确相对指代才改变轮次焦点]
  D -. 问题需要历史依据 .-> D1[CLI evidence<br/>按知识点读有界作答事实]
  D1 --> E
  D --> D0[浏览器先保存消息/上下文/提交标识<br/>再清空输入框]
  D0 --> Dsend[POST turns · 带 submission_id]
  Dsend -- accepted --> E[provider 原生运行 · 事件流回传]
  Dsend -- unknown response --> F5[本地发送箱标记未知<br/>核对时复用同一标识与内容]
  F5 --> Dsend
  Dsend -- definite rejection --> F6[本地发送箱保留原文供恢复<br/>不覆盖较新的草稿]
  E -- done --> F[结果进对话流]
  E -- provider 失败/取消 --> F1[轮次记录保留用户消息/真实状态<br/>仅显示实际部分回答]
  F1 --> F7{显式重试?}
  F7 -- 是 --> F8[新关联轮次 retry_of<br/>不自动重放操作或写入]
  F7 -- 否 --> I
  E -- 真静默超预算 --> F4[如实报错 provider timed out<br/>时长本身不算超时]
  E -- 运行中再发 --> F2[409 拒绝 · 单轮次串行]
  E -- 点停止 --> F3[本轮 cancelled<br/>保留消息/状态及实际部分回答]
  F --> G{产出带结构化动作?}
  G -- 有明确练习意图 --> H[replace_practice_selection<br/>仅替换组卷 Paper Scope]
  H --> H1[返回练习出发页<br/>组装 Paper / 开始 Practice Run 仍需单独操作]
  G -- 普通对话 --> I[绝不写任何学习记录]
  A5[工件动作 paper_artifact<br/>只按已保存试卷记录] --> A6[对话内工件卡<br/>最新一张可临时预览]
  A6 --> A7[显式点击后去组卷页]
```

工具结果卡展示归一化的动作与终态；只有后端证据支持时才说明已知影响，否则标为未知。诊断折叠并脱敏；没有对应后端操作时不提供单步重试。

> 2026-10-12（agent-context）：当前可解析正式题是页面锚点；只有它属于同一 active practice 时才附前序题。否定或同时比较当前/上一题的表达保留页面默认焦点，未知题号与闪卡号不形成正式题焦点；这条上下文读取不写学习记录或移动游标。

> 2026-09-25（bridge-timeouts-follow-progress）：原 `E -- 掉线/超时/退出 --> F1` 拆成两条——
> **时长本身不构成超时**，只有静默超预算才失败。预算按静默计：任一输出行或归一事件重置时钟，
> 命令/工具在飞时改用更长的工具预算（`bridge add --timeout` / `--tool-timeout`，`bridge list`
> 报生效值），因此 3 分钟以上的回答与长时间安静的构建都不会被截停，也不会再把正在运行的命令
> 一起杀掉；真卡住时仍如实报 `provider timed out`。
