# PRODUCT-MANUAL — lesson-kit 产品说明书

> **这是一份面向使用者的功能说明书**，讲「这个东西怎么用、每一步会发生什么」，不讲实现。目标是用足够的细节让使用者对每个操作都有准确预期——宁长勿略。
>
> **写作纪律（与 AGENTS.md 同步）：**
> 1. 正文里的每一个设计名词必须在 `docs/GLOSSARY.md` 有条目；没有就去补条目，不许裸用。
> 2. 行为描述不确定时，写「以 openspec 规格为准」并附规格文件名；**禁止编造未实现的行为**。
> 3. 每章头部标注：目标深度 / 当前完成度 / 权威规格。
> 4. 每次功能变更交付时，同步补写对应章节（AGENTS.md 交付纪律）。目标态是极详尽（十万字量级），靠逐次变更长出来，不一次编成。

**全书的恒等式（先记住这一句）**：只有你**显式提交 1–5 自评**（或在图谱里显式改状态）才会写入学习记录；浏览、勾选、草稿、跳题、翻看，一律不写。调度只影响排序与建议，永不锁题，参数永不出现在你眼前。

## 1. 这是什么

**目标深度：短。完成度：✅ 已成文。权威：README、philosophy。**

lesson-kit 把你的课程材料变成一个可以天天用的学习台：知识点、题目、你的评分记录、一条只做背景提醒的遗忘曲线，加上一个可以提问的 Agent 对话栏。它为你每天回答一个问题——**今天练什么**——但决定权始终在你：练什么范围、用哪种模式、什么时候打分，全部由你显式选择，系统只建议、不代劳。

它明确**不**承诺的事：不自动判开放题（主观题永远是你看了解析自己打分）；不替你安排计划外的任务（建议永远可无视）；不显示任何算法参数（没有间隔、难度系数、掌握度百分比——你只会看到「重点练习」「可以复习」这样的人话）；不锁题（任何内容任何时候都能练）。

工作台是三页结构：**练习**（主页）、**知识点**（列表与详情）、**知识图谱**，外加一条常驻右侧的 **Agent 对话**栏。没有更多的页面，也没有藏起来的功能入口——你看到的就是全部。

视觉采用柔和蒙德里安语言：暖纸色是大面积背景，深色线条划分三栏；蓝色用于
主要动作和选中，黄色用于当前阶段与复习提示，红色用于重点练习和失败。颜色
旁始终还有文字、轮廓或位置提示，不要求靠辨色理解状态。

**怎么把它跑起来**：在仓库根目录 `lesson-kit daemon start`（后台服务，进程号与日志记在用户级目录），`lesson-kit dashboard` 一步到位——没在跑就起、然后打开浏览器；`lesson-kit daemon status` 看状态、`daemon stop` 收工。想看着日志占用一个终端就换 `lesson-kit serve`（前台运行，Ctrl+C 停）。全新开始很简单：**站进课程文件夹跑 `lesson-kit init`**——文件夹名是 ASCII 时直接当课程缩写，文件夹里已有池则用池名，中文名的文件夹自动分到一个顺序短码（`c01`、`c02`…，只当机器内部的下标）。它会建好池和骨架再注册，文件夹名会成为工作区名（中文也可以，顶栏显示的就是这个名）。要换课程或章节，`lesson-kit use <课> <章>`，不用重新注册。感觉哪里不对劲（页面打不开、Agent 不出现）先跑 `lesson-kit doctor`：它只读地检查注册表、每个池数据库、各 Agent 可执行文件和服务端口，把有问题的条目逐行列出来，但不会自己动手改任何东西。

**一个工作区 = 一门课**：这是本项目的硬性局限，不是建议。工作区的池、附图、会话镜像、计划与目标文件都只在自己的文件夹里，页面/命令/Agent 桥构造的路径全部限定在这个文件夹内，跨工作区的会话或内容 id 会被直接拒收——所以两个学科各自建一个文件夹、各自 `lesson-kit init`（中文名文件夹照样零参可用）。要在两门课之间切换，就在 Dashboard 的工作区列表里点另一个，或者给命令带上工作区名（多个工作区存在时，不带名的命令会拒绝执行并把可粘贴的命令写给你）。同一个文件夹里出现多份 `pool/*.db`（例如备份副本）时，`init` 不会替你猜哪份是主库，而是让你用 `--course` 指名。

## 2. 开始一天的学习（练习页）

**目标深度：极详。完成度：✅ 首批成文。权威：workbench-ui spec、consolidate-practice-views（专题 19）。**

打开工作台，默认落在**练习页**。它是你的主页，从上到下回答一个问题：今天做什么。

### 2.1 学习安排：长期与阶段目标

页面最上方是「学习安排」区，展示你的**目标卡**：每张卡有标题、截止日期（如「截止 2026-08-31」），写了解说的目标还能展开「查看说明与范围」看原文。没有目标时会如实显示「暂无已设置的长期或阶段目标」——系统不会替你编造目标，也不会生成「课程规划」之类的空话。

点「▶ 添加目标」展开表单：填目标名称、选类型（阶段目标 / 长期目标）、选可选开始日期与截止日期、写说明，保存后立即成为一张真实持久化的目标卡。开始日期不能晚于截止日期，填反时会在表单里就地提示。目标会在下方「时间安排」的月历上显示为从开始日延伸到截止日的跑道（见第 5 章）；旧目标没有开始日期也无需迁移，会显示为截止日上的单日跑道。目标卡片可以直接「编辑」「删除」；说不清字段时，在表单里用一句话让 Agent 代填——它填在表单里，你确认后才保存。

### 2.2 准备练习：今天要练的

这是全页的核心区块，也是全书最重要的概念：**这里列出的，就是这次真的要练的东西**。它对应「范围」这个概念——你在别处勾选的知识点，全部会汇成这份清单。它有两个状态：

**空状态**：你还没选任何知识点时，这里只有一句话——「还没选定要练的知识点——去知识点页挑一个」。「去知识点页挑一个」是可点的链接，直接跳去选择页（见第 3 章）。不催促、不自动塞内容、不显示任何「推荐」。

**已选定**：每个选中的知识点一行，只有两样东西——知识点名称和一个「✕」。点 ✕ 就取消选中这个知识点。改动会立刻同步：知识点页的勾选框、图谱页的节点勾选、练习页的这份清单，三处永远是同一份数据，在哪边改都一样。行上没有别的任何信息——不显示进度、不显示难度、不显示推荐理由。要练的名单就该是一份干净的名单（这是所有者定下的硬约束：**哪怕工整的字段也会加重阅读量**）。

### 2.2.1 把一次练习固定下来并打印（CLI）

浏览器里的这份名单是「这次要练什么」；如果你要把某一批题**钉住、打印、带到纸上做**，用命令行的 `lesson-kit pull`（同一个「拉题」，不是新概念）。一次调用可以同时用六种方式选题：

```bash
lesson-kit pull <工作区> --kp dmath-ch06-kp-002 --n 8          # 按范围（缺省=章透镜）
lesson-kit pull <工作区> --problem dmath-ch06-prob-131          # 单题追加（不受筛选与上限影响，可重复）
lesson-kit pull <工作区> --source-kind final --exam-year 2023   # 条件筛选（材料/年份/难度四维）
lesson-kit pull <工作区> --wrong --n 20                         # 我做错的题（--due 到期、--weak 薄弱）
lesson-kit pull <工作区> --n 20 --ids                           # 只看题号（旧形状），不打印整行
```

范围取自「章透镜」：`lesson-kit use dmath ""` 把透镜关掉就是整门课，那之后再 `--wrong` 就是**整门课的错题**——期末复习要的正是这个。

三种驱动（`--wrong` 错题 / `--due` 到期 / `--weak` 薄弱）都基于**已有学习证据**：新池上它们为空，先用范围或条件筛选题。每题都会带一个入卷理由（`explicit`/`wrong`/`due`/`weak`/`scope`），所以一张卷子为什么是这些题，看得见、可复核。

固定与打印：

```bash
lesson-kit pull <工作区> --kp … --n 10 --plan plan.json                    # 存清单（可重跑，不是学习记录）
lesson-kit pull <工作区> --input plan.json --check                        # 零写入预检：题数、缺解、重复、泄漏
lesson-kit pull <工作区> --input plan.json --print output/c01/ch06 --base ch06
```

`--print` 出两份 Markdown：学生卷只有题干（不含答案，也不含 `problem_id`/`kp_id`/材料类型），解答卷题号与它逐条对齐、没存解析的写「待补」。默认文件名用章号，跨章的卷（关掉章透镜后组的那种）用 `--base` 自己起名。**跨章卷**就是期末复习要的那种：把章透镜关掉（`lesson-kit use dmath ""`）或把要练的知识点逐个 `--kp` 列出来，再选题目。

### 2.3 建议：加今天要练的

准备练习区块下方有一个按钮：「**＋ 加今天要练的（N）**」。括号里的数字是当前建议的数量；没有建议时按钮不带数字。点开才出现建议列表，再点收起——建议平时不占页面一寸地方。

每行严格三样东西：**知识点名称 · 一个短语 · 「加入」按钮**。短语只会是这三种之一：

- `拖了 N 天` —— 这个知识点有一条到期的复习安排，已经过了 N 天。
- `今天到期` —— 复习安排恰好今天到期。
- `覆盖仍低` —— 它在你的每日计划建议里（计划依据目标与覆盖情况生成）。

没有徽标、没有日期、没有数字、没有第二个短语。同一个知识点如果同时「拖了几天」又「在计划里」，只显示到期那条短语——一行只说一件事。

点「加入」，这个知识点进入上面的准备练习列表；它同时从建议里消失、按钮计数减一。**加入的本质就是「帮你勾选」**：和去知识点页手动勾选完全等效，之后随时可以 ✕ 掉。

排序规则：拖得最久的排最前，然后是今天到期的，最后是计划建议。建议最多展开显示 20 条，更多时末尾一行「还有 N 条」。已经选中的知识点不会出现在建议里（避免重复）。

建议区里还有一个「**重新安排**」按钮：点它系统按当前目标与进度重算一次每日建议，完成后自动刷新页面。另外每天第一次打开工作台时也会自动重算一次——除此之外系统不会在背后偷偷动你的建议。

### 2.4 本轮练习：选模式

范围定了之后，在「本轮练习」区做两个必选：

**练习模式（四选一）**：
- **综合题**：这个范围的常规正式题，作答 → 查看解析 → 自己打分。所有未做特殊标注的存量题都在这个模式里。
- **小测**：选择题点选（单选/多选），提交后立刻判对错并显示错因。只拉取标注过可用的微题——没有会如实显示空态，绝不拿普通题冒充。
- **判断**：判断题（是/否），选完立刻判对错并显示错因。同样只认标注过的内容，缺内容同样如实空态。
- **闪卡**：从知识点拆出的键值对记忆卡——自己回忆、揭示另一面、打分。选中后还能指定混合、正向或反向；单向卡始终正向。没有选项、没有判分，全凭你对记忆的诚实。背概念、术语或双语词汇用这个。缺内容同样如实空态。

**自评时机（二选一）**：
- **每题作答后自评**：做一题打一题的分。
- **完成后统一自评**：先一路做完，最后在收束页统一补分（见 6.6）。

模式选好、范围非空，「**开始本轮练习**」按钮才点亮。范围是空的时候它一直是灰的——这是设计，不是坏了：**没有范围绝不拉题**。灰色的按钮也能一眼看出是灰的（浅灰底、灰字），不会让你误以为它能点。

页面中部还有一句常驻说明：「当前范围由知识点视图明确选择；本轮不会自动扩展范围。」——练到一半不会突然冒出范围外的题。

### 2.5 开始与结束

点「开始本轮练习」后进入练习流（见第 6 章），页面同时收起上方的目标卡、准备练习列表、建议、模式选择和时间安排——**中间栏只剩练习本身**，做题就是全部，做完（或提前结束）它们原样回来。界面任何时刻都如实告诉你处于哪一步，不会出现「不知道自己在干嘛」的中间态。

### 2.6 一个完整的开场例子

走一遍最常见的早晨流程，把前面所有零件串起来：

> 打开工作台，落在练习页。学习安排区显示目标卡「第八章前 20 节覆盖 · 截止 08-31」。「今天要练的」还是空的，只有那句话和一个「＋ 加今天要练的（20）」。
>
> 点开建议：第一行「帕斯卡恒等式 · 拖了 6 天 · 加入」——上周练过、按排期该复习了，拖了六天。点「加入」，它跳进准备练习列表；建议按钮变成（19）。又看到「二项式定理 · 覆盖仍低」，最近没怎么碰它，也点「加入」。剩下 18 条建议暂时不想理，把建议区收起——列表干干净净就两行：帕斯卡恒等式 ✕、二项式定理 ✕。
>
> 觉得还想带上一道具体卡过的知识点，去知识点页把「鸽巢原理」勾上——回到练习页，准备列表里它已经在了（三处同步）。
>
> 范围三个知识点，够今天练了。选「综合题」+「每题作答后自评」，「开始本轮练习」点亮，点下去。今天的学习开始。下方时间安排里，08-31 的目标轨道安静地待在月历上——不急，还有两天。

## 3. 选定范围：知识点页与知识图谱

工作台不会用省略号隐藏知识点名称、题目、目标或备注。长文本会在自己的栏内
完整换行；代码块、宽公式和表格如果超过栏宽，只在自身区域横向滚动，不会把
中栏或 Agent 右栏撑宽。

**目标深度：详。完成度：✅ 首批成文。权威：workbench-ui spec。**

范围（要练哪些知识点）只有两个加入入口：知识点页和知识图谱页。两个页面的勾选与练习页的准备练习列表**实时是同一份数据**——在哪边改都一样。阅读、导航、排序都不会改变勾选。

### 3.1 章透镜：顶栏那个「章」开关

工作区的池是**一门课一整本**（单库多章）。顶栏工作区名旁边有个「**章**」开关，决定"现在看哪部分"：

- 关着 = 全课程，所有章的内容都在眼前（默认）。
- 打开 = 只看一章；旁边的下拉列出**池里真有的章**（跟着内容走：新章内容一入池就出现在下拉里，不用登记、不用建表）。

透镜管的是"看"：知识点页、知识图谱页、复习与练习建议都按它取数，页头的「学习 / 当前章节」或「学习 / 全课程」、章节标题下的「本章知识点 / 全部知识点」会如实说明当前在哪一层。**它不管"练"**：勾选（练习范围）不受约束，可以跨章；切换透镜时已勾的照旧保留，练习照旧从整份选区拉题。想跨章突击就关掉透镜，或把几章的 KP 一起勾上。

开关与命令行 `lesson-kit use <课> <章>`（`""` = 全课程）写的是同一个值，网页上切完，CLI 与 Agent 看到的就是同一章。Hub 首页卡片上的知识点/题目/待复习数字始终是**整门课**口径（回答"这个工作区有什么"），不随透镜缩小。

每个工作区页面的中栏右上角都有一个小型「**练习范围 N**」按钮。点开会出现范围托盘：里面完整列出当前已选知识点，内容多时直接在托盘内用鼠标滚轮上下浏览；点某行的 × 可以移除，点「练习这些知识点」进入练习页。右上角的减号把托盘收回小按钮。选区和展开/收起状态都在当前标签页跨页面保留。

### 3.2 知识点页

左侧导航点「知识点」。本章所有知识点列成清单，每行：勾选框 + 知识点名称（可点进详情页）+ 一行小字——关联题目数（如「12 题」），以及该知识点当前的行动提醒：有明确薄弱证据的带「**重点练习**」、到期的带「**可以复习**」，两者都没有就什么都不标。没有掌握度、没有分数。

进入详情后，正文使用更大的阅读字号、宽行距和单侧结构线，是页面最醒目的
内容；提醒和关联题目与正文拉开距离，主题入口保持紧凑。

顶部工具条：

- **排序**：课程顺序（默认，跟教材章节走）/ 名称 / 题目数量 / 学习状态 / 重要性，旁边的 ↑ 按钮在升序降序间切换。排序是稳定的：同值条目保持原有相对次序。排序纯视图操作，不写任何记录。
- 勾选结果立即进入右上角的练习范围托盘；勾选若干后可从托盘直接回练习页开练，一个都没勾时托盘内的练习按钮禁用。

### 3.3 知识图谱页

左侧导航点「知识图谱」。本章知识点构成一张力导向图，连线是知识点之间的关系。可以做的事：

- **搜索**：按名称定位一个节点。
- **切换视图（投影）**：关系结构（默认，展示知识点之间的关系）/ 题目数量 / 重要性 / 学习状态——同一张图换着角度看，基于已有指标，不发明新指标。切换指标时节点不会瞬移或整图刷新，而会像气泡一样向新位置移动：指标越高，节点越大、越靠近中心。题量用蓝色色谱，重要性用黄色色谱；学习状态用蓝/黄/红/灰表示掌握/复习/待加强/未标记，并按关注优先级 `needs_work / review / null / mastered` 从中心向外排列（待加强最靠中心）。工具栏会同步说明当前视觉含义。
- **切换视图（投影）**：关系结构（默认，展示知识点之间的关系）/ 题目数量 / 重要性 / 学习状态——同一张图换着角度看，基于已有指标，不发明新指标。
- **按学习状态筛选**：可以同时勾选重点练习、可以复习、已掌握、未标记中的一个或多个类别。没有勾选时显示全图；勾选后，不符合条件的节点和相关连线先淡出，保留节点按状态聚成一团或多团。多项筛选取并集，跨团关系仍显示。点「清除筛选」恢复全图。筛选和上面的视图投影可以同时使用，且都不改变练习范围或学习记录。
- **聚拢**：滑杆调整节点的聚散程度；「适应画布」一键缩放到全图可见；另有 ＋/− 逐步缩放。
- **勾选节点**：点选节点即勾选知识点，与知识点页、练习页的准备列表同步。图大的时候不用回列表页翻。
- **学习看板**：右侧栏默认显示「学习看板」标签：点一个节点，看板显示它的名称、提醒词（重点练习/可以复习）、关联题数等**有限**信息，以及「打开知识点」进详情。看板刻意只显示有限信息——不看参数、不看证据明细。要跟 Agent 说话就切到旁边的「对话」标签。

图谱稳定后保持完全静止，只有拖拽、筛选、聚焦、切换投影、缩放或调聚拢时才重新布局。图不呼吸、不晃动；系统开启「减少动态效果」时，投影切换直接显示稳定终态。
图谱稳定后保持完全静止，只有拖拽、筛选、聚焦、缩放或调聚拢时才重新布局。图不呼吸、不晃动；系统开启「减少动态效果」时，筛选直接显示稳定分群结果。

关系结构视图会优先选择交叉更少的确定性布局。关系强度同时控制连线的宽度和
深浅；每条关系由阴影、管体和高光三层构成，弱关系先绘制、强关系后绘制，
因此密集区域中较强关系仍保持清晰。该效果只读取既有关系，不写入图谱坐标或
学习数据。

### 3.4 知识点详情页

从列表或图谱点进一个知识点，看到：正文（支持公式、图片、`[[知识点]]` 互链跳转）、行动提醒词（若有的话）、以及「关联题目」区——按主题分组折叠展示（点组名展开），每组内是题干与解析入口。

页头有「**练习此知识点**」按钮：单点突破一个知识点时用它，它会带着这一个知识点回练习页（等效于只勾选它一个）。

### 3.5 一条铁律

练习范围**只能**来自你的显式勾选（或建议区里你亲手点的「加入」）。对话里随便聊天、系统的弱项排序、每日建议，都不会悄悄改你的范围。唯一的例外也握在你手里：Agent 只有在收到你的**明确练习意图**时才可能替换范围（见第 8 章）；普通对话永远只读。

## 4. 建议与计划：系统怎么「多嘴」

**目标深度：详。完成度：✅ 首批成文。权威：daily-learning-plan spec、consolidate-practice-views。**

系统通过两个渠道提建议，共同原则只有一条：**只提醒、不强迫、不露参数、可无视。**

**每日建议**：每天第一次打开时，系统按你的目标、进度、覆盖情况算一次当日建议；也可以随时用建议区的「重新安排」手动重算。它最多只有三条，措辞是「覆盖仍低」这样的人话，不带「去做第 3.2 节」式的指令。计划失败时保留上一次的有效结果，不会给你看一个报错堆栈。

**到期建议**：你练过的内容会被排期复习（第 7 章讲机制）。到期了的、拖了日的，汇进候选区，按「拖了 N 天」「今天到期」标注，拖最久的排最前。

两条渠道在「＋ 加今天要练的」里合流（第 2.3 节）。系统的全部「主动性」到此为止——它不会弹窗、不会置顶催促、不会因为你不理建议就加重语气或加倍推荐。学习是你的，它只管把该说的用一句人话说到位。

## 5. 目标与时间安排

**目标深度：详。完成度：✅ 首批成文。权威：calendar-workload spec。**

练习页中栏日计划下方有一个全宽「时间安排」卡（标注了「实验视图」——形态还会迭代），全部**只读**：它不写、不改、不重排你的任何数据。

**目标时间跑道**：当月月历中，每个有截止日期的目标是一条细轨道。填了开始日期时，轨道从开始日持续到截止日；没有开始日期的旧目标显示为截止日上的单日轨道。跨周目标按自然周换行并用箭头续接，仍然是同一个目标，但标题只在首个可见分段出现一次；时间重叠的目标自动占用上下不同的紧凑跑道，不会互相遮盖或合并。阶段目标用黄色，长期目标用蓝色，逾期目标只把结束端点变红；今天只高亮日期数字，不再涂满整格。完整标题和起止日期保留在每段的悬停提示与无障碍标签中。窄栏允许月历自身横向滚动，不挤压整页。

本月之外或没有截止日期的目标不会硬塞进日期格，而是在月历下方如实列出。没有任何目标且 14 天内也没有到期任务时，显示一句诚实的空态：「最近没有安排在日历上。」

**未来 14 天复习负荷**：从今天起 14 天，每天有多少项到期就画多高的柱。上方先汇总 14 天总量、峰值日期/数量和当前逾期数；每个非零值直接写在柱顶，所有日期固定在同一条基线上，零值只留日期、不画假的短柱。峰值柱用黄色强调；若它或其他日期达到非零日均的两倍，再加红点表示「这天恐怕练不完」。这里没有拟合线或预测线，只有真实到期数。

**让 Agent 看看**：出现「重」日时，卡片标题旁会出现这个按钮。点它把一句话预填进右侧 Agent 输入框——「最近几天任务偏重（最多的一天 N 项），帮我重排一下。」——**只是填进去，绝不替你发送**。发不发、怎么跟 Agent 商量，由你决定。

窄屏下时间安排仍然纵向显示；月历和 14 天日期轴各自在卡内横向滚动，不挤压整页。

## 6. 练习过程：一题一条流水线

**目标深度：极详。完成度：✅ 首批成文（微题实测细节见 6.3/6.4，判分边界见 6.8）。权威：review-workbench spec、micro-quiz-content spec、flash-card spec。**

### 6.1 通用节奏

每轮练习就是一张一张卡片向前走：**看题 →（作答）→ 揭示解析 → 自评 → 下一题**。当前处于哪一步永远有明确的界面状态；网络出错时错误信息留在原地并给「重试」按钮，不会静默吞掉你的操作。题干可以带教材原图（几何图、表格等），正常显示在题目文字里；图没加载出来时会看到空位——重试页面即可，图文件本身在池的记录里有据可查。

### 6.2 综合题（exam）

1. 题目卡展示题干（支持公式与图片）。
2. 在作答框写下你的解答（写与不写随你——草稿不写库）。选择题直接点选项作答，多选题用勾选，选中项会自动收集成你的答案。
3. 点「查看解析」对照完整解答。
4. 在紧凑反馈区直接填 **1–5 自评分**（1–2 = 没掌握，3 = 一般，4–5 = 熟练，语义你自己把握），可在下一行附一句备注（比如「卡在第二步」——备注会原样保存并参与弱项识别）。这里是数字填空，不会展开成五个选择按钮。
5. 点「记录并下一题」——**这一刻**才写入记录（一次写入：反馈 + 信号 + 进度 + 调度），然后进下一题。

开放题（证明、设计、建模、解释类）遵循「**先作答，再揭示**」：解析揭示后你对照自己的过程打分，系统不代劳判断。多步题可以把「卡在第 N 步」连同一句备注标记下来——这个卡点标记会存进本次尝试，之后在对话里问 Agent 时原样带上，不用你再解释一遍卡在哪。

### 6.3 小测（micro）

选择题点选作答（单选点一个，多选点多个、全对才算对）：点选项 → 提交 → **立刻判分**——答对显示「回答正确」；答错显示「回答错误」，并附上为什么（错因说明），同时**高亮正确选项**。判分发生在浏览器本地，只是即时反馈，**它本身不写学习记录**；你的 1–5 自评才是记录的触发点。小测**没有**自由文本作答框——它考的是概念辨认与区分，不是长篇推理（那是综合题的事）。

统一自评的轮次里，判分同样即时：横幅（对/错 + 错因 + 正确项高亮）会**停留约两秒**再自动进下一题——够你看清对错，不打断节奏；不想等就点「跳到下一道题目」立刻走。评分仍然留到收束页统一给。

### 6.4 判断（yes_no）

题干 + 「是 / 否」两个选项。选完**立刻判分**：答对显示「回答正确」；答错显示「回答错误」，并附上为什么（错因说明，比如「3 恰有两个正因数」），答错时同样高亮正确选项。判分发生在浏览器本地，只是即时反馈——**它本身不写学习记录**；你的 1–5 自评才是记录的触发点。统一自评时的停留节奏与小测一致。

### 6.5 闪卡（flash_card）

从知识点内容拆出的**记忆卡**：一张卡就是一条键值对。开始前可选**混合、正向、反向**；混合是默认。单向卡始终以正面提问、另一面作答；双向卡可按任一面提问，适合中英互背等两面都具有教学意义的内容。流程仍然很短：看提示面 → 在心里回忆 → 点「揭示另一面」对照 → 打 1–5 自评。没有选项、没有判分，全凭你对记忆的诚实。

单向卡揭示时向下展开。双向卡在视觉上叠成两张，揭示时像摊牌一样分别向左下、右下扇开；`⇄` 可在揭示前后交换当前提问面。最终自评记录的是**实际使用的方向**。系统减少动态效果时会直接显示展开后的状态，不播放位移动画。统一自评页也会按实际方向列出提示、答案和方向。

闪卡可以**自由回翻**：「上一张 / 下一张」在本轮已看过的卡之间移动——翻回去时揭示状态原样保留（看过的背面直接可见，已评分的卡只读）；翻到历史末尾再按「下一张」才会拉新卡。中途跳过没揭示的卡，翻回去还能补揭示——补了就算玩过，等收束页补分。

### 6.6 两种自评时机的实际体验

- **每题作答后自评**：如上，做一题结一题，节奏干净。
- **完成后统一自评**：做题过程中不打分，一路做完；**判分照常即时**（横幅停留两秒再走），只有评分留到最后。点「提前结束本次练习」（或题目自然做完）会进入**会话末统一自评**页：列出所有还没打分的题，逐题补 1–5 分；「跳过全部」则这些题完全不记录（不留半条）；底部一个「**再练同类**」按钮，用同一组知识点立刻再开一轮——专门用来「把痛点练到通」。

两种时机下都有一个常驻的小入口：「跳到下一道题目」。跳过的题不写任何记录——不惩罚、不记欠账。已经作答或已揭示的卡不会被跳过降级：它们的待评分状态保留到收束页。

### 6.7 中断与恢复

练习会话存在浏览器标签页里：同一标签页**刷新或离开再回来，会恢复到原题**——练习模式、当前题（包括闪卡回翻到了哪一张）、已做题集合、每题的作答/判分/揭示状态、待统一评分的队列全部还原，且不会重复拉同一道题。关闭标签页则未提交的作答草稿直接消失，系统不会替你补写任何记录。已保存的评分永远安全——它们在池里，不在浏览器里。

### 6.8 判分的边界（重要）

判断/选择题的「回答正确/错误」是**即时反馈**，不是学习结论。系统对一道题的学习结论只有一个来源：**1–5 学习自评**——你自己在练习页提交，或在第 8 章里让 Agent 按你的要求代录并评分。所以答对了但觉得自己是蒙的，就诚实地打 2 分——系统听你的，不听题面的。

手写长题（比如拍照交的证明题）不必再一个字一个字敲进作答框：把照片放在你自己的目录里，让 Agent 转录并给一个 1–5 自评，它走的是**同一套**规则与同一条写入路径（第 8 章）。拿不准掌握到什么程度时，可以让它**只转录、不打分**——那是一条不留评分痕迹的尝试，不会动信号、当前状态、进度和排期。

### 6.9 一个综合题回合的完整例子

> 题目卡出现：「40. How many ways are there to select 12 countries …」——一道关于分组选择的计数题。你在作答框写下自己的解法，感觉卡在第二组的人数上，但先写完。
>
> 点「查看解析」。对照后发现思路对了一半：分组内部用了组合，但忘了各组之间是乘法关系。在反馈区打 **3**，备注写「乘法关系漏了，分组内 C 的选取没问题」。点「记录并下一题」——这一瞬间，一条反馈（3 分 + 那句备注）进了池，对应知识点（加法规则/乘法规则方向）的薄弱证据被加强，进度更新，这道题的下次复习日期被推后了一点。整套动作一次完成，你只会感觉到「下一题出现了」。
>
> 做到第五题有事要走，直接关标签页。前四题的评分都在池里；第五题的草稿随标签页消失，不欠账。晚上重新打开工作台，范围还在准备练习列表里躺着——随时点开始，从头再来这一轮。

## 7. 记录与调度：你的评分去哪了

**目标深度：详。完成度：✅ 首批成文。权威：review-workbench spec。**

### 7.1 一次自评，四件事

你提交 1–5 分的那一刻，系统原子地做四件事：记一条**反馈事件**（评分 + 备注）、更新**学习信号**（低分会加强对应知识点的薄弱证据；信号只加强不自动消除）、更新**当前学习状态**（1–2 分 → 重点练习，3–4 分 → 可以复习，5 分 → 掌握）、更新**调度**（这道题的下次复习日期按新间隔推进）。这是一次写入，不多不少；2 分和 5 分留下的痕迹不同，但流程完全一样。

除自评外唯一的写入口：在图谱里显式编辑一个知识点的状态——它按对应评分更新状态与调度，但**不**追加反馈历史（改主意不留下 gossip）。

### 7.2 调度只做背景

每道练过的题有自己的复习排期。到期了的**只会**出现在练习页的「加今天要练的」建议里，带一句「拖了 N 天 / 今天到期」。它永远不会：弹窗催你、把没练的题藏起来、拒绝你练任何东西、或把「间隔」「熟悉度」这种参数摆到你面前。**调度永不锁题**——想练没到期的？随时练，正常记录。

### 7.3 方向

双向闪卡按方向分别排期（比如中→英、英→中各一条进度，互不影响）。方向控件只在你主动选择闪卡模式后出现；其他模式不会询问方向，系统也不会主动发起卡片会话。混合练习中，同一张双向内容可以先后以两个方向出现，并作为两条独立的学习动作保存。

### 7.4 你会看到的全部「评价词汇」

整个系统对你的学习状态只使用三个词：**重点练习**（有明确薄弱证据）、**可以复习**（到期待回看）、其余**保持沉默**。没有分数、没有百分比、没有「掌握度 73%」这类伪精确。系统对你的全部判断，都压缩成这三个词，其余交给你的自评和体感。

## 8. Agent 对话

**目标深度：详。完成度：✅ 已成文（2026-08-29；讲解/诊断一键任务同日经所有者决定移除，见 remove-explain-diagnose）。权威：ai-teacher-bridge spec、workbench-ui spec。**

右侧是 Agent 栏。它背后没有内置的 AI 内核——接的是你自己机器上的 Agent 命令行（Codex / Claude / Pi），配置归你，账单归你，Lesson Kit 只做桥。Pi 是三者里最轻的一个：同样的功能，harness 占用的 token 更少。

**新建对话与选择 Agent**：点「新建」会列出本机可用的 Agent（在 PATH 上发现的 Codex / Claude / Pi）。选中即创建对话，**之后这个对话固定用这个 Agent**——系统绝不会悄悄换一个，Agent 掉线、超时、退出都会如实报错，而不是装作一切正常。Agent 在自己进程里报的错也会被翻出来：即使进程是「正常退出」，只要它流里说了失败，这一轮就记为失败并附上它给的原因。历史对话列表在左侧，随时切回、重命名、删除。

**自由提问与练习页上下文**：对话里随便问。你在哪个页面、正在练什么，Agent 自动知道——练习页发消息会带上**当前题目**、练习模式和进度（比如「已做 5 题」），另外还带上你**还没提交**的那份作答、已选选项、反馈备注和当前显示的图片；知识点页会带上当前知识点；图谱页会带上你选中的节点和筛选词。不用复述背景，直接问。带上草稿只是为了这一轮问答更贴题：聊完不写任何记录，草稿仍只活在当前标签页里，关掉就没。

**什么才算「卡住」**：一轮回答**不按总时长判超时**，判据是「多久没动静」——只要 Agent 还在输出、还在推进步骤，这一轮跑十分钟也照跑；它正在跑一条安静的命令（编译、批处理、长脚本）时另有一份更宽的预算，不会因为命令不吭声就把它截停。反过来，真卡住（完全没有输出又超出预算）仍会如实报 `provider timed out`，绝不假装完成。两份预算可在配置 provider 时指定（`lesson-kit bridge add <provider> --command <路径> --timeout 秒 --tool-timeout 秒`，`lesson-kit bridge list` 显示当前生效值），默认静默 5 分钟、命令在跑 20 分钟。

**执行过程怎么看**：Codex/Claude 继续在一张「执行计划」中显示具体步骤。Pi 则把读取文件、更新文件、搜索、运行命令和操作 Lesson Kit 各自显示成一条紧凑消息；同一步从「进行中」原位更新为「已完成」或「失败」，不会刷重复消息。Pi 在工具前后说的话会分成前后两个气泡，顺序与实时事件一致。所有工具输出默认折叠，路径和经遮盖的命令可见，写入内容不拿来做摘要。底层协议名、通用处理阶段和隐藏推理都不显示；只有成功轮次的具体活动会随回答恢复。Pi 每个对话只开一个**隐藏**的后台进程（不会弹终端窗口），空闲半小时自动回收，你点「停止」时先请它自己停下、失效才强杀；工作台关闭或删除对话都会一起清理。回答里的表格、公式、图片按同一套安全 Markdown 渲染，窄栏里表格自己横向滚动。

**想聊某道题就直接聊**：你在练习页发消息，Agent 自动带着当前题目和你的作答上下文——想让它讲这道题、找卡点，用对话说就行，不需要专门的按钮。

**让 Agent 替你记下并批改手写作答**：手写证明题、写在纸上的推导、拍了三四页照片的答案，都可以交给 Agent。流程是这样：你先把自己存放答案照片的**目录**告诉它一次（命令行 `lesson-kit attempts <工作区> sources list` 能列出哪些目录已配置，`sources add --path <目录>` 添加；目录可以在工作区之外，纯只读）。之后你说「帮我把这道题的答案记下来」「按我的水平给个 1–5 的自评」，Agent 会读那些图片、把作答**转录成文字**、写下批改说明，然后通过 `lesson-kit attempts` 一次提交；它提交前可以先用 `check` 预检（零写入），失败会逐条告诉你哪一题哪里不对。

几条边界值得记住：

- **只有你要求，才会记。** 只发消息问问题、只让它读照片、只讨论草稿，都不会产生任何学习记录——尝试、信号、状态、排期一个字节都不动。
- **评分是你的分，不是它的分。** `rating` 用的就是你自己那套 1–5 学习自评量表（1–2 重点练习 / 3–4 可以复习 / 5 掌握），不是卷面分、不是百分比；它不能替你决定掌握程度，也可以选择**不打分**，只留一条转录。
- **一次可以交好几题。** 一页纸上有两道题、或者一题写了好几页，都不影响：一份清单可以同时含多道题，要么全部记下，要么一条都不记。
- **重发不会重复记分。** 网络断了、回答丢了，Agent 原样重发（同一份 `request_id`）只会拿回第一次的结果，不会多出一条记录。要真的再记一次（比如隔了一天又做了一遍），换一个新的 `request_id` 即可。
- **记错了可以改，但只改最近一次。** 你对 Agent 说「刚才那道题转录错了 / 评分改成 3」，它用 `lesson-kit attempts <工作区> correct <尝试 id>` 整体替换那一次尝试，并**撤销旧评分的影响后按新分重算**（不是叠加）。如果那次尝试之后你又练过这道题、或改过相关知识点状态，更正会被拒绝并告诉你重新记一次——它绝不会回头改写你后来的学习历史。
- **图片不留档。** 照片留在你自己的目录里，Lesson Kit 不复制、不建索引、不在尝试上记单图路径；池里只有 Agent 提交的**文字**。所以图片是「来源」，不是「附件」。

**没配 Agent 时的样子**：对话面板提示「暂无可用 Agent。请先配置一个提供方。」——**其他所有功能照常**，练习、记录、调度一点不受影响。配置动作是在命令行跑 `lesson-kit bridge add`——Agent 没配就是没配，界面不装。想知道到底解析到了哪个可执行文件（机器上装了两份同名 Agent 时尤其有用），跑 `lesson-kit bridge list`；它还会标出路径是否真的存在。要让某个 Agent 固定走某一份安装而不是听 PATH 的，用 `bridge add <名字> --command <绝对路径>` 钉死它。

**Agent 能改你的练习范围吗**：只有一种情况——你在消息里**明确表达了练习意图**（比如「帮我练这几个知识点」），Agent 返回的结构化动作才会替换当前选区，而且只换一次。普通聊天里 Agent 说什么都动不了你的选择。

**Agent 能帮你把内容搬进来吗（内容批次）**：能，但只在你要求时——你说「把这些题导进去 / 给这一章补知识点和插图」，Agent 会准备一份清单，可能同时包含知识点、正式题、微题、闪卡和题目必需的插图，条数不限（大清单先存在本对话目录里，回答里只引用文件名）。服务端**一次预检、一份备份**：字段、引用、出处、图片字节全过一遍才写；任何一条不合格或缺图，整批一个字节都不写，并把每条原因原样列出来让你和 Agent 一起改。**一份清单可以横跨好几章**（每道题/每个知识点自己写所属章），落盘时**按章各成一个批次**——所以「12 到 14 章一起导」一次就能说完，而回滚可以只撤其中一章。结果卡片每章一行，写清楚：批次号、所属章、各类资产数量、来源分布、工作区、备份位置，以及**当前**是否已回滚。

教材原题按原样进池：原题文字、数值、选项、作答形式都不改，出处（如「教材 第12章 习题12-5」）显示在题目下方；只有你明确要求「改成小测」才会变体，AI 自己生成的判断/选择题另标来源。教材给的短答案单独保留，AI 的详细解析按需生成、并明确标成「AI 生成解析」，两者不会互相覆盖。插图按**原始字节**复制到工作区的 `figures/` 下，不裁剪不转换；缺必需插图的题目整批不写。

对结果不满意，点某一行上的「整批回滚」（或命令行 `lesson-kit ingest rollback --batch 批次号`）一次撤销**那一章**的全部内容，连该批创建且再没人引用的插图一起删；该批内容已经产生过练习/评价记录时，回滚会拒绝并如实告诉你——绝不会偷偷删你的学习记录。重新打开这个对话，回滚过的卡片会显示「已回滚」，回滚按钮不再出现。

**来源和难度怎么分**：每道新题同时记录“依据什么材料”（课本、小测、期中、期末等）和“它是原题、改编题还是基于材料生成的新题”。因此 AI 根据期末材料生成的新题仍能同时保留两层事实。**真题还可以带一个「考察年份」**（如 `2023` 或 `2023-2024秋冬`，可空）——它是第三个可选来源事实，导入真题时顺手写上，之后就能「把 2023 期末的题挑出来练」（`lesson-kit pull <工作区> --exam-year 2023`，按前缀匹配）。客观难度是独立、可空的四维评级，不随出题自动产生；只有你明确要求给指定题评级时，Agent 才能先预检再整批应用。未评级题完全照常使用，学生页面也不显示裸分或星级。

**普通对话绝不写学习记录**：聊天本身不产生任何学习写入——不打分、不改状态、不动调度。Agent 只有在**你明确要求记录或批改**、并且真的调用了 `lesson-kit attempts` 写命令时，才会产生一条尝试（第 8 章）。对话留痕（谁问了什么、答了什么）保存在工作区本地，作为过程记录，不是学习记录。除此之外，学习记录仍然只有一个来源：你自己提交的 1–5 自评。

## 9. 数据安全边界

**目标深度：详。完成度：✅ 已成文（2026-08-29）。权威：ARCHITECTURE、workbench-content-governance spec。**

一句话版本：**系统只在你明确动作的那一刻写库，其余一切只读。**

**会写什么**（全部由你的显式动作触发）：

- **1–5 自评**（练习页或收束页点「保存」的那一刻）：一次原子写入四件事——反馈事件、学习信号、当前状态、调度（第 7.1 节）。
- **图谱状态编辑**：在图谱里显式改一个知识点的状态——按对应评分更新状态与调度，不追加反馈历史。
- **Agent 代录作答（`lesson-kit attempts`）**：你明确要求记录/批改、Agent 提交清单的那一刻——同一事务里写入尝试与（若带评分）反馈事件、信号、当前状态、进度、调度；换 `request_id` 重发才会再记一次，`correct` 只改指定尝试并撤销旧评分影响。只读草稿、只读图片、只预检都不写。
- **目标的增删改**：练习页目标表单里你填的长期/阶段目标。
- **Agent 出题入库（Check 管线）**：你明确要求出题/补池、Agent 产出通过门禁的那一刻——按批次记号入池，整批可回滚（第 8 章）。
- **题目难度评级**：你明确要求给指定题评级并确认执行时——完整四维清单整批写入；预检零写入。

**一次说清几章，就一次导完**：你已经说明范围（比如「把第 18–22 章导进去」）时，Agent 应当在同一轮里把这几章一起提交，不必每章等你再说一次「继续」；一轮回复里可以带一份跨章清单，也可以带几个区块，服务端逐个应用。**每一章各记一个批次**（因此可以只回滚某一章），但预检、备份和写入是整份清单一次——任何一条不合法就整份零写入，不会只丢那一章。

**题型（综合题 / 判断 / 小测）在入库时选**：不给 `quiz_type` 的普通题进**综合题**；给 `quiz_type: "yes_no"` 的是**判断题**；给 `single_choice`/`multiple_choice` 加 2–6 个选项的是**小测题**。判断题、单选题**即使题源里没有正确答案也能入库**：这类题不自动判分，练习页会写明「本题未录入答案键，请对照课本或解析自评」，你照常作答并自评 1–5，学习状态照常更新。以后拿到答案，随时可以补上（让 Agent 补，或 `lesson-kit data <工作区> update problem <题号>` 写 `answer_key`），补上后就开始自动判分。**「题型」在这里指的是练习模式**；题目的学科形态（计算/证明/建模…，即 `problem_type`）是另一件事，判断题、单选题的学科形态写 `other`。

**绝不写什么**：浏览（翻了哪页、看了哪题）、勾选（选区勾勾改改）、作答草稿（没点提交的作答只活在当前标签页里，关掉就没；练习页发消息带给 Agent 的那份也是临时的）、跳过的题（不写、不记欠账）、普通对话（第 8 章）。这些动作再频繁，池里也不会多一个字节。

**池数据库与备份机制**：全部题目、卡片、知识点、你的记录都在一个池数据库（`pool/dmath.db`）里。内容入库只有一条合法通道——**确定性门禁配方**（Check 管线，`lesson-kit ingest` 或对话桥出题动作），任何一批内容 apply 之前都会先做可恢复备份，apply 在单事务里执行，失败即回滚、池子原样；每一批都带**批次 id**（内容行自带批次标记），一条命令（或结果卡上的按钮）即可整批撤销。所以「内容坏了」永远有得回滚。

**状态文件位置**：用户级工作区/Bridge 注册表在 `~/.lessonkit-workbench/`（答卷目录清单 `answer-sources.json` 同在这一层）；每个工作区自己的对话事件、成功镜像、计划和目标在项目下的 `.lessonkit/`；池数据库在 `pool/`。失败/取消的 Agent 输出不会进入长期对话镜像。

**走查一律用副本**：开发与验收从不直接碰真实池——用隔离注册表（`LESSONKIT_WB_HOME` 指到临时目录）+ 拷贝的池副本 + 专用端口起服务，全部流程在副本上走一遍才算数。这条纪律对开发者和 Agent 一视同仁：**真实池的写入只来自门禁，永远不来自走查**。
