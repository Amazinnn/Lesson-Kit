# PRODUCT-MANUAL — lesson-kit 产品说明书

> **这是一份面向使用者的功能说明书**，讲「这个东西怎么用、每一步会发生什么」，不讲实现。目标是用足够的细节让使用者对每个操作都有准确预期——宁长勿略。
>
> **写作纪律（与 AGENTS.md 同步）：**
> 1. 正文里的每一个设计名词必须在 `docs/GLOSSARY.md` 有条目；没有就去补条目，不许裸用。
> 2. 行为描述不确定时，写「以 openspec 规格为准」并附规格文件名；**禁止编造未实现的行为**。
> 3. 每章头部标注：目标深度 / 当前完成度 / 权威规格。
> 4. 每次功能变更交付时，同步补写对应章节（AGENTS.md 交付纪律）。目标态是极详尽（十万字量级），靠逐次变更长出来，不一次编成。

**全书的恒等式（先记住这一句）**：只有你**显式提交 1–5 自评**（或在图谱里显式改状态）才会写入学习记录；浏览、勾选、草稿、跳题、翻看，一律不写。调度只影响排序与建议，永不锁题，参数永不出现在你眼前。

## 1. 这是什么

**目标深度：短。完成度：✅ 已成文。权威：README、philosophy。**

lesson-kit 把你的课程材料变成一个可以天天用的学习台：知识点、题目、你的评分记录、一条只做背景提醒的遗忘曲线，加上一个可以提问的 Agent 对话栏。它为你每天回答一个问题——**今天练什么**——但决定权始终在你：练什么范围、用哪种模式、什么时候打分，全部由你显式选择，系统只建议、不代劳。

它明确**不**承诺的事：不自动判开放题（主观题永远是你看了解析自己打分）；不替你安排计划外的任务（建议永远可无视）；不显示任何算法参数（没有间隔、难度系数、掌握度百分比——你只会看到「重点练习」「可以复习」这样的人话）；不锁题（任何内容任何时候都能练）。

工作台是三页结构：**练习**（主页）、**知识点**（列表与详情）、**知识图谱**，外加一条常驻右侧的 **Agent 对话**栏。没有更多的页面，也没有藏起来的功能入口——你看到的就是全部。

视觉采用柔和蒙德里安语言：暖纸色是大面积背景，深色线条划分三栏；蓝色用于
主要动作和选中，黄色用于当前阶段与复习提示，红色用于重点练习和失败。颜色
旁始终还有文字、轮廓或位置提示，不要求靠辨色理解状态。

## 2. 开始一天的学习（练习页）

**目标深度：极详。完成度：✅ 首批成文。权威：workbench-ui spec、consolidate-practice-views（专题 19）。**

打开工作台，默认落在**练习页**。它是你的主页，从上到下回答一个问题：今天做什么。

### 2.1 学习安排：长期与阶段目标

页面最上方是「学习安排」区，展示你的**目标卡**：每张卡有标题、截止日期（如「截止 2026-08-31」），写了解说的目标还能展开「查看说明与范围」看原文。没有目标时会如实显示「暂无已设置的长期或阶段目标」——系统不会替你编造目标，也不会生成「课程规划」之类的空话。

点「▶ 添加目标」展开表单：填目标名称、选类型（阶段目标 / 长期目标）、选可选开始日期与截止日期、写说明，保存后立即成为一张真实持久化的目标卡。开始日期不能晚于截止日期，填反时会在表单里就地提示。目标会在右侧「时间安排」的月历上显示为从开始日延伸到截止日的跑道（见第 5 章）；旧目标没有开始日期也无需迁移，会显示为截止日上的单日跑道。目标卡片可以直接「编辑」「删除」；说不清字段时，在表单里用一句话让 Agent 代填——它填在表单里，你确认后才保存。

### 2.2 准备练习：今天要练的

这是全页的核心区块，也是全书最重要的概念：**这里列出的，就是这次真的要练的东西**。它对应「范围」这个概念——你在别处勾选的知识点，全部会汇成这份清单。它有两个状态：

**空状态**：你还没选任何知识点时，这里只有一句话——「还没选定要练的知识点——去知识点页挑一个」。「去知识点页挑一个」是可点的链接，直接跳去选择页（见第 3 章）。不催促、不自动塞内容、不显示任何「推荐」。

**已选定**：每个选中的知识点一行，只有两样东西——知识点名称和一个「✕」。点 ✕ 就取消选中这个知识点。改动会立刻同步：知识点页的勾选框、图谱页的节点勾选、练习页的这份清单，三处永远是同一份数据，在哪边改都一样。行上没有别的任何信息——不显示进度、不显示难度、不显示推荐理由。要练的名单就该是一份干净的名单（这是所有者定下的硬约束：**哪怕工整的字段也会加重阅读量**）。

### 2.3 建议：加今天要练的

准备练习区块下方有一个按钮：「**＋ 加今天要练的（N）**」。括号里的数字是当前建议的数量；没有建议时按钮不带数字。点开才出现建议列表，再点收起——建议平时不占页面一寸地方。

每行严格三样东西：**知识点名称 · 一个短语 · 「加入」按钮**。短语只会是这三种之一：

- `拖了 N 天` —— 这个知识点有一条到期的复习安排，已经过了 N 天。
- `今天到期` —— 复习安排恰好今天到期。
- `覆盖仍低` —— 它在你的每日计划建议里（计划依据目标与覆盖情况生成）。

没有徽标、没有日期、没有数字、没有第二个短语。同一个知识点如果同时「拖了几天」又「在计划里」，只显示到期那条短语——一行只说一件事。

点「加入」，这个知识点进入上面的准备练习列表；它同时从建议里消失、按钮计数减一。**加入的本质就是「帮你勾选」**：和去知识点页手动勾选完全等效，之后随时可以 ✕ 掉。

排序规则：拖得最久的排最前，然后是今天到期的，最后是计划建议。建议最多展开显示 20 条，更多时末尾一行「还有 N 条」。已经选中的知识点不会出现在建议里（避免重复）。

建议区里还有一个「**重新安排**」按钮：点它系统按当前目标与进度重算一次每日建议，完成后自动刷新页面。另外每天第一次打开工作台时也会自动重算一次——除此之外系统不会在背后偷偷动你的建议。

### 2.4 本轮练习：选模式

范围定了之后，在「本轮练习」区做两个必选：

**练习模式（四选一）**：
- **综合题**：这个范围的常规正式题，作答 → 查看解析 → 自己打分。所有未做特殊标注的存量题都在这个模式里。
- **小测**：选择题点选（单选/多选），提交后立刻判对错并显示错因。只拉取标注过可用的微题——没有会如实显示空态，绝不拿普通题冒充。
- **判断**：判断题（是/否），选完立刻判对错并显示错因。同样只认标注过的内容，缺内容同样如实空态。
- **闪卡**：从知识点拆出的键值对记忆卡——看正面、自己回忆、揭示背面、打分。没有选项、没有判分，全凭你对记忆的诚实。背概念、背术语用这个。缺内容同样如实空态。

**自评时机（二选一）**：
- **每题作答后自评**：做一题打一题的分。
- **完成后统一自评**：先一路做完，最后在收束页统一补分（见 6.6）。

模式选好、范围非空，「**开始本轮练习**」按钮才点亮。范围是空的时候它一直是灰的——这是设计，不是坏了：**没有范围绝不拉题**。灰色的按钮也能一眼看出是灰的（浅灰底、灰字），不会让你误以为它能点。

页面中部还有一句常驻说明：「当前范围由知识点视图明确选择；本轮不会自动扩展范围。」——练到一半不会突然冒出范围外的题。

### 2.5 开始与结束

点「开始本轮练习」后进入练习流（见第 6 章），页面同时收起上方的目标卡、准备练习列表、建议、模式选择和右栏时间安排——**中间栏只剩练习本身**，做题就是全部，做完（或提前结束）它们原样回来。界面任何时刻都如实告诉你处于哪一步，不会出现「不知道自己在干嘛」的中间态。

### 2.6 一个完整的开场例子

走一遍最常见的早晨流程，把前面所有零件串起来：

> 打开工作台，落在练习页。学习安排区显示目标卡「第八章前 20 节覆盖 · 截止 08-31」。「今天要练的」还是空的，只有那句话和一个「＋ 加今天要练的（20）」。
>
> 点开建议：第一行「帕斯卡恒等式 · 拖了 6 天 · 加入」——上周练过、按排期该复习了，拖了六天。点「加入」，它跳进准备练习列表；建议按钮变成（19）。又看到「二项式定理 · 覆盖仍低」，最近没怎么碰它，也点「加入」。剩下 18 条建议暂时不想理，把建议区收起——列表干干净净就两行：帕斯卡恒等式 ✕、二项式定理 ✕。
>
> 觉得还想带上一道具体卡过的知识点，去知识点页把「鸽巢原理」勾上——回到练习页，准备列表里它已经在了（三处同步）。
>
> 范围三个知识点，够今天练了。选「综合题」+「每题作答后自评」，「开始本轮练习」点亮，点下去。今天的学习开始。右侧的时间安排里，08-31 的目标格安静地待在月历上——不急，还有两天。

## 3. 选定范围：知识点页与知识图谱

工作台不会用省略号隐藏知识点名称、题目、目标或备注。长文本会在自己的栏内
完整换行；代码块、宽公式和表格如果超过栏宽，只在自身区域横向滚动，不会把
中栏或 Agent 右栏撑宽。

**目标深度：详。完成度：✅ 首批成文。权威：workbench-ui spec。**

范围（要练哪些知识点）只有两个加入入口：知识点页和知识图谱页。两个页面的勾选与练习页的准备练习列表**实时是同一份数据**——在哪边改都一样。阅读、导航、排序都不会改变勾选。

每个工作区页面的中栏右上角都有一个小型「**练习范围 N**」按钮。点开会出现范围托盘：里面完整列出当前已选知识点，内容多时直接在托盘内用鼠标滚轮上下浏览；点某行的 × 可以移除，点「练习这些知识点」进入练习页。右上角的减号把托盘收回小按钮。选区和展开/收起状态都在当前标签页跨页面保留。

### 3.1 知识点页

左侧导航点「知识点」。本章所有知识点列成清单，每行：勾选框 + 知识点名称（可点进详情页）+ 一行小字——关联题目数（如「12 题」），以及该知识点当前的行动提醒：有明确薄弱证据的带「**重点练习**」、到期的带「**可以复习**」，两者都没有就什么都不标。没有掌握度、没有分数。

进入详情后，正文使用更大的阅读字号、宽行距和单侧结构线，是页面最醒目的
内容；提醒和关联题目与正文拉开距离，主题入口保持紧凑。

顶部工具条：

- **排序**：课程顺序（默认，跟教材章节走）/ 名称 / 题目数量 / 学习状态 / 重要性，旁边的 ↑ 按钮在升序降序间切换。排序是稳定的：同值条目保持原有相对次序。排序纯视图操作，不写任何记录。
- 勾选结果立即进入右上角的练习范围托盘；勾选若干后可从托盘直接回练习页开练，一个都没勾时托盘内的练习按钮禁用。

### 3.2 知识图谱页

左侧导航点「知识图谱」。本章知识点构成一张力导向图，连线是知识点之间的关系。可以做的事：

- **搜索**：按名称定位一个节点。
- **切换视图（投影）**：关系结构（默认，展示知识点之间的关系）/ 题目数量 / 重要性 / 学习状态——同一张图换着角度看，基于已有指标，不发明新指标。切换指标时节点不会瞬移或整图刷新，而会像气泡一样向新位置移动：指标越高，节点越大、越靠近中心。题量用蓝色色谱，重要性用黄色色谱；学习状态用蓝/黄/红/灰表示掌握/复习/待加强/未标记，并按关注优先级 `needs_work / review / null / mastered` 从中心向外排列（待加强最靠中心）。工具栏会同步说明当前视觉含义。
- **切换视图（投影）**：关系结构（默认，展示知识点之间的关系）/ 题目数量 / 重要性 / 学习状态——同一张图换着角度看，基于已有指标，不发明新指标。
- **按学习状态筛选**：可以同时勾选重点练习、可以复习、已掌握、未标记中的一个或多个类别。没有勾选时显示全图；勾选后，不符合条件的节点和相关连线先淡出，保留节点按状态聚成一团或多团。多项筛选取并集，跨团关系仍显示。点「清除筛选」恢复全图。筛选和上面的视图投影可以同时使用，且都不改变练习范围或学习记录。
- **聚拢**：滑杆调整节点的聚散程度；「适应画布」一键缩放到全图可见；另有 ＋/− 逐步缩放。
- **勾选节点**：点选节点即勾选知识点，与知识点页、练习页的准备列表同步。图大的时候不用回列表页翻。
- **学习看板**：右侧栏默认显示「学习看板」标签：点一个节点，看板显示它的名称、提醒词（重点练习/可以复习）、关联题数等**有限**信息，以及「打开知识点」进详情。看板刻意只显示有限信息——不看参数、不看证据明细。要跟 Agent 说话就切到旁边的「对话」标签。

图谱稳定后保持完全静止，只有拖拽、筛选、聚焦、切换投影、缩放或调聚拢时才重新布局。图不呼吸、不晃动；系统开启「减少动态效果」时，投影切换直接显示稳定终态。
图谱稳定后保持完全静止，只有拖拽、筛选、聚焦、缩放或调聚拢时才重新布局。图不呼吸、不晃动；系统开启「减少动态效果」时，筛选直接显示稳定分群结果。

关系结构视图会优先选择交叉更少的确定性布局。关系强度同时控制连线的宽度和
深浅；每条关系由阴影、管体和高光三层构成，弱关系先绘制、强关系后绘制，
因此密集区域中较强关系仍保持清晰。该效果只读取既有关系，不写入图谱坐标或
学习数据。

### 3.3 知识点详情页

从列表或图谱点进一个知识点，看到：正文（支持公式、图片、`[[知识点]]` 互链跳转）、行动提醒词（若有的话）、以及「关联题目」区——按主题分组折叠展示（点组名展开），每组内是题干与解析入口。

页头有「**练习此知识点**」按钮：单点突破一个知识点时用它，它会带着这一个知识点回练习页（等效于只勾选它一个）。

### 3.4 一条铁律

练习范围**只能**来自你的显式勾选（或建议区里你亲手点的「加入」）。对话里随便聊天、系统的弱项排序、每日建议，都不会悄悄改你的范围。唯一的例外也握在你手里：Agent 只有在收到你的**明确练习意图**时才可能替换范围（见第 8 章）；普通对话永远只读。

## 4. 建议与计划：系统怎么「多嘴」

**目标深度：详。完成度：✅ 首批成文。权威：daily-learning-plan spec、consolidate-practice-views。**

系统通过两个渠道提建议，共同原则只有一条：**只提醒、不强迫、不露参数、可无视。**

**每日建议**：每天第一次打开时，系统按你的目标、进度、覆盖情况算一次当日建议；也可以随时用建议区的「重新安排」手动重算。它最多只有三条，措辞是「覆盖仍低」这样的人话，不带「去做第 3.2 节」式的指令。计划失败时保留上一次的有效结果，不会给你看一个报错堆栈。

**到期建议**：你练过的内容会被排期复习（第 7 章讲机制）。到期了的、拖了日的，汇进候选区，按「拖了 N 天」「今天到期」标注，拖最久的排最前。

两条渠道在「＋ 加今天要练的」里合流（第 2.3 节）。系统的全部「主动性」到此为止——它不会弹窗、不会置顶催促、不会因为你不理建议就加重语气或加倍推荐。学习是你的，它只管把该说的用一句人话说到位。

## 5. 目标与时间安排

**目标深度：详。完成度：✅ 首批成文。权威：calendar-workload spec。**

练习页右侧有一个「时间安排」卡（标注了「实验视图」——形态还会迭代），全部**只读**：它不写、不改、不重排你的任何数据。

**目标时间跑道**：当月月历中，每个有截止日期的目标是一条横向跑道。填了开始日期时，跑道从开始日持续到截止日；没有开始日期的旧目标显示为截止日上的单日跑道。跨周目标按自然周换行续接，仍然是同一个目标；时间重叠的目标自动占用上下不同的跑道，不会互相遮盖或合并。阶段目标用黄色，长期目标用蓝色，逾期目标只增加红色边缘；今天的日期格保持高亮。跑道标题在空间不足时不撑破边界，完整标题和起止日期保留在悬停提示与无障碍标签中。窄栏允许月历自身横向滚动，不挤压整页。

本月之外或没有截止日期的目标不会硬塞进日期格，而是在月历下方如实列出。没有任何目标且 14 天内也没有到期任务时，显示一句诚实的空态：「最近没有安排在日历上。」

**14 天任务量柱状与趋势线**：从今天起 14 天，每天有多少项到期就画多高的柱，柱下标日期与数量；叠在柱上的黄色平滑线只帮助看出任务量正在上升还是回落，不是预测。某一天的量达到非零日均的两倍会带一个「**重**」字，趋势线上同时出现红点——意思是「这天恐怕练不完」。没有到期项时不画一条虚假的零趋势线。

**让 Agent 看看**：出现「重」日时，卡片标题旁会出现这个按钮。点它把一句话预填进右侧 Agent 输入框——「最近几天任务偏重（最多的一天 N 项），帮我重排一下。」——**只是填进去，绝不替你发送**。发不发、怎么跟 Agent 商量，由你决定。

窄屏（窗口约 1000px 以下）时，时间安排自动移到页面下方整宽显示，不跟内容挤。

## 6. 练习过程：一题一条流水线

**目标深度：极详。完成度：✅ 首批成文（微题实测细节见 6.3/6.4，判分边界见 6.8）。权威：review-workbench spec、micro-quiz-content spec、flash-card spec。**

### 6.1 通用节奏

每轮练习就是一张一张卡片向前走：**看题 →（作答）→ 揭示解析 → 自评 → 下一题**。当前处于哪一步永远有明确的界面状态；网络出错时错误信息留在原地并给「重试」按钮，不会静默吞掉你的操作。

### 6.2 综合题（exam）

1. 题目卡展示题干（支持公式与图片）。
2. 在作答框写下你的解答（写与不写随你——草稿不写库）。选择题直接点选项作答，多选题用勾选，选中项会自动收集成你的答案。
3. 点「查看解析」对照完整解答。
4. 在紧凑反馈区直接填 **1–5 自评分**（1–2 = 没掌握，3 = 一般，4–5 = 熟练，语义你自己把握），可在下一行附一句备注（比如「卡在第二步」——备注会原样保存并参与弱项识别）。这里是数字填空，不会展开成五个选择按钮。
5. 点「记录并下一题」——**这一刻**才写入记录（一次写入：反馈 + 信号 + 进度 + 调度），然后进下一题。

开放题（证明、设计、建模、解释类）遵循「**先作答，再揭示**」：解析揭示后你对照自己的过程打分，系统不代劳判断。多步题可以把「卡在第 N 步」连同一句备注标记下来——这个卡点标记会存进本次尝试，之后在对话里问 Agent 时原样带上，不用你再解释一遍卡在哪。

### 6.3 小测（micro）

选择题点选作答（单选点一个，多选点多个、全对才算对）：点选项 → 提交 → **立刻判分**——答对显示「回答正确」；答错显示「回答错误」，并附上为什么（错因说明），同时**高亮正确选项**。判分发生在浏览器本地，只是即时反馈，**它本身不写学习记录**；你的 1–5 自评才是记录的触发点。小测**没有**自由文本作答框——它考的是概念辨认与区分，不是长篇推理（那是综合题的事）。

统一自评的轮次里，判分同样即时：横幅（对/错 + 错因 + 正确项高亮）会**停留约两秒**再自动进下一题——够你看清对错，不打断节奏；不想等就点「跳到下一道题目」立刻走。评分仍然留到收束页统一给。

### 6.4 判断（yes_no）

题干 + 「是 / 否」两个选项。选完**立刻判分**：答对显示「回答正确」；答错显示「回答错误」，并附上为什么（错因说明，比如「3 恰有两个正因数」），答错时同样高亮正确选项。判分发生在浏览器本地，只是即时反馈——**它本身不写学习记录**；你的 1–5 自评才是记录的触发点。统一自评时的停留节奏与小测一致。

### 6.5 闪卡（flash_card）

从知识点内容拆出的**记忆卡**：一张卡就是一条键值对——正面是提示（一个术语、一个问题），背面是对应的答案。流程最简单：看正面 → 自己在心里回忆 → 点「揭示」对照背面 → 打 1–5 自评。没有选项、没有判分，全凭你对记忆的诚实——记得牢就打 5，含糊就打 2，系统听你的。一卡只考一个点，背定义、背术语、背结论这类「说得出 / 说不出」的内容用它最快。统一自评时，收束页会列出每张已玩卡的正反面供你补分。闪卡和题目一样有自己的复习排期，到期了照常在建议里以知识点名义出现。

闪卡可以**自由回翻**：「上一张 / 下一张」在本轮已看过的卡之间移动——翻回去时揭示状态原样保留（看过的背面直接可见，已评分的卡只读）；翻到历史末尾再按「下一张」才会拉新卡。中途跳过没揭示的卡，翻回去还能补揭示——补了就算玩过，等收束页补分。

### 6.6 两种自评时机的实际体验

- **每题作答后自评**：如上，做一题结一题，节奏干净。
- **完成后统一自评**：做题过程中不打分，一路做完；**判分照常即时**（横幅停留两秒再走），只有评分留到最后。点「提前结束本次练习」（或题目自然做完）会进入**会话末统一自评**页：列出所有还没打分的题，逐题补 1–5 分；「跳过全部」则这些题完全不记录（不留半条）；底部一个「**再练同类**」按钮，用同一组知识点立刻再开一轮——专门用来「把痛点练到通」。

两种时机下都有一个常驻的小入口：「跳到下一道题目」。跳过的题不写任何记录——不惩罚、不记欠账。已经作答或已揭示的卡不会被跳过降级：它们的待评分状态保留到收束页。

### 6.7 中断与恢复

练习会话存在浏览器标签页里：同一标签页**刷新或离开再回来，会恢复到原题**——练习模式、当前题（包括闪卡回翻到了哪一张）、已做题集合、每题的作答/判分/揭示状态、待统一评分的队列全部还原，且不会重复拉同一道题。关闭标签页则未提交的作答草稿直接消失，系统不会替你补写任何记录。已保存的评分永远安全——它们在池里，不在浏览器里。

### 6.8 判分的边界（重要）

判断/选择题的「回答正确/错误」是**即时反馈**，不是学习结论。系统对一道题的学习结论只有一个来源：你的 1–5 自评。所以答对了但觉得自己是蒙的，就诚实地打 2 分——系统听你的，不听题面的。

### 6.9 一个综合题回合的完整例子

> 题目卡出现：「40. How many ways are there to select 12 countries …」——一道关于分组选择的计数题。你在作答框写下自己的解法，感觉卡在第二组的人数上，但先写完。
>
> 点「查看解析」。对照后发现思路对了一半：分组内部用了组合，但忘了各组之间是乘法关系。在反馈区打 **3**，备注写「乘法关系漏了，分组内 C 的选取没问题」。点「记录并下一题」——这一瞬间，一条反馈（3 分 + 那句备注）进了池，对应知识点（加法规则/乘法规则方向）的薄弱证据被加强，进度更新，这道题的下次复习日期被推后了一点。整套动作一次完成，你只会感觉到「下一题出现了」。
>
> 做到第五题有事要走，直接关标签页。前四题的评分都在池里；第五题的草稿随标签页消失，不欠账。晚上重新打开工作台，范围还在准备练习列表里躺着——随时点开始，从头再来这一轮。

## 7. 记录与调度：你的评分去哪了

**目标深度：详。完成度：✅ 首批成文。权威：review-workbench spec。**

### 7.1 一次自评，四件事

你提交 1–5 分的那一刻，系统原子地做四件事：记一条**反馈事件**（评分 + 备注）、更新**学习信号**（低分会加强对应知识点的薄弱证据；信号只加强不自动消除）、更新**当前学习状态**（1–2 分 → 重点练习，3–4 分 → 可以复习，5 分 → 掌握）、更新**调度**（这道题的下次复习日期按新间隔推进）。这是一次写入，不多不少；2 分和 5 分留下的痕迹不同，但流程完全一样。

除自评外唯一的写入口：在图谱里显式编辑一个知识点的状态——它按对应评分更新状态与调度，但**不**追加反馈历史（改主意不留下 gossip）。

### 7.2 调度只做背景

每道练过的题有自己的复习排期。到期了的**只会**出现在练习页的「加今天要练的」建议里，带一句「拖了 N 天 / 今天到期」。它永远不会：弹窗催你、把没练的题藏起来、拒绝你练任何东西、或把「间隔」「熟悉度」这种参数摆到你面前。**调度永不锁题**——想练没到期的？随时练，正常记录。

### 7.3 方向（当前仅数据层）

记忆回忆类知识点可以按「方向」分别排期（比如中→英、英→中各一条进度，互不影响）。目前界面没有专门的方向卡练习入口——系统也不会主动引导你做「卡片会话」；方向排期只在建议里照常以知识点名义出现。什么时候做卡片式练习，等真实需要出现再说。

### 7.4 你会看到的全部「评价词汇」

整个系统对你的学习状态只使用三个词：**重点练习**（有明确薄弱证据）、**可以复习**（到期待回看）、其余**保持沉默**。没有分数、没有百分比、没有「掌握度 73%」这类伪精确。系统对你的全部判断，都压缩成这三个词，其余交给你的自评和体感。

## 8. Agent 对话

**目标深度：详。完成度：✅ 已成文（2026-08-29；讲解/诊断一键任务同日经所有者决定移除，见 remove-explain-diagnose）。权威：ai-teacher-bridge spec、workbench-ui spec。**

右侧是 Agent 栏。它背后没有内置的 AI 内核——接的是你自己机器上的 Agent 命令行（Codex / Claude），配置归你，账单归你，Lesson Kit 只做桥。

**新建对话与选择 Agent**：点「新建」会列出本机可用的 Agent（在 PATH 上发现的 Codex / Claude）。选中即创建对话，**之后这个对话固定用这个 Agent**——系统绝不会悄悄换一个，Agent 掉线、超时、退出都会如实报错，而不是装作一切正常。历史对话列表在左侧，随时切回、重命名、删除。

**自由提问与练习页上下文**：对话里随便问。你在哪个页面、正在练什么，Agent 自动知道——练习页发消息会带上**当前题目**、练习模式和进度（比如「已做 5 题」）；知识点页会带上当前知识点；图谱页会带上你选中的节点和筛选词。不用复述背景，直接问。

**执行过程怎么看**：Agent 开始工作后，对话流里会出现一张「执行计划」。命令、工具、搜索和回答生成各占一行，同一步从「进行中」原位更新为「已完成」或「失败」，不会刷出一串重复状态。命令与工具有输出时可点「查看输出」展开，长命令会换行、长输出在卡片内部滚动，不会把右栏撑破。底层的 `TURN_STARTED` 一类协议名和 Agent 的隐藏推理不会显示；对话完成后重新打开，成功轮次的计划仍在答案前面。

**想聊某道题就直接聊**：你在练习页发消息，Agent 自动带着当前题目和你的作答上下文——想让它讲这道题、找卡点，用对话说就行，不需要专门的按钮。

**没配 Agent 时的样子**：对话面板提示「暂无可用 Agent。请先配置一个提供方。」——**其他所有功能照常**，练习、记录、调度一点不受影响。配置动作是在命令行跑 `wb bridge add`——Agent 没配就是没配，界面不装。

**Agent 能改你的练习范围吗**：只有一种情况——你在消息里**明确表达了练习意图**（比如「帮我练这几个知识点」），Agent 返回的结构化动作才会替换当前选区，而且只换一次。普通聊天里 Agent 说什么都动不了你的选择。

**Agent 能帮你出题入库吗（Check 管线）**：能，但只有你明确要求时——在对话里说「给某知识点出题 / 补几张闪卡」，Agent 产出的内容会先过**确定性门禁**（字段契约、id 规则、重复 id 拒收、来源证据必填），通过后直接入池并记一个**批次号**；对话流里会出现一张结果卡片（批次号、条数、备份位置）和一个「整批回滚」按钮。门禁没过的话，每一条拒绝原因都会原样列在对话里，池子一个字节都不动。对结果不满意，点「整批回滚」（或命令行 `wb ingest rollback --batch 批次号`）一次撤销该批全部内容；该批内容已经产生过练习/评价记录时，回滚会拒绝并如实告诉你——绝不会偷偷删你的学习记录。

**普通对话绝不写学习记录**：聊天本身不产生任何学习写入——不打分、不改状态、不动调度。对话留痕（谁问了什么、答了什么）保存在工作区本地，作为过程记录，不是学习记录。你的学习记录仍然只有一个来源：你自己提交的 1–5 自评。

## 9. 数据安全边界

**目标深度：详。完成度：✅ 已成文（2026-08-29）。权威：ARCHITECTURE、workbench-content-governance spec。**

一句话版本：**系统只在你明确动作的那一刻写库，其余一切只读。**

**会写什么**（全部由你的显式动作触发）：

- **1–5 自评**（练习页或收束页点「保存」的那一刻）：一次原子写入四件事——反馈事件、学习信号、当前状态、调度（第 7.1 节）。
- **图谱状态编辑**：在图谱里显式改一个知识点的状态——按对应评分更新状态与调度，不追加反馈历史。
- **目标的增删改**：练习页目标表单里你填的长期/阶段目标。
- **Agent 出题入库（Check 管线）**：你明确要求出题/补池、Agent 产出通过门禁的那一刻——按批次记号入池，整批可回滚（第 8 章）。

**绝不写什么**：浏览（翻了哪页、看了哪题）、勾选（选区勾勾改改）、作答草稿（没点提交的作答只活在当前标签页里，关掉就没）、跳过的题（不写、不记欠账）、普通对话（第 8 章）。这些动作再频繁，池里也不会多一个字节。

**池数据库与备份机制**：全部题目、卡片、知识点、你的记录都在一个池数据库（`pool/dmath.db`）里。内容入库只有一条合法通道——**确定性门禁配方**（Check 管线，`wb ingest` 或对话桥出题动作），任何一批内容 apply 之前都会先做可恢复备份，apply 在单事务里执行，失败即回滚、池子原样；每一批都带**批次 id**（内容行自带批次标记），一条命令（或结果卡上的按钮）即可整批撤销。所以「内容坏了」永远有得回滚。

**工作区注册表位置**：每个工作台的本地状态（工作区注册表、对话留痕、任务工作文件、讲解结果）都在项目下的 `.lessonkit/` 目录里；池数据库在 `pool/` 下。这两处之外，界面的任何操作不落盘。

**走查一律用副本**：开发与验收从不直接碰真实池——用隔离注册表（`LESSONKIT_WB_HOME` 指到临时目录）+ 拷贝的池副本 + 专用端口起服务，全部流程在副本上走一遍才算数。这条纪律对开发者和 Agent 一视同仁：**真实池的写入只来自门禁，永远不来自走查**。
