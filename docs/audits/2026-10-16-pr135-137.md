## What landed

The accepted Agent UI v1 baseline (PR #129) was implemented in three stacked PRs
and merged in order, each after an independent audit:

- **PR #135** — rail foundation: composer autosizing, context chips, the inert
  Activity Float / Bottom Dock / Adaptive Split containers, explicit collapse.
- **PR #136** — runtime surfaces: provider activity projection, editable-while-
  running composer, single-flight send, session-scoped runtime state, and the
  Approval Gate for low-reversibility content rollback.

- **PR #137** — Managed Paper Artifact handoff: a `paper_artifact` conversation
  action that must resolve to a saved Paper, plus the live Adaptive Split preview.

Contract work for all three is in OpenSpec change `agent-ui-v1-implementation`
(proposal, design, deltas for `workbench-ui` and `ai-teacher-bridge`), with the
live specs, `FILE_CONTRACT.md`, `docs/PRODUCT-MANUAL.md`, and the action graph
updated in the same branches. The change is still open; tasks 4.1–4.3 remain.

## Findings that changed the code

- The Artifact split could ride over the central page at common desktop widths;
  panel width and reserved space now come from one custom property, and a narrow
  central column falls back to an explicit preview layer.
- The composer had no visible keyboard focus indicator.
- The Activity Float was emitted after the page body, so it started below the
  fold on long pages.
- The context chip kept a stale knowledge-point count after a same-page scope
  change; the central selection writer now refreshes it.
- Enter could submit a second turn while the first POST was still in flight.
- An open rollback Approval Gate, its activities, and the poll cursor could
  survive a conversation switch and act on the new conversation.
- A failed progress read was reported as a provider failure and invited a resend
  that could duplicate work; it is now unavailable progress with the turn kept.
- `paper_artifact` accepted fabricated ids, titles, and counts; identity, title,
  and count now come from the selected workspace's saved-paper record, and an
  unknown id produces no card with a visible reason.
- The completed-turn Adaptive Split preview was closed by the conversation
  reload that follows a finished turn.
