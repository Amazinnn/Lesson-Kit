# lesson-kit 设计哲学

**Date:** 2026-06-18
**Status:** 核心光谱已锁定（9 轴）——待工程化轴另录。学习模式细节待续。

## 核心命题

**不是帮你跳过源材料，是帮你回到源材料。**

市面上几乎所有 AI 学习工具共享一个隐含假设：课程内容是负担，需要被简化、浓缩、代劳。——它们的存在理由就是帮你省时间。

lesson-kit 反过来：它帮你花时间，去读你本来应该读但不知道怎么读的东西。

这就解释了为什么：
- `RED_LINES.md` 第一条：「速览不能替代源材料阅读」
- 场景判断 MCQ 必须「回到源材料才能答对」
- `quick_absorption` 最多 3 句，不准写完整解释
- Print 功能导出的是链接网络，不导出摘要合集
- Pipeline 提取的是持久化知识资产，不是一次性考点浓缩

## 服务对象

不是「想考高分但不想读书的人」。

是**想读进去但不知道从哪开始的人**。

教材在面前——每句话都认识，但不知道读完重点在哪、跟前面的东西什么关系、该注意什么易错点。lesson-kit 不是帮你取代教材，是帮你导航你本来就应该看完的那个教材。

未来扩展到非课程场景：一本想读的课外书、一篇有意思的博客、一套想深入的技术文档——任何"你想认真读进去但不知道怎么组织"的知识材料。

## 差异定位

### 其他产品在做什么

- 喂课程 PPT/PDF → 生成知识大纲
- 生成模拟卷
- 根据学生掌握度个性化推荐学习计划
- 核心场景：备考、考前抱佛脚、通过考试

### lesson-kit 不同在哪

| 维度 | 其他产品 | lesson-kit |
|------|---------|-----------|
| 学习假设 | 课程内容是需要简化的负担 | 课程内容是值得深入阅读的宝藏 |
| AI 角色 | 内容提供者——帮学生生成答案和总结 | 认知导航者——帮学生在源材料中找到自己的路 |
| 时间观 | 一次性的——考完就丢 | 累积的——知识池是随时间增值的永久资产 |
| 产品形态 | 重型 SaaS 平台（注册、付费、课程库、Dashboard） | 轻量 personal skill——在你自己电脑上跑，零基础设施 |
| 学习场景 | 单一——考试冲刺 | 多种模式——精读 / 速成 / 博雅 / ...（同一池子，不同模式） |
| 与源材料关系 | 替代——读完产出就不需要回去翻书了 | 导引——产出有意不完整，迫使你回到源材料 |
| 面对非课程内容 | 不支持（假设前提是有课程大纲和考试范围） | 支持——博雅模式面向任何文字材料 |

### 产品形态愿景

lesson-kit 不一定是重型项目——不强制有前端。但至少是一个有清晰哲学内核、有多个可配置学习模式、有持久知识资产的设计系统。即便只有 Markdown 产出，它也是**独特的**——每一份速览、每一道场景判断题、每一个 Obsidian 知识图谱节点，都在表达"学习不是消费内容，是建立你和知识之间的关系"。

## 设计哲学光谱

lesson-kit 不是选一个极端的哲学立场，而是定义了一个多维光谱。每个学习模式（精读 / 速成 / 博雅 / ...）在这个光谱上有自己的坐标。

光谱轴分为两类：**核心光谱**（已确认，指导所有设计决策）和**待工程化**（方向确认但工程表达尚未定型）。

### 核心光谱（9 轴）

#### 1. 知识归顺度（唤醒自我 ↔ 规训自我）

知识为谁的秩序服务？

- **唤醒端**：工具不告诉学生"你应该学到哪了"，而是问学生"你看到了什么"。思考题开放，关联靠学生主动发现。教材是地图，学生是探险者。
- **规训端**：工具提供结构化清单——大纲、考点、掌握度诊断。你知道考什么、缺什么、按什么顺序补。教材是任务清单，学生是执行者。

其他产品几乎全部站规训端。lesson-kit 的核心——知识可以在不同场景中选择归顺于读者的内心节奏还是归顺于给定的学习框架。

#### 2. 离原材料距离（近源 ↔ 远源）

产出在什么程度上挑战和邀请学生回到源材料？

- **近源端**：产出只给关键词、定位描述——学生必须自己回到教材找到完整的定义、推导、例题。产出的价值是"告诉你花时间读哪里"。
- **远源端**：产出本身几乎自给自足——包含完整的阐释、例题、推导过程。学生可以仅靠产出理解和应用。产出的价值是"就算你不翻书也能懂"。

lesson-kit 默认在近源端。但速成模式可以允许拉远——当学生需要快速过一遍时，提供更大的自包含度和独立性。

#### 3. 接收 ↔ 建构

知识作为成品交付，还是作为原料让学生自己拼装？

- **接收端**：知识是现成的——结构清晰、阐释完整、关系已连好。学生只需要读和消化。
- **建构端**：知识是碎片——思考题没有预设答案，关联需要学生自己发现和连接。学生的脑力劳动本身就是学习过程的不可剥夺部分。

#### 4. 呈现 ↔ 告知

工具是窗户，还是替身？

- **呈现端**：工具是窗户——创造条件让学生自己面对源材料，然后退开。像望远镜的目的不是告诉你月亮是什么样的，而是让你自己看月亮。工具的职责是减少你与源材料之间的障碍，不替你决定哪里重要、哪里值得看。
- **告知端**：工具替你提取、解释、总结——你得到的是加工后的结果。NotebookLM 的摘要、ChatPDF 的答案提取、可汗学院的讲解——全在告知端。

与「离原材料距离」正交：你可以近源但仍在告知（只给关键词但关键词本身就是提取和强调），也可以远源但指向呈现（一段引导文字让你想去亲眼看看）。距离轴问的是"还需要回去吗"，呈现轴问的是"我替你看了还是让你自己看"。

#### 5. 无知测绘 ↔ 全知假象

知识体系有多诚实？

- **无知测绘端**：系统标注"我们不知道什么""这里存在争议""本工具未覆盖的领域""本领域当前的开放问题"。学完这些后你不只掌握了新知识——你还更清楚地知道你离学科前沿有多远。
- **全知假象端**：呈现完整、封闭的知识体系，暗示"学完这些你就掌握了这门学科"。

没有任何面向大众的教育工具做过系统性的无知测绘。消费者购买的是"掌握"的承诺——一个敢说"学完这个你将更清楚地意识到你对这门学科的了解是多么浅薄"的产品，违背所有市场直觉。lesson-kit 选择诚实。

#### 6. 静止 ↔ 流动

学习体验的节奏由谁掌控？

- **静止端**：允许停下。在关键内容之后——沉默，没有下一步按钮，没有进度条催促。工具在知识周围创造空间。像好老师在问了一个真正的问题后、任何人发言前留下的那段沉默。
- **流动端**：持续前行的动力——平滑过渡、清晰下一步、累积进步感。工具通过保持移动来维持参与度。

整个 edtech 行业建立在"参与度 = 动量"的度量基础上。静止作为设计价值在数字学习工具中几乎完全缺席——不是因为不重要，而是因为它违背了所有 UX 教条。lesson-kit 承认：源材料不是地铁站，你需要花时间在那里。静止就是为这种停留创造许可。

#### 7. 单脉络 ↔ 多脉络

给学生一条解读路径，还是多条视角？

- **单脉络端**：一个 through-line 贯穿全章。线性、连贯、有始有终。学生信任工具选的那条线，沿着它走下去。
- **多脉络端**：每个 KP 可沿不同 through-line 解读。学生自己选择走哪条线。允许非线性的跳跃阅读。同一章从不同角度进入，看到不同的东西。

#### 8. 难度自主权（固定难度 ↔ 学生自定难度）

难度是谁说了算？

- **固定端**：按客观复杂度（difficulty 1-5）排——简单概念在前，复杂概念在后。系统用统一标准判断什么难什么容易。
- **自定端**：学生说"这部分难"，系统就重点展开；学生说"这部分简单"，系统就轻量掠过。学生感知的难度和客观 difficulty 之间往往有差距——尊重这种差距，而非纠正它。

#### 9. 错误价值（避免错误 ↔ 拥抱错误）

学生犯错是缺陷还是机会？

- **避免端**：错题是缺陷——做错了说明没学好，需要针对性补。干扰项设计尽量让学生选对。
- **拥抱端**：Productive failure（Kapur, 2008）——先让学生在场景判断里踩坑，再用答案的解释触发"aha moment"。选错比选对学得更深。错误不是教学的失败，而是教学的设计。

场景判断 MCQ 的根本逻辑就在拥抱端：题目有意制造认知冲突，让学生先在错误中暴露盲区，再在解释中重构理解。

### 待工程化（方向确认，工程表达待定型）

以下轴的方向已确认，但在 Agent 可执行的工程表述上仍需打磨。暂不进入核心光谱，后续讨论中逐步落地。

| # | 轴 | 方向 | 卡点 |
|---|-----|------|------|
| 1 | **工具可弃性 ↔ 工具依赖性** | 设计目标是让自己变得不再必要——Wittgenstein 的梯子，爬上去就扔掉。所有商业产品的结构性禁区，lesson-kit 最独树一帜的立场。 | 如何在实际功能中体现"教你不再需要我"而不沦为空洞宣言？需要找到可操作的工程表达。 |
| 2 | **光滑 ↔ 有纹理** | 内容保留真实智力工作的纹理——思考的痕迹、论证的迂回、未解决的张力。AI 时代光滑已免费，纹理才是稀缺品。纹理创造学生心智可以抓住、质疑、反驳的地方。 | "纹理"在 Skill 和 Gate 里怎么指导 Agent 执行？需要从文学描述翻译为工程约束。 |
| 3 | **完成感 ↔ 未完成感** | 你永远不会"完成"一个主题——每次重返源材料都揭示新层次。保留，但严格限制范围：完成一章的满足感是真实且健康的心理需求，不应被未完成感侵蚀。 | 未完成感只在深层理解的语境中适用——什么时候触发、如何不制造知识焦虑？ |
| 4 | **解构/反学习** | 最重要的学习有时候是拆掉已有的错误框架。对白纸学生不适用，但对启发式书籍阅读有价值。 | 严格限制适用范围——非教材场景（博雅模式），且学生已有先验知识框架时才触发。 |
| 5 | **消费 ↔ 品味** | 知识如美餐——对一条定理凝视二十分钟而非迅速勾选。仅适用于精读模式，不进入核心光谱。 | 作为精读模式的模式参数，不作为全局光谱轴。在速成模式中完全不触发。 |

### 已丢弃

以下在讨论中提出但未被确认，记录原因供追溯：

| 条目 | 丢弃原因 |
|------|---------|
| 可见性（透明 ↔ 不透明） | 大多数学生不在乎设计决策为什么这样——元认知层暴露是给设计者看的，不是给学生的。 |
| 情感温度（中性 ↔ 有温度） | 是写作风格问题（STYLE.md 的范畴），不是哲学轴。工具在不同模式用不同语调，但不定义产品哲学差异。 |
| 学习即身份转化 | Lave & Wenger 的理论正确，但"成为不同的人"是整个教育过程的结果，不是一个工具的轴能承载的。太大。 |
| 学习即集体行动/社会维度 | lesson-kit 是 personal skill，不是平台。社会维度不在设计空间内。 |
| 学习即具身/身体性 | lesson-kit 面向文本材料。身体、空间、感官作为学习场所——文本工具无法承载。 |
| 学习即经济批判 | 太政治，与 lesson-kit 的学术定位不搭。 |
| 学习即关系与关怀 | Noddings 关怀伦理——工具不适合谈关怀。模仿关怀就虚伪了。 |
| 学习即审美愉悦 | 是"品味"的子集，已合并。Dewey 的 Art as Experience 在品味轴中体现。 |

## 三种学习模式（初步构想）

所有模式共享同一个 SQLite 知识池。不同模式 = 在核心光谱上的不同坐标组合。

| | 精读模式 | 速成模式 | 博雅模式 |
|------|---------|---------|---------|
| 知识归顺度 | 偏唤醒 | 偏规训 | 极唤醒 |
| 离原材料距离 | 近源 | 远源 | 近源 |
| 接收↔建构 | 偏建构 | 偏接收 | 偏建构 |
| 呈现↔告知 | 呈现 | 告知 | 呈现 |
| 无知测绘↔全知 | 无知测绘 | 全知假象 | 无知测绘 |
| 静止↔流动 | 静止 | 流动 | 静止 |
| 单脉络↔多脉络 | 单脉络 | 单脉络 | 多脉络 |
| 难度自主权 | 固定 | 固定 | 自定 |
| 错误价值 | 拥抱 | 避免 | 拥抱 |
| 场景 | 日常学习、深入理解 | 考前一周、快速扫完 | 课外书、博客、兴趣阅读 |
| 典型产出 | 速览 + 深度讲解 + 课后练习 | 超轻量索引 + 关键公式 + fragile 易混淆清单 | 阅读导航 + 开放式思考题 + 关联到已有知识网络 |

**待工程化轴的模式归属：**

| | 精读模式 | 速成模式 | 博雅模式 |
|------|---------|---------|---------|
| 工具可弃性 | 偏可弃 | 偏可弃 | 极可弃 |
| 光滑↔有纹理 | 有纹理 | 光滑 | 有纹理 |
| 完成感↔未完成感 | 偏未完成 | 完成感 | 未完成感 |
| 解构/反学习 | 不触发 | 不触发 | 条件触发 |
| 消费↔品味 | 品味 | 消费 | 品味 |

> 待工程化轴的模式归属为暂定方向——随工程表达定型后可能调整。

## 附录：全局白空间（2026-06-18 脑暴记录）

lesson-kit 的核心光谱是在以下白空间背景下提炼的。扫描覆盖 ~10 个商业产品（NotebookLM、Khanmigo、Quizlet AI、ChatPDF、Perplexity、Coursera AI、学而思、作业帮、猿辅导、Duolingo）和 ~50 个 GitHub 开源项目。

**元模式**：所有现有 AI 学习工具共享"获取范式"（Acquisition Paradigm）——学习是知识从源头高效传输到脑袋的过程，工具的任务是优化传输速度。lesson-kit 的"返回范式"（Return Paradigm）——学习是反复回到源材料的诚实相遇，工具的任务是创造条件让这种相遇发生——在此光谱中无人占领。
