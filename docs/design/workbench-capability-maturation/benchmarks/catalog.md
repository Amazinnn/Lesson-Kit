# 可执行验收目录与 benchmark 门槛

## 状态与测量口径

本页全部数值为本轮规划选择的工程验收门槛，尚未实测，不是当前成绩。实现后记录基线与结果；未达标要修复或登记经新决策调整的门槛，不能临时降低以宣布成功。数据完整性和操作语义门槛为硬条件。

固定 Windows 桌面、实际 Python/Node/浏览器/Git 版本、CPU/内存、磁盘、视口和缩放。基础视口 1440×900、缩放 100%，补测 1280×800。每个 CLI 性能场景预热 1 次、计时 20 次，给 p50/p95/max；网络、免费模型延迟分别报告。浏览器流程每场景至少 3 次，保存起止截图、操作步骤和实际数据变化。

## 固定夹具

- F1 完整小课程，3 章、12 知识点、24 道题（普通/客观/混合小问）、6 闪卡、6 关系、3 张共享题目的 Paper、2 个未完成执行、12 份作答、4 份经验、2 个目标、8 个课程学习文件、10 张图片以及1份原始教材。二进制总量约 5 MiB，生成器固定字节和文本，所有实体可读固定 ID。
- F2 中等课程，20 章、1,000 知识点、10,000 题、100 Paper、10,000 份作答、30 个并存未完成执行、500 个课程学习文件，附件总量 100 MiB。文本含中文、行内/块公式、表格、长标题及特殊字符。
- F3 异常变体，单项无效引用、损坏图片、未知格式、缺文件、明确删除、同 ID 不同来源、共同基线后的双侧编辑、重复请求及写入中断。每种变体同时包含独立有效项。
- F4 旧格式，至少包括已支持最早用户数据格式、当前主格式及缺新增列的真实脱敏副本。保存 fixture 版本和来源说明。数据不得来自活动库直接破坏。

所有负载在隔离临时目录和独立 Git 测试仓库运行，真实网络 Git 验收另有专用测试远端。性能首次测量同时记录原实现可完成的子集，旧实现不支持的场景标记 unsupported，不捏造基线耗时。

12个学习脚本是真实LLM的交互实操，学习者由脚本模拟，报告须明确。自由生成题由独立答案依据或人工/独立模型复核，生成者自评不构成独立正确性证据。Q004 允许 Agent 完成可代验内容，个人长期学习提升单列观察。

## 发布与恢复

RELEASE-01 每个包运行 `python -m pytest tests -q`、`python -m compileall -q lessonkit.py workbench pipeline pool tests`、`openspec validate --specs --strict`、`python lessonkit.py guard extract-problems --course dmath --chapter ch06`，前端包补 `node --test tests/workbench/*.test.js` 及真实浏览器。输出产物存在时才运行 problem-set guard。任何失败原样登记。

RELEASE-02 记录实际安装入口、`/api/runtime` 的 source_root、进程身份、CLI版本及静态资源版本。副本升级、备份可恢复与正常启动通过后直接切换，备份用于灾难数据恢复，成功批次撤销退役。切换失败保持可解释错误，修正后重试，禁止暗中执行另一份实现。

RELEASE-03 免费测试 API 记录 provider/model/日期/免费依据/调用次数/延迟及失败。不可用时相关包为 blocked，其他独立包继续，付费或本机决策大模型自动调用0。
