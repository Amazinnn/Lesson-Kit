## 依赖与停止条件

首包复用既有 Agent 会话和提交身份机制。仅纳入为确认行为所必需的修复，未证实的全局重构不作为前置。与 agent-chat-simplify 重叠处先核对分支合入和运行事实，再更新对应工件，避免并行重复 change。

针对性学习依赖内容范围可靠和学习证据可消费，不要求先完成整课整理、移动端适配或文件同步。文件交换需理解学习状态的持久边界，不承担外部原生 Agent 会话迁移。迁移与验收是每个受影响包的交付责任，不能全部推迟到最后一个总包。

真实 LLM 验收受阻按 Q063 处理。契约冲突未协调、数据恢复路径未验证或依赖包未接受时，不标记相应包完整交付。其余独立包继续。所有者看到精简摘要，实施 Agent 获得完整输入、任务和证据入口。
