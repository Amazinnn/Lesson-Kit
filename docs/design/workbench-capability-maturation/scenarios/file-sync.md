# 文件同步验收场景草案

状态为已确认产品行为的场景分解，尚非最终实施规格。对应决定修改时同时复核本表，具体文件格式、命令和性能门槛在正式 change 中确定。

## 共用环境与证据

使用 A、B 两个独立临时课程工作区及一个文件媒介目录，路径不能依赖同一台机器的绝对地址。夹具包含知识点、关系、普通与混合小问题目、引用图片、多张共享题目的试卷、完成与未完成作答、草稿和反馈。夹具的实体数量及 schema 版本由最终验收包固定。

每项保存执行前后内容及状态摘要、CLI 命令/退出码/结构化回执、文件清单和可比较的截图。重复执行核对无重复实体与学习证据。模拟测试、CLI 实操、浏览器实操分别登记，失败输出不得登记为通过。

## 待确认后细化

原始资料、对话、浏览器未保存输入、部分失败、身份碰撞、旧版本兼容及媒介布局。未确认行为不写预期结果，不把当前实现自动视为接受标准。
