# 验收与 benchmark 框架

## 所有者交付要求

计划须能交给其他 Agent 实施，且提供程序与仿真之外的真实用户交互体验 benchmark。当前尚无足够基线数据，数值目标待测量及相关体验决策后确定。

## 每项 benchmark 必填内容

- 场景编号、对应决定 Q 编号、拥有该行为的 spec/change、验证负责人。
- 起始状态、数据规模与来源、用户目标、允许操作、成功结束条件。
- 固定环境与版本、可重复步骤、样本次数、计时起止、失败和重试计数口径。
- 当前基线、目标、允许退化、目标依据、未测项。
- 证据文件位置、实际结果、偏差、修复及复验记录。

## 证据层次

| 层次 | 回答的问题 | 证据形式 |
|---|---|---|
| 纯规则与存储检查 | 规则正确、事务一致、重试和兼容是否成立 | 自动化结果及夹具 |
| 集成与故障演练 | CLI/API/进程/文件协作及中断恢复是否成立 | 可重复脚本与运行记录 |
| 真实浏览器操作 | 用户经正常入口能否完成任务 | 操作步骤、屏幕证据、请求结果 |
| 真实学习或作者任务 | 是否减少等待、打断、解释与返工 | 脱敏任务记录及所有者反馈 |

各层分别报告。单元测试通过不计为浏览器或自用验收通过。

## 待细化的体验指标

任务完成率，用户操作步骤，主动澄清次数，重复说明次数，等待时间，中断恢复所需操作，失败后是否明确知道结果，内容返工次数，是否发生草稿或进度丢失，可理解性与主观负担。性能指标按交互场景分别测量，区分本地处理与外部模型等待。

真实课程写入、资料外传和远端 Git 操作按各自授权执行。优先使用脱敏副本和独立仓库复现。验收阶段明确哪些属于模拟、隔离实操与真实自用。


## Q004 已确认的执行责任

Agent 负责全部可代验项目，包括使用测试用免费 API 调用真实 LLM。无需强制所有者逐包或抽样验收。实际浏览器操作、真实模型调用、模型主观判断与所有者反馈分别标记。测试材料优先使用夹具和脱敏副本，记录 provider/model、日期、免费额度依据、调用数、延迟、失败及重试，不记录凭据。不自动转为付费 API。模型评价不能代替所有者本人体验证言。


## 文件往返场景候选

依 S001，后续至少测量 A 工作区导出文件、外部纯文件搬运、B 工作区接收并继续作答、B 导出后 A 接收的完整往返。分别核对题目/试卷依赖、草稿、进度与历史。另覆盖内容未变但版本不同、单侧更新、真正双侧冲突、中断后重试。尚未确定的字段范围和冲突结果须等待对应 Q 决定，再形成可执行 benchmark。远程服务可用性不作为该场景前置条件。


## Q021 针对性练习场景候选

先以脱敏课程夹具和明确的学习任务对照现有普通组卷与教学分支入口，记录正常入口能否采集需求、所选知识点/真题来源是否符合任务、缺题如何披露、生成题有何来源依据、作答反馈如何影响后续加强与到期复习。观察用户需补充说明次数、无关题比例、准备到开始作答所需操作和等待、重复大范围刷题是否减少。需明确每项评价的人工标注或规则依据，不以模型自评替代真实正确性。

决策模型分类候选须先有标注样本、无模型基线、混淆类别、误判代价、吞吐与能耗测量约定。当前仅规划测法，本机模型调用和加载均未授权。真实 LLM 测试仍遵循 Q004 的免费测试 API 边界，并区别功能演练与长期学习效果证据。

## Q025–Q027 发送与中断体验

使用隔离课程与可计数的操作夹具，经真实对话入口分别覆盖发送前失败、未知送达、拒绝、已接受后失败、主动停止和进程中断。记录提交身份、服务端接受次数、实际内容操作次数、对话呈现和恢复卡片数量，区分用户明确重试与自动行为。

已确认门槛为停止或执行失败后自动新增重试队列记录数为 0，停止后自动重新执行次数为 0，同一提交被重复接受或重复执行的次数为 0。未知送达核对继续使用原提交身份。主动编辑后重试保持修改内容并可追溯原失败，已有输入框草稿保持完整。安全自动重试的次数与时间上限待结合现有实现确定并公开，不能无界重试。

重复信息报告尚未复现。验收须分别检查 UI 重复呈现和实际重复操作，不能凭去重单元测试推断真实交互已通过。记录从失败到恢复所需点击、是否离开对话流及用户需要理解的状态字段数，当前基线待测。

## Q028–Q031 体验约束

目标明确且已有必要上下文的场景，不要求用户填写固定表单。记录首次可用练习前的补充说明次数及选题与目标的对应依据。真题和题库来源必须能核对到实际内容，不能伪称生成题为真题。跨日追踪的完成条件待 Q032，不能以同次对话记忆充当验收。

批量修改默认以简短对话汇报，追问时 Agent 能准确说明实际差异、失败和进度影响。验收检查回答与实际修改一致，UI 差异展开不作为交付门槛。更新准备完成后，未经所有者切换动作不得自动切换运行版本；验证版本身份及切换时数据连续性，实际操作步骤与延迟基线待测。

## Q032–Q035 学习承接与诊断成本

在隔日或关闭后重开的场景，经正常入口显示上次目标、完成证据和建议下一步，用户可继续或修改。不能只用同一页面内存验证跨日承接。到达时间预算时在自然节点提示并保存可恢复进度；临考任务优先场景核对暂缓复习仍可查、未被伪记为完成。

诊断样本分别覆盖公式或适用条件不熟、能回忆但无法独立应用、两者并存及证据不足。使用预先标注的任务与可核对的原始作答，记录首次有效加强前耗时、检查题数、无效重复提问、定位准确性及看答案后误判为独立掌握的情况。闪卡、选择题和代表性习题分别评估，不以题型本身证明测到了目标能力。投入门槛待 Q036，不擅自填写已达标数值；短期任务验收与长期学习收益分开报告。

## Q036–Q039 筛查与求助

Q036–Q037 已确定少量客观题起步、练中继续定位的路径。记录首次针对性练习前的检查题数和时间，并与穷举式检查基线比较；具体上限仍待基线，不能将所有知识点遍历作为必需前置。检查结论须披露证据不足，样本中包含猜对及只能识别公式但不能应用的情况。

逐步提示须在用户求助后触发。首步提示与完整解答分别检查，保留现有完整解析入口和历史作答。内容纠错场景覆盖当前题焦点正确及指代不明两种情况，检查 Agent 的依据、待确认措辞与实际修改目标一致。使用无误内容作为反例，防止将用户怀疑直接当成错误事实。

## Q040–Q043 前置质量与队列精简

前置检查样本包含知识点 ID 存在但学术归属错误、仅按章节序号误配、原文内容漏覆盖及合法跨章节关联。分别记录结构检查、来源语义核对、发现时机、漏报及误报，合法跨章关联不能一律拒绝。以进入本次针对性练习前能否发现疑点衡量预防，不只测报表是否存在。疑点处理策略待 Q044。

队列真实浏览器验收检查正常状态仅有消息正文、编辑及删除，分别覆盖单条、多条、长文本、失败后刷新和窄窗口。额外状态字段、立即发送及排序按钮不能作为默认交付残留。编辑提交、取消编辑与删除竞态另经实际操作验证，消息内容、服务端提交身份及恰好一次接受保障须保持一致。前述最后一项是去重验收要求，不承诺外部 provider 的通用恰好一次执行。

来源答案缺失时，检查 Agent 推导标识与真实来源一致。指代歧义场景检查修改前完成一次简短对象澄清，不能先修改再要求用户纠错。

Q044 已确认疑点题暂缓使用。混合样本验收要求未确认疑点题进入本次针对性练习的数量为 0，独立已核对内容仍可开始，并有简短缺口说明。检查未删除题目或改变既有学习历史。疑点解决后的重新使用需核对实际依据，不以去掉显示标记替代内容核查。

## Q045–Q048 来源按需查阅与对象稳定

默认学习界面不因本计划新增来源展示负担，用户请求来源时能定位已知原文位置并准确区分推导与来源内容，原件不存在时不伪称成功打开。此条替代 Q029/Q041 候选中的默认来源可见预期，来源真实性和内部证据要求保留。

真实交互覆盖 A 题发送、排队、切 B 题、发送第二条及随后执行。核对第一条实际读取或修改 A，第二条指向 B，排队不被执行时的页面改绑；仅检查聊天文本不算通过。还需覆盖两题 ID 相同但属于不同课程的场景。启动恢复核对课程身份、执行和学习位置一致，显式目标覆盖上次位置，不可用课程明确说明。

## Q049–Q052 渲染、未提交记录与恢复

渲染建立字段清单，逐项使用行内/块公式、列表、表格及代码片段经真实入口核对，保留编辑原文；显示通过与原文往返分别报告。字段范围待 Q056，不能只以一个展示页代表全部字段。

依 S004，以未完成试卷及其执行检查保留和恢复；原 300 份边界及淘汰测试撤销。覆盖多卷独立草稿、重开浏览器、进程异常、课程切换及题目内容修改。未完成试卷在练习开始界面可发现并继续，不能因数量或存放时间自动淘汰。规模场景仍需测入口可用性和恢复耗时，规模仅为负载测试输入，不构成保留上限。

异常重启后从未开始的队列自动执行数为 0，明确恢复后保持原序及发送时对象。历史回看和错题重练不增加开始普通练习的必经步骤。未完成执行的主动收尾待 Q058，不能自动丢弃代替用户选择。

Q056 已将补齐重点确定为标题类字段。为每个现存内容标题列出正常写入入口及全部显示面，覆盖行内公式、Markdown 强调、长标题和特殊字符。验证列表至详情、练习恢复及历史显示的一致性，重命名打开后取消或原样保存不能改写原文，不能把 KaTeX 辅助文本回填持久标题。正文已有能力仅做相关回归，不据此另做编辑器重建。字段逐项证据表与真实浏览器结果均须交付。

Q057–Q060 补充。继续原卷保持执行身份和草稿，明确重做前须确认，不默认创建另一份未完成执行。删除未提交练习的破坏范围待 Q061，至少检查不误删单题及已提交历史。新课整理验收使用限定章节或试卷，未授权范围的新增或修改数为 0。

并行学习验收覆盖 Agent 修改当前题、修改其他题及只改归属。当前输入操作不被打断，受影响题变更在自然节点呈现且不丢输入，未受影响题可继续；旧版本提交按协调后的契约处理。模拟并发测试与真实浏览器正常操作都要提供证据，不能只靠客户端延时规避并发。

Q061 已明确删除范围。由练习开始界面删除 A 卷未完成执行后，A 从待继续列表消失，原 A 卷可重新开始；其题目、已提交历史及 B 卷的进度和草稿保持不变。刷新或重开后被删除的 A 执行草稿不能因浏览器残留自动恢复。核对其他页面或迟到草稿写入不能复活已清除执行，沿用既有版本与身份机制处理。
