# 验收与 benchmark 框架

## 所有者交付要求

计划须能交给其他 Agent 实施，且提供程序与仿真之外的真实用户交互体验 benchmark。当前尚无足够基线数据，数值目标待测量及相关体验决策后确定。

## 每项 benchmark 必填内容

- 场景编号、对应决定 Q 编号、拥有该行为的 spec/change、验证负责人。
- 起始状态、数据规模与来源、用户目标、允许操作、成功结束条件。
- 固定环境与版本、可重复步骤、样本次数、计时起止、失败和重试计数口径。
- 当前基线、目标、允许退化、目标依据、未测项。
- 证据文件位置、实际结果、偏差、修复及复验记录。

## 证据层次

| 层次 | 回答的问题 | 证据形式 |
|---|---|---|
| 纯规则与存储检查 | 规则正确、事务一致、重试和兼容是否成立 | 自动化结果及夹具 |
| 集成与故障演练 | CLI/API/进程/文件协作及中断恢复是否成立 | 可重复脚本与运行记录 |
| 真实浏览器操作 | 用户经正常入口能否完成任务 | 操作步骤、屏幕证据、请求结果 |
| 真实学习或作者任务 | 是否减少等待、打断、解释与返工 | 脱敏任务记录及所有者反馈 |

各层分别报告。单元测试通过不计为浏览器或自用验收通过。

## 待细化的体验指标

任务完成率，用户操作步骤，主动澄清次数，重复说明次数，等待时间，中断恢复所需操作，失败后是否明确知道结果，内容返工次数，是否发生草稿或进度丢失，可理解性与主观负担。性能指标按交互场景分别测量，区分本地处理与外部模型等待。

真实课程写入、资料外传和远端 Git 操作按各自授权执行。优先使用脱敏副本和独立仓库复现。验收阶段明确哪些属于模拟、隔离实操与真实自用。


## Q004 已确认的执行责任

Agent 负责全部可代验项目，包括使用测试用免费 API 调用真实 LLM。无需强制所有者逐包或抽样验收。实际浏览器操作、真实模型调用、模型主观判断与所有者反馈分别标记。测试材料优先使用夹具和脱敏副本，记录 provider/model、日期、免费额度依据、调用数、延迟、失败及重试，不记录凭据。不自动转为付费 API。模型评价不能代替所有者本人体验证言。
