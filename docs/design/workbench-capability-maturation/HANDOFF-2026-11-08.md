## 9. 踩过的坑（复现成本很高，务必先读）

- **Edit 会吞相邻代码**（本轮一次把 `raise` 与 `finally:` 粘成一行 → SyntaxError）。改完看 `git diff` + 跑 `compileall`。
- **Windows CRLF**：夹具里 `write_text(..., newline="\n")` 才能做字节比较；Git 存 LF、工作区可能 CRLF。
- **控制台是 GBK**：`grep`/`cat` 读中文源码会乱码；用 `PYTHONUTF8=1 python - <<'PY'` 读文件、按行号匹配，不要靠肉眼比对乱码字符串。
- **每个"设备"必须有自己的 `LESSONKIT_WB_HOME`**，否则两台设备共用安装来源，来源前缀身份会撞。
- **`registry.register` 要求课程是"像工作区"的目录**：池必须在 `pool/` 或 `.lessonkit/pool/` 下。
- **`create-tables.py` 不建 workbench 独有表**（如 `retired_paper_items`）：接收端在**首次写入**时 `ensure_paper_lifecycle_schema`，不在启动迁移。
