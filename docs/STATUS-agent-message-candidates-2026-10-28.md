# Agent 消息候选列表（2026-10-28）

## 已确认行为

- 对话流只保留消息内容与真实工具结果，发送恢复框、发送状态标签和重试入口集中到输入框上方的消息候选列表。
- 发送被拒绝或执行失败的消息等待手动重发；状态未知时使用原标识和请求字段核对，不自动重发。
- 普通任务失败不暂停后续正常队列。手动停止、待审批、服务恢复和执行线程无法启动保留原有暂停规则。

## 修复

复用现有本地发送箱与服务端队列，仅合并展示区域；被拒绝消息可直接重发，已接收的失败重试保留原上下文并关联新轮次。新请求保存后替代旧失败候选，避免重试成功后旧项一直残留。可移除本机恢复记录；正在发送时不允许通过旧按钮删除恢复记录。普通失败后由现有 worker 释放路径继续队列，不增加自动重试器。
