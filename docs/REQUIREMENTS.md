## 一句话

**个人用的趁手学习工具**：把 lesson-kit 池子（31 KP / 正式题 / 闪卡 / 信号）变成每天打开
的复习工作台——挠自己痛处（弱项优先），AI 只经外部 agent CLI 当老师，绝不内置 AI 内核。

## 核心需求（已确认）

1. 网页一体工作台 + 超级 CLI（wb），文件夹 = 工作区，用户级注册表。
2. 日常复习为主；考前突击（`--mode all` 跨章节）、跟课抽取并重。
3. 挠痛处模型：弱项列表 → 拉题 → 直接练不会的；流程不钉死，永不锁题。
4. 反馈可选：1–5 打分 + 自然语言，映射信号并影响下次复习；信号永不自动清除。
5. 遗忘曲线只做排序背景与提醒（SM-2 变体），永不锁题。
6. AI 转接层：无 AI 内核；任务 + 输出契约 + 外部 agent CLI（cwd=工作区）；架构优于提示词。
7. 高信噪比输入（大纲/真题/经典解释）；真题覆盖门禁；出题而非总结；错题反向复习。
8. 教学行为分层：CLI 只是数据接口；教学在 Skill + 教师行为契约；会话弹性、不硬编码流程
   （ADR 0020，DeepTutor 启示）；Scoropic 苏格拉底对话模式已记录、延期（ADR 0021）。
9. 判分：可判分自动判；开放题"先作答→揭晓→自评"；没时间批改就只记录。
10. 图形知识点：`.lessonkit/figures/` 图床，KP 与题目都可挂图，Markdown 双端渲染。
11. 证明/推导卡点粒度（卡在第几步 + 自然语言）；级联信号（前置/方法 KP 传导）。
12. 对话中的作答记录进会话痕迹（trace），供未来 AI 教师记忆。

## 明确不做（scope 边界）

- 不做 AI 内核 / Harness Engineering；不做 LLM 接入适配器（v1 只接外部 CLI）。
- 不做模拟答辩模式（Scoropic 已延期，ADR 0021）；不做 generate 出题桥操作（v1.5）。
- 不做速成模式专用视图（v1 用 `--mode all` 顶住）。
- 不做跨对话 AI 教师个性画像消费端（trace 在积累，消费端后置）。
- 不做图形资产管理工具；不做 Obsidian vault 打包。
- 不改变现有管线/池子契约：新增全部增量（表/列），`lessonkit.py` 与 pipeline 不动。
- 不做防御性编程、不用哈希（含 SHA-256），ID 一律可读顺序标识。

## 2026-08-22 工作台信息架构优化

### 需求

工作台必须让学习者一眼看清当前位置、当前页面的主任务，以及正文和辅助信息的层级；
它应像一份结构良好的 Markdown 文档，而不是把标题、内容和操作等权堆叠的页面。

### 本次边界

- 重整顶栏、左栏、右侧 AI 栏和现有练习、会话末、知识点、图谱页的语义结构与视觉层级。
- 保留三栏布局、DSH 浅色令牌、所有路由、既有 DOM ID、客户端会话 key 与学习行为。
- 补齐工作区切换、会话末评分、再练同类、wiki 链接四个既有规范场景的可执行交互测试。
- 不增加学习功能、摘要看板、主题、拖拽栏宽、浏览器或 npm 依赖；不修改后端、数据或 Bridge 契约。

### 完成信号

- 页面均呈现“上下文 → H1 → 主内容或主动作 → 具名辅助区”的阅读顺序，且每页只有一个显著主动作。
- 非练习页加载共享脚本时不访问练习控件；练习、会话末、知识点、图谱、AI 栏原有行为保持可用。
- 四个既有 UI 场景通过自动化测试，完整测试、OpenSpec 验证与本地人工冒烟均通过。

## 2026-08-22 知识结构与练习会话重构

### 需求

- 正式题和候选题必须提供短标题与单一主题标签；薄弱项和知识点详情以可读名称为主。关联题按主题折叠，展开后直接显示短标题与完整题干，不显示摘要或原始题目 ID。

### 非目标

### 验收标准

- 现有 303 题的标题和主题均通过格式、重复、覆盖检查，并经不少于 30 题的人工抽检。
- 同一练习会话不重复题目；跳题和未提交内容不改变 SQLite；评分只写入一次。
- 图谱状态刷新后保持，且手动状态编辑不增加反馈事件或学习信号。
- 全量测试、OpenSpec 严格验证、JS 语法检查、池守卫和 :3081 人工冒烟均有通过证据。

## 2026-08-25 原生力导向知识图谱

### 需求

- 图谱节点按真实关系动态布局：关系越紧密，弹簧牵引越强、稳定距离越短。

## 2026-08-25 Agent 原生对话与内容治理

### Agent 数据能力

- 提供统一 JSON `wb data`，覆盖知识点、正式题、候选题和关系的读取、搜索、历史、显式增删改、状态、门禁与晋升。
- 浏览、搜索、讨论、草稿和导航零写入；正式题只能由双门禁通过的候选题晋升创建。
- 新对象按课程/章节/实体分配可读顺序 ID，不使用 hash；候选内容修改后重置门禁。
- 物理删除在单一事务中完成完整级联，不保留删除日志；显式状态编辑仍只覆盖当前值与调度。

### 对话与上下文

- 自动发现 PATH 中的 Codex 和 Claude；每个会话选定并锁定 provider，使用 provider 原生新建/续聊存储，不静默切换或重建。
- 每工作区独立保存会话入口与成功问答镜像；一次只运行一轮，支持真实取消和如实失败。
- 右栏是任何页面都可用的自由对话，不再显示讲解/诊断快捷按钮；旧 API 和 CLI 保留。
- 服务端根据路由与对象 ID 重建当前页权威上下文，并附当前浏览器会话最近三个对象；不发送整页 DOM。
- 未提交作答默认排除，仅练习页可对单轮显式附带；草稿、导航、失败输出与工具事件不进入长期对话镜像。
- 每日自动新会话默认关闭，由用户按浏览器本地日期启用，不能打断运行中的会话。

### 非目标与验收

- 不增加模型 SDK、npm、守护进程、跨 provider 自动降级或新的学习日志。
- 不修改 pipeline、lessonkit.py 或既有命令/API 行为；仅允许 `pool_schema.py` 增量 sequence 表。
- 自动化覆盖零写入读取、顺序 ID、门禁重置/晋升、删除级联、原生新建/续聊、并发冲突、取消、上下文边界、最近会话、每日开关与窄屏。

## 2026-08-27 灵动知识图谱与开发阶段冻结

- 六起点分量布局只提供确定性初始坐标；所有可见节点随后进入同一个无边界弹性力场，拖拽响应可跨原分量传播。
- 边长继续只由既有关系强度与共同题目形成的 `attraction` 决定：语义净距为 72–144px，并额外保证任意节点圆至少 24px 净空。
- 节点可拖到逻辑平面任意位置，边缘拖拽平移镜头；松手形成仅当前页面有效的软锚点，适应画布只调整镜头。
- 稳定后允许不超过 4px、30fps 的确定性低频呼吸；页面隐藏和 reduced-motion 均停止持续动画。
- 默认按核心性、正式题量和稳定 ID 只显示 6 个标签；缩放后逐级显示 12 个或全部，悬停、搜索和聚焦标签优先显示。
- 本变更归档后冻结主动功能开发；不增加社区、路径、桥节点、Graph Findings、参数面板或持久坐标，后续只响应真实学习使用中的问题。

## 2026-08-27 图谱聚拢控制

- 图谱工具栏增加一个紧凑的全局聚拢滑槽；数值越大，所有节点越趋向中心，数值越小，节点越分散，与是否有连线无关。
- 聚拢值只作用当前页面内存中的力场并立即重热，不写入 SQLite、浏览器持久化或学习记录。

## 2026-08-27 工作台侧栏与对话滚动补丁

- 桌面端左右侧栏支持拖动内侧边缘调整宽度，左栏约 200–480px、右栏约 360–560px，宽度仅存在于当前页面内存；移动端抽屉行为不变。
- Agent 对话消息区在内容超出可视高度时支持鼠标滚轮纵向滚动，输入区保持可见。

## 2026-08-27 图谱稳定性与后续学习方向

- 图谱稳定后保持完全静止；仅在拖拽、筛选、聚焦、尺寸变化或聚拢调节时重新运行力场，不叠加持续呼吸位移。
- 聚拢滑槽继续使用 0–100 范围，中心引力最大值提高到约原来的三倍；关系弹簧距离和节点净空规则不变。
- 后续允许另行设计以掌握证据和薄弱度驱动的图谱形态变化，以及少量可解释的选中节点学习看板；本轮不实现未定型学习功能。

## 2026-08-28 每日学习计划主线

- 练习页同时展示长期目标、阶段目标和当天的粗粒度短队列；学生只看到最终有效计划，不显示计划由默认算法还是 Agent 微调产生。
- 默认配量算法在无 Agent 时也必须可用，依据课程/阶段目标、进度、覆盖、截止时间、题型数量与难度生成稳定计划；Agent 只在理解自然语言反馈或学生主动要求时微调。
- 练习范围必须先由知识视图（知识图谱或知识列表）显式勾选，或由 Agent 在收到明确练习意图后代选并替换；普通对话、弱项排序和每日计划不得隐式抓题。
- 学生可以在已选范围内选择试卷、Flash Card 或 Yes/No 入口；每次会话只允许一种模式。Flash Card / Yes-No 仅在内容数据显式标注且确有可用题目时可用，未标注旧题不视为已实现这些模式。
- 无选中范围时练习页只显示空的交接状态，不拉取题目；短队列不得拆成精细操作手册。
- 每天首次打开时可自动重算一次，用户可主动再次重算；应用关闭期间不运行 Heartbeat。Agent 工作状态在对话区顶部显示，停止与返回同一行。
- 计划失败时保留上一次有效计划或默认算法结果；不新增未定义的状态机状态。
- 日历、任务量曲线、可选学习模型、插件生态、跨学科图谱和 AI 综合题生成继续作为后续实验方向。

### 2026-08-28 纠偏约束（本轮 Task 1）

- 长期目标、阶段目标只展示真实持久化目标；目标卡默认标题、进度和 DDL，不凭空生成课程目标、时长或掌握结论。
- 今日计划是独立的粗粒度队列，最多三项；无目标时只报告真实到期/可用工作。队列点击只能预填同一显式范围并打开模式选择。
- 选择、导航、草稿、跳题和查看计划均不写学习记录；详细增量契约见 `openspec/changes/correct-practice-scope-and-daily-plan/`。

## 2026-08-28 剩余学习闭环收束

- 当前收束变更 `complete-learning-workbench` 将内容题型与自评时机分开：每轮必须选择一种综合/闪卡/判断题型，以及每题自评或会话末统一自评。
- 闪卡、判断和选择题只有在内容显式提供相应结构时才可用；没有合格内容时必须显示空状态，不得把旧题干片段冒充新题型。
- 长期目标和阶段目标通过工作区本地真实数据管理；今日队列仍由确定性算法兜底，重算后完整刷新可见计划区域。
- Agent 只有收到明确练习意图时才可以用结构化动作替换当前知识点选择；普通对话保持只读。
- 知识列表默认课程/章节顺序并支持稳定正反排序；图谱默认关系布局，可基于现有指标切换投影，不持久化坐标。
- 日历、任务量曲线、学习模型选择、跨学科视图、自动 AI 小题生成和第三方动态插件安装继续属于后续实验，不在本次变更中伪造完成。

## 2026-08-29 视图合并决定

- 导航回三页：练习 / 知识点 / 知识图谱；2026-08-29 短暂出现的第 4 导航页「复习」移除（与专题 17、B6.2 的三页导航纠正一致）。
- （同日实现会话修订，见专题 19）练习页「真正要练的」只有一张「准备练习」列表 = 当前显式选区的行视图：知识点名 + 清除，与知识点页/图谱勾选双向同步，零新存储；模式选择与开始按钮行为不变。
- 计划与到期都是建议、按需拉取：「加今天要练的（N）」按钮展开候选，行 = 知识点名 · 一个短语 · 加入（知识点级去重、一行一短语，到期短语优先）；「今天先做」计划卡片解散、计划输出降为候选来源之一，重算按钮保留；到期不做常驻视图；UI 只到知识点级，题目行不进任何 UI。
- 字段极简是硬约束：候选与准备行不带徽标、日期、数字或调度参数；空态一句话一动作。
- 时间安排（目标月历 + 未来 14 天复习负荷，实验视图）放在练习页中栏日计划下方；卡内先月历、后负荷图纵向排列，窄屏各自横向滚动。
- 方向卡片 UI 全拆：无系统导向的会话，会话由用户自开（所有者确认真实池尚无方向调度行）；每方向独立调度键保留，卡片 UI 待真实使用再议。
- 保留的 additive API：pull include_ids、feedback direction、/calendar 端点、queries.review_overview（候选源与规划参考）、micro quiz 内容契约与判分；复习页 UI 拆除；顺手修复练习页主按钮禁用态样式（UX 清单项）。
