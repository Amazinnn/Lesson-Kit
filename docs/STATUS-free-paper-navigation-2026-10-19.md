# 练习自由导航改版：需求访谈（2026-10-19）

使用 `grill-with-docs`，按用户要求每轮通过提问工具集中确认多个相关问题。本轮仅记录明确方向与待决问题，不实现代码，不修改真实课程数据。OpenSpec change：`free-navigation-paper-practice`。

用户明确要求：上一题/下一题可自由浏览且不自动标不会；显式“不会”展示参考答案并标记；最终提交才处理仍未作答题；暂停按钮保留并改名“暂停练习”；删除旧的本地会话提示和截图中的开始配置块；补充题目状态圆点面板与完成页。

第一轮待答：逐题提交与自动保存、判定展示时机、不会标记的正式记录时机、交卷前修改及看过参考答案的处理。下一轮再确认开始入口、闪卡/自评归属、圆点行为与完成页，避免提前把未确认建议写成正式规范。

当前契约冲突：现有 `active_practice.mark` 只接受 pending 题目的首次 answered/stuck 转换，最后一题标记后自动归档；Practice Review 仅覆盖当前轮次已有作答的只读浏览，Attempt 原文只增不改。新流程必须在文档中划清本轮可编辑状态和正式记录的边界，再设计实现。Glossary 是术语权威；不另建与它竞争的 CONTEXT 词表，也不覆盖主工作区已有的 PENDING-DEFINITIONS 修改。
