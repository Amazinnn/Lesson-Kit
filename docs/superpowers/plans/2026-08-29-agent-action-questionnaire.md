# Agent 动作面问卷

**Purpose:** 决定 lesson-kit 下一阶段的动作面设计——讲解/诊断如何处置、Agent
（外部 AI）可以获得哪些动作（尤其 CLI）、新动作做什么。你的答案将直接变成
下一个 OpenSpec change 的需求输入。

**From:** 开发会话（2026-08-29） — **To:** 所有者 — **How your answers will be used:**
回收后由 Agent 起草 change 提案（讲解/诊断处置 + 动作面分级 + 新动作立项），
再走正常 grilling → 规格 → 实现 流程。

## Context

现状：Agent 可用的动作面 = AI 面板对话（自动带页面上下文）+ 22 个 CLI 数据
命令 + 讲解/诊断任务。你已表态：讲解/诊断是「针对一道题的特化」，而 Agent
拿到的上下文本就是整个版面，倾向不保留。全景登记见
`docs/ACTION-GRAPH.md`（动作图谱，本轮新建）——回答前可先扫一眼六域登记表。

## How to answer

异步填写即可，约 15–20 分钟。选项可多选/改写，`其他：` 处自由填写；不确定的
题写「没想好」比跳过更有用。
