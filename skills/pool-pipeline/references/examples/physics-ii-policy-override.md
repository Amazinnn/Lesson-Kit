# 示例：大学物理乙(II)课程级 policy override（2026-09-27）

> **示例，不是全局默认。** 只展示课程级 override 应如何记录；禁止自动套用到其他课程。

本文件覆盖 `policy-defaults.md` 的默认判据。用户在此门课上的四个决定：

## 1. 知识点缺口：先补齐残缺知识点，再入库

试卷里约 23 块涉及现有 81 个知识点覆盖不到的内容（现有 kp 到 ch22 康普顿效应为止）。
**决定：先新建 5 个知识点，再入库**，这 23 块绑新 kp，不绑"最接近的旧 kp"。

新建（chapter=`ch22`，沿用现有 `c01-ch22-kp-NNN` 词表）：

| kp_id | knowledge_item | 覆盖内容 |
| --- | --- | --- |
| `c01-ch22-kp-006` | 德布罗意波与波粒二象性 | 德布罗意波长、电子加速后波长、足球/宏观物体波长 |
| `c01-ch22-kp-007` | 不确定关系 | Δx·Δp ≥ ħ/2、光子 Δλ→Δx、时间-能量不确定关系 |
| `c01-ch22-kp-008` | 玻尔氢原子与氢光谱 | 能级、巴耳末/莱曼系、跃迁光子、氢原子量子态 |
| `c01-ch22-kp-009` | 波函数与概率密度 | 波函数归一化、概率密度、一维无限深势阱 |
| `c01-ch22-kp-010` | 电子自旋与四个量子数 | 自旋磁量子数 m_s、n/l/m/m_s 取值与数目 |

## 2. 匿名卷的 `exam_year`：按未定年份处理

期末合集 p02–p10、期中合集 p04–p06 共 8 张卷文本中无任何年份线索。
**决定：这些卷的 `exam_year` 留空（null），不猜、不填归档年、不做视觉定年任务。**
（`exam_year` 的合法形式是"以 4 位年份开头、≤20 字符"，留空表示"年份未知"，是合法状态。）

## 3. 没有答案键的题：不入库

**决定：推不出答案键的题块**（policy-defaults §3 的 `answer_key=null` 情形）**本次不入库**。
- 这类约 170 块（小测为主 + 两张回忆卷），全部登记进 `not-ingested.json` 台账，**不删源、不留半成品行**。
- 台账保留，用户改主意时可按同一套切分规则一次性补入。
- 注意区分：**答案写在题下、无 `【正解】` 标记但可证明的**（如 `qz-2526-zlx2r` 每题下的 `$$…$$`、`qz-2526-zlx1` 的 q2、wintermelonc 小测1–4 的 `**小测N答案**` 区）**算有答案键，正常入库**。
  只有"源里确实没有答案依据"的才排除。判据见 `split-rules.md` R6（E-a…E-f）。

## 4. 视觉升级：只补"选项在截图里"的选择题

**决定：只做 V2（选项只在截图里的选择题）**，把选项转录回来后按正常选择题入库。
- **不做** V1（整题只有一张图）→ 不入库，登记台账。
- **不做** V4（图片版整卷转录，3 张小测 webp，估计能新增 6–12 题）→ 不转录，登记台账。
- **不做** V5（匿名卷定年），已在 §2 决定。
- V3（公式 `U+FFFD` 坏到读不出）：能就地唯一恢复的就地修并注明；不能恢复的不入库、登记台账。

垃圾图判据 —— 全部照 `policy-defaults.md` 默认执行，本课无改动。
