# 已知陷阱（2026-10，仓库维护版）

这里保存已经实测、以后很容易重复踩的坑。历史课程路径只说明证据来源，不是当前运行依赖。

## 1. “干跑”可能是假验证

### 现象

旧实测确认三件事：

1. `lesson-kit ingest` 按**注册工作区名**找池；`cd` 到副本目录不会改变目标池。
2. `ingest recipe` 没有通用 `--db` 参数可以把命令随手指向任意副本。
3. 不带 `--apply` 的 recipe 路径可能只做 accounting/产物准备，并不等价于执行写入门禁；`rc=0` 不能单独证明 patch 可应用。

### 正确做法

- 要验证真实写链：复制池到隔离工作区，保留 `<course>.db` 文件名，注册临时 workspace，然后在副本上 `--apply`。
- 要做只读验证：调用正式 `check` 命令；如果某条 ingest 只有内部 gate，则在 Lesson Kit 开发环境里显式对副本/只读连接跑 gate。
- 永远不要用“换 cwd”作为数据库隔离手段。

副本文件名很重要：部分老路径会从 `database.stem` 推导 course。若改成 `c14-copy.db`，可能把合法 `c14-*` id 判成前缀错误。

## 2. 扫描器硬编码会制造假缺陷

曾经出现过三类假阳性，照着自动修会破坏正确题目：

- `[A-D]` 数不到 `E.`，于是误报“缺第 5 选项”；
- 没有先统一 Markdown/引号/空白，就误报“选项文本不在题面”；
- 行首字母正则把 `- **方案 A**：` 一类排版当成裸选项。

硬要求：

1. 不写死选择字母上限；根据实际 options 数或至少覆盖合理范围。
2. “数目检查”和“文本内容检查”同时做；文本匹配先声明归一化口径。
3. 脚本结果只是**可疑项**。缺失/多余/错位结论至少再用一种独立口径或人工抽样确认。
4. 不把某次扫描命中的具体条数写成永久常数。

## 3. 先做形态体检，再写切分器

源材料可能是 Markdown、HTML 表格、MHTML、PDF 文本层、截图或混合导出。上游“题数”“章节边界”都可能只是切分器提案。

体检至少记录：
- 文件/容器类型和编码；
- 题号写法；
- 选项写法；
- 答案证据在哪一层；
- 图片与文本如何对应；
- 跨文件/同文件重复率。

材料很碎时，精炼层只做索引，回原料取证。不要因为某个上游解析器报 `questions=0` 就断言文件里没有题。

## 4. 生成步骤必须有落盘产物

批量修复的关键中间物必须可复跑：源清单、sugared blocks、decision JSONL、patch manifest、删除台账。若只能靠聊天记忆重构 manifest，就不算完成。

## 5. `ingest_batch_id` 与删除

不要为了方便回滚/删除而随手回填历史 `ingest_batch_id`。它不是课程知识字段，却可能改变后续删除/回滚边界。批量清理需要关联时，优先写独立映射/台账。

## 6. `display_summary` 不是垃圾桶

它是短展示摘要，不应承载题目分组、处理过程或分类层。problem 的正式知识归属只在 `kp_ids`；`topic_label` 已从 problem schema 退役。

## 7. 并发读写时要认清快照

“我的脚本没写池”和“池期间没有变化”不是一回事。长时间审计或对账时：
- 写入前重新读取当前 revision/row；
- 需要一致视图时显式事务固定快照；
- 报告记录观察时间或源快照哈希。

做题经验已经内建 revision 冲突保护：Agent update/delete 必须用刚读到的 `expected_revision`，冲突就重新读并合并。

## 8. 页面视觉现象不等于数据库损伤

KaTeX、隐藏可访问性节点或浏览器复制可能让公式看起来重复。修数据前先直接读取字段/渲染夹具，确认数据库文本真的重复。

共享富文本回归夹具在 `tests/workbench/fixtures/rich_text.json`；渲染缺陷应在 Lesson Kit 产品仓库修 renderer，不要在课程数据里手写补丁。

## 9. 现代池不要依赖旧 `validate-pool.py`

截至 2026-10-08 current main，`pipeline/scripts/validate-pool.py` 仍把已经退役的 `candidate_problems/candidate_attempts` 当 required tables，且老 problem id 正则只认 `-prob-`，不完整覆盖 `-mq-`。

因此它不是现代池的验收权威。当前内容卫生用 `lesson-kit data <ws> audit`，写入前用正式 check/gate，再加本 skill 的 `preflight.py`。

## 10. 文件枚举也会骗人

某些生成路径可能产生名字像文件但实际是目录的 `*.recipe.json`。扫描/读取前先 `os.path.isfile()`，不要只按 glob 后缀相信类型。
