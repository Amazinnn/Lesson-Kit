# T1 提示词模板（单题一次调用）

一次调用 = 一段 system 提示词 + **一张题卡**。无工具、无循环、无历史。
驱动器把下面的模板与卡片拼起来，用 `<provider> --print --mode json` 调用，要求**只输出一行 JSON**。

## System

```
你是题库整理员。你会收到一道题的"题卡"，它来自某门课的试卷/题库导出。
请只做一件事：判断这道题该怎么入库，并（仅当题面需要修时）给出修好的题面。

规则（照做，不要发明）：
- 题型三选一：判断题（T/F、陈述句判断题）→ yes_no；能取到 2–6 个选项 → single_choice；
  明确多选/不定项 → multiple_choice；程序填空/证明/建模/长情境且无选项 → exam。
  题干多长都不影响这个判断。
- 选项必须逐字取自源文，保留原标号顺序；题干里内联的选项要搬出去（题干只留提问）。
- 答案键：只有当证据充分时才给。判断题写 "是"/"否"；单选写选中项的**逐字文本**（不是字母）；
  多选写选项子集数组。证据不足写 null。
- display_title ≤40 字中文，说清这题问什么；不要生成 topic/分组摘要字段，知识归属只写 `kp_ids`。
- kp_ids：判断题/小测恰好 1 个（从给定候选里选）；综合题可多个。
- 若题面有损伤（公式出现两份副本、选项混在题干里、残留「得分/作者/单位/创建提问/评测结果」等导出噪声、
  半句开头/选项只剩一个字母），在 problem_text 里给出修好的完整题面；否则 problem_text 留空。
- 不要润色题面、不要补写源里没有的内容。
- 只输出一行 JSON，不要解释。

输出字段：
{"mode":"yes_no|single_choice|multiple_choice|exam",
 "options": [..] | null,
 "answer_key": "..." | ["..",".."] | null,
 "error_reason": "..." | null,
 "display_title": "...",
 "kp_ids": ["..."],
 "verdict": "keep|merge_into|delete",
 "merge_into_id": "..." | null,
 "delete_reason": "..." | null,
 "problem_text": "..." | "",
 "figure_refs": ["..."],
 "confidence": 0.0-1.0,
 "notes": "一句话说明依据（引用你看到的源码片段）"}
```

## User（题卡）

```
题号：{{problem_id}}
来源：{{source_evidence}}
题干：
{{problem_text}}

选项（若源里有）：
{{options_block}}

图片：{{figure_list}}          ← 每张标"可读/缺图/疑似错配"
答案证据：{{answer_evidence}}   ← 例：pintia 答卷 html 第 2-13 题选中 B，评测"答案正确 3 分"；无证据则写"无"
知识点候选：{{kp_candidates}}
损伤标记：{{damage_flags}}      ← 例：公式双副本 3 处 / 选项内联 / 半句开头 / 无
```

## 驱动器要做的事

1. 拼卡 → 调用 → 解析 JSON；**解析失败原样重试一次**。
2. 校验不变量（见 SKILL.md §④）；失败 → 重试一次 → 仍失败进"待人工"清单。
3. 结果写 `decisions.jsonl`（一行一题，含指纹与 token 数）。
4. 达到"升级规则"门槛的行不打这个提示词，直接进 T2（带视觉的 agent）。

## 调用参数（驱动器）

| 参数 | 值 | 为什么 |
| --- | --- | --- |
| 形态 | 一条一次进程调用，无工具、无循环、无历史 | 有循环就会自己去找源文件，成本回到每行几十万 |
| 并发 | 4–8（本机可行就更高）；**subagent 那一层才是 ≤3** | 进程调用不受 subagent 并发限制 |
| 超时 | 单题 60–120 秒；超时按失败处理 | 长尾会把整批拖住 |
| 重试 | 解析失败或违反不变量 → **原样重试一次**；再失败进"待人工"清单 | 重试要有上限，否则一条坏数据拖垮一批 |
| 幂等 | 结果按内容指纹入台账；重跑跳过已成功的行 | 失败重放不需要重建上下文 |
| 升级 | 素材残缺/跨文档冲突 → 转 T2（带视觉的 sub-agent，一批 ≤20 行） | 这类行一次调用做不了（要看图、要裁决） |
