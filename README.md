# lesson-kit

**Modular study material generator.**

lesson-kit extracts knowledge points and durable problems from source material
into a course-level SQLite pool, then renders student-facing views from that
pool.

## Architecture

```text
Source material
  -> pipeline extraction
  -> pool/{course}.db
  -> views
```

The pool is the runtime source of truth for generated views. Markdown
intermediate files remain on disk for audit and repair.

## Runtime State

Lesson-Kit has a lightweight workflow checkpoint at `.lessonkit/state.yaml`.
It records the active course, chapter, command, phase, required artifacts, last
guard result, blocker, and next action. It is coordination state for agents;
it does not replace the SQLite pool as the source of truth for learning data.

Use the root CLI to inspect or update the runtime:

```bash
python lessonkit.py status
python lessonkit.py resume
python lessonkit.py init --course dmath --chapter ch06 --command problem-set
python lessonkit.py guard problem-set --course dmath --chapter ch06 --apply
python lessonkit.py guard extract-problems --course dmath --chapter ch06 --db pool/dmath.db --apply
```

The CLI is intentionally dependency-free in v1. It reads and writes a limited
YAML subset owned by Lesson-Kit. Guards are lightweight by default: they check
tracked intermediate artifacts and check reports. For extraction commands,
pass `--db pool/<course>.db` when you want local SQLite pool validation through
`pipeline/scripts/validate-pool.py`.

## Current Pools

- `knowledge_points`: extracted course knowledge.
- `problems`: durable practice problems. `source_kind` distinguishes textbook,
  quiz, midterm, final, makeup, and other problem pools.
- `problem_progress`: current durable problem status.
- `problem_attempts`: append-only durable problem interaction history.
- `questions`: legacy companion-check table retained for compatibility; it is
  not the v1 durable problem pool.

## Current Views

- Knowledge guide view: generated by `pool/scripts/print-graph.py`.
- Knowledge graph preview: generated by `pool/scripts/render-graph-html.py`.
  This is an optional, static HTML chapter map; it is not a blocking guard.
- Editable graph view: served locally by `pool/scripts/serve-graph.py` for
  pool maintenance and practice records. It uses the built assets in
  `frontend/editable-graph/dist` when present, and exposes graph data at
  `/api/graph`.
- Problem-set view: renders a practice set and matching solution file from
  `problems`.

## Editable Graph Frontend

The rich editable graph is a migration-friendly local prototype. Built assets
are checked in so normal use only needs Python:

```bash
python pool/scripts/serve-graph.py --db pool/dmath.db --course dmath --chapter ch06 --course-name "Discrete Math"
```

Maintainers can rebuild the frontend after UI edits:

```bash
cd frontend/editable-graph
npm install
npm run build
```

## Key Commands

```bash
python pipeline/scripts/create-tables.py --db pool/dmath.db
python pool/scripts/migrate-progress.py --db pool/dmath.db
python pipeline/scripts/insert-knowledge-points.py --db pool/dmath.db --manifest <pool-insert-manifest.json>
python pipeline/scripts/insert-problems.py --db pool/dmath.db --manifest <problem-insert-manifest.json>
python pipeline/scripts/validate-pool.py --db pool/dmath.db --course dmath --chapter ch06
python pool/scripts/query-pool.py --db pool/dmath.db --chapter dmath-ch06 --view problem-set --source-kind textbook
python pool/scripts/record-problem.py --db pool/dmath.db --problem dmath-ch06-prob-001 --status wrong --note "missed the counting model"
python pool/scripts/render-graph-html.py --db pool/dmath.db --course dmath --chapter ch06 --course-name "Discrete Math" --out output/dmath/ch06
python pool/scripts/serve-graph.py --db pool/dmath.db --course dmath --chapter ch06 --course-name "Discrete Math"
python lessonkit.py guard extract-chapter --course dmath --chapter ch06
python lessonkit.py guard extract-problems --course dmath --chapter ch06
python lessonkit.py guard extract-problems --course dmath --chapter ch06 --db pool/dmath.db
python lessonkit.py guard problem-set --course dmath --chapter ch06
```

## Versioning

Git commits and tags are the version source of truth. Zip packages may still be
created for external review or prompt-level handoff, but they are release
artifacts, not version records.

## Status

Pre-release. Knowledge extraction, the knowledge guide view, the unified
problem pool, the problem-set view, and lightweight runtime guards are working.
